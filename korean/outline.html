5 PHASES · 26 UNITS

完整課程大綱

目標是能閱讀生活中常見的韓文、完成基本日常對話，並聽出句子裡的關鍵字。第一階段已完成，後續內容會依此順序製作。

PHASE 01 / UNIT 01—06

先把韓文讀出來

階段目標看到陌生的簡單韓文時，能拆開音節、嘗試拼讀，並聽出學過的聲音。

UNIT 01已完成

韓文字母怎麼運作

認識音節方塊、子音與母音的角色，以及韓文的閱讀方向。

  • 音節方塊
  • 子音與母音
  • 左右／上下組合
  • 拆解音節
UNIT 02已完成

基本母音

用嘴型和字形認識十個基本母音，建立第一批可拼讀音節。

  • ㅏ ㅓ
  • ㅗ ㅜ
  • ㅡ ㅣ
  • ㅑ ㅕ ㅛ ㅠ
UNIT 03已完成

基本子音

分組學習十四個基本子音，聽辨平音與送氣音的差別。

  • ㄱ ㄴ ㄷ ㄹ ㅁ
  • ㅂ ㅅ ㅇ
  • ㅈ ㅊ
  • ㅋ ㅌ ㅍ ㅎ
UNIT 04已完成

複合母音與雙子音

補齊常見複合母音，並比較平音、送氣音和緊音。

  • ㅐ ㅔ
  • ㅘ ㅙ ㅚ
  • ㅝ ㅞ ㅟ ㅢ
  • ㄲ ㄸ ㅃ ㅆ ㅉ
UNIT 05已完成

받침 收尾音

理解音節底部的收尾音，掌握七種代表聲音與雙 받침 入門。

  • 받침 位置
  • ㄱ ㄴ ㄷ
  • ㄹ ㅁ ㅂ ㅇ
  • 雙 받침
UNIT 06已完成

連音與常見發音變化

把拼字和實際聲音連起來，練習連音、鼻音化與其他常見變化。

  • 連音
  • 鼻音／流音化
  • 送氣／緊音化
  • 街頭文字拼讀

PHASE 02 / UNIT 07—11

看懂路上的韓文

階段目標看懂車站、商店、餐廳與公共空間裡最常出現的關鍵字。

UNIT 07後續製作

數字、樓層與價格

辨認兩套數字、韓元價格、樓層與常見促銷文字。

  • 固有數字
  • 漢字數字
  • 樓層／數量
  • 價格／折扣
UNIT 08後續製作

時間、日期與營業時間

讀懂日期、星期、幾點幾分、營業與休息資訊。

  • 日期／星期
  • 時間
  • 營業時間
  • 公休／最後入場
UNIT 09後續製作

入口、出口與方向

辨認入口、出口、左右、上下、裡外與洗手間方向。

  • 입구／출구
  • 左右／前後
  • 上下／裡外
  • 方向指示
UNIT 10後續製作

交通與車站文字

閱讀地鐵、公車、月台、轉乘、終點與施工資訊。

  • 地鐵／公車
  • 月台／出口
  • 方向／轉乘
  • 禁止／施工
UNIT 11後續製作

商店、餐廳與公共場所

認識店家種類、內用外帶、營業狀態與常見警告標示。

  • 店家種類
  • 內用／外帶
  • 營業／售完
  • 警告標示

PHASE 03 / UNIT 12—17

建立韓文句子

階段目標讀懂簡單完整句子，並能提出人物、地點、時間與價格問題。

UNIT 12後續製作

「是」與自我介紹

使用 이에요／예요、입니다 與 아니에요 建立自我介紹。

  • 이에요／예요
  • 입니다
  • 아니에요
  • 姓名／國籍／職業
UNIT 13後續製作

主題、主詞與受詞

理解韓文句序，以及 은／는、이／가、을／를 的基本作用。

  • 基本句序
  • 은／는
  • 이／가
  • 을／를
UNIT 14後續製作

有、沒有與位置

使用 있어요／없어요 和 에 描述人物、物品與地點。

  • 있어요／없어요
  • 에
  • 位置詞
  • 詢問地點
UNIT 15後續製作

現在式與日常動作

從動詞原形進入 -아요／어요，描述每天做的事情。

  • 動詞原形
  • -아요／어요
  • 하다 → 해요
  • 日常動作
UNIT 16後續製作

形容詞與否定

描述物品、天氣與感受，並使用 안 和 -지 않아요 否定。

  • 常用形容詞
  • 안
  • -지 않아요
  • 感受描述
UNIT 17後續製作

問句與疑問詞

使用 누구、뭐、어디、언제、왜、어떻게 與 얼마 提問。

  • 人物／事物
  • 地點／時間
  • 原因／方法
  • 價格／數量

PHASE 04 / UNIT 18—23

日常生活會話

階段目標在常見生活情境中使用簡短而有禮貌的韓文完成需求。

UNIT 18後續製作

問候與基本互動

練習問候、致謝、道歉，以及聽不懂時的確認方法。

  • 問候／道別
  • 謝謝／道歉
  • 請再說一次
  • 禮貌體界線
UNIT 19後續製作

餐廳與點餐

看懂基本菜單，完成推薦、份數、辣度、加點與結帳。

  • 看菜單
  • 詢問推薦
  • 份數／辣度
  • 結帳
UNIT 20後續製作

購物與付款

詢問價格、顏色、尺寸與其他款式，完成付款與退稅。

  • 詢價
  • 顏色／尺寸
  • 試穿／款式
  • 付款／退稅
UNIT 21後續製作

交通與問路

詢問怎麼去、在哪站下車、是否轉乘，並聽懂簡短方向。

  • 問地點
  • 方向
  • 上下車
  • 轉乘／車資
UNIT 22後續製作

時間、約會與計畫

約日期、時間與地點，表達想去、可以或不方便。

  • 約時間
  • 可以／不方便
  • -고 싶어요
  • 未來計畫
UNIT 23後續製作

住宿、問題與求助

處理入住、設施問題、遺失物，以及醫院或警察局求助。

  • 入住／預約
  • 房間設施
  • 遺失／故障
  • 基本求助

PHASE 05 / UNIT 24—26

閱讀與聽力整合

階段目標不逐字翻譯，也能抓到生活韓文中的重要資訊與回應方式。

UNIT 24後續製作

讀菜單、招牌與商品標示

從關鍵字判斷店家、料理、價格、口味與注意事項。

  • 招牌分類
  • 菜名結構
  • 商品口味
  • 期限／注意事項
UNIT 25後續製作

基礎聽力與關鍵字

聽辨數字、價格、時間、方向與問句語尾，不追求逐字翻譯。

  • 關鍵字
  • 問句語尾
  • 數字／地點
  • 慢速／自然速度
UNIT 26後續製作

一天在韓國的綜合任務

從車站到餐廳、商店與住宿，把閱讀和簡短對話串成完整一天。

  • 車站出口
  • 點餐購物
  • 約人搭車
  • 自我介紹
