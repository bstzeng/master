UNIT 125 LESSONS

이다와 자기소개

「是」與自我介紹

使用 이에요／예요、입니다 與 아니에요，說明姓名、國籍與職業。

  1. 01이에요／예요：禮貌地說「是」
  2. 02입니다：正式場合的「是」
  3. 03아니에요：禮貌地說「不是」
  4. 04姓名與國籍介紹
  5. 05職業與完整自我介紹

UNIT 136 LESSONS

문장 순서와 조사

主題、主詞與受詞

理解韓文述語在後的句序，並使用 은／는、이／가、을／를標示句中角色。

  1. 01基本句序：述語放最後
  2. 02은／는：設定談話主題
  3. 03이／가：指出主詞與新資訊
  4. 04은／는 與 이／가 的基本差異
  5. 05을／를：標示動作的受詞
  6. 06句序與助詞整合任務

UNIT 145 LESSONS

있다·없다와 위치

有、沒有與位置

使用 있어요／없어요、에 與位置詞，描述人和物品在哪裡或是否存在。

  1. 01있어요／없어요：有、在與沒有
  2. 02에：標示存在地點
  3. 03前後左右與內外
  4. 04어디에 있어요?：詢問地點
  5. 05位置地圖整合任務

UNIT 156 LESSONS

현재형과 일상 동작

現在式與日常動作

從動詞原形找出語幹，套用 -아요／어요 與 해요，描述每天的生活動作。

  1. 01動詞原形與語幹
  2. 02-아요／어요：現在式基本規則
  3. 03母音相遇時的常見縮約
  4. 04하다 → 해요 與 하다 動詞
  5. 05描述一天的日常動作
  6. 06現在式問答與作息整合

UNIT 165 LESSONS

형용사와 부정

形容詞與否定

使用韓文形容詞描述物品、天氣與感受，再以 안 和 -지 않아요 建立否定。

  1. 01韓文形容詞也會變句尾
  2. 02描述物品、天氣與味道
  3. 03描述感受與身體狀態
  4. 04안：簡短自然的否定
  5. 05-지 않아요 與否定整合

UNIT 175 LESSONS

의문문과 의문사

問句與疑問詞

使用 누구、뭐、어디、언제、왜、어떻게、얼마 與 몇，詢問人物、事物、地點、時間、原因、方法與數量。

  1. 01해요體的是非問句
  2. 02누구／뭐：詢問人物與事物
  3. 03어디／언제：詢問地點與時間
  4. 04왜／어떻게：詢問原因與方法
  5. 05얼마／몇 與疑問詞整合任務
