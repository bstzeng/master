UNIT 185 LESSONS

인사와 기본 대화

問候與基本互動

從日常問候、道別、致謝與道歉開始，練習聽不懂時的禮貌確認。

  1. 01見面問候與近況
  2. 02道別與下次見
  3. 03謝謝、回應與道歉
  4. 04沒聽懂時請再說一次
  5. 05禮貌體界線與互動整合

UNIT 196 LESSONS

식당과 주문

餐廳與點餐

讀取菜單關鍵字，詢問推薦、份數與辣度，並完成加點和結帳。

  1. 01看懂菜單與入座
  2. 02詢問推薦與餐點內容
  3. 03完成基本點餐
  4. 04份量、辣度與需求調整
  5. 05加點、續加與外帶
  6. 06結帳與付款

UNIT 205 LESSONS

쇼핑과 결제

購物與付款

詢問價格、顏色、尺寸與其他款式，完成試穿、付款與退稅。

  1. 01詢價與折扣
  2. 02顏色與尺寸
  3. 03試穿、試用與比較
  4. 04結帳、袋子與收據
  5. 05退稅與基本換貨詢問

UNIT 216 LESSONS

교통과 길 찾기

交通與問路

詢問目的地怎麼去、在哪站下車與是否轉乘，並聽懂簡短方向。

  1. 01詢問目的地怎麼去
  2. 02聽懂步行方向
  3. 03上車、下車與站數
  4. 04轉乘與路線
  5. 05車資、時間與交通卡
  6. 06問路與搭車整合任務

UNIT 225 LESSONS

시간·약속·계획

時間、約會與計畫

約日期、時間與地點，表達想去、可以或不方便，並確認未來計畫。

  1. 01詢問有沒有時間
  2. 02提出日期、時間與地點
  3. 03可以、不方便與改期
  4. 04-고 싶어요 與想做的事
  5. 05未來計畫與約會整合

UNIT 236 LESSONS

숙소·문제·도움 요청

住宿、問題與求助

處理入住、房間設施、遺失與故障，並在醫院或警察局提出基本求助。

  1. 01入住與確認預約
  2. 02設施、時間與住宿規定
  3. 03房間設施故障
  4. 04遺失物與找回
  5. 05身體不舒服與醫療求助
  6. 06警察求助與緊急整合
