받침

받침 是什麼

方塊底部的子音會收住音節

零基礎15 分鐘點擊發音

TODAY / 15 MIN

比較 가 與 각、나 與 난，理解沒有收尾和有收尾的結構。

LEARNING GOALS

  • 辨認 받침 位置
  • 比較開音節與閉音節
  • 依上到下順序拆解三層方塊
01

底部多一個子音

받침 位於音節方塊底部，作用是收住音節。가 只有 ㄱ + ㅏ；각 則在底部多了 ㄱ。

  • 가：沒有 받침
  • 각：底部 ㄱ
  • 간：底部 ㄴ

02

閱讀順序固定到底部

有 받침 的音節仍先讀開頭子音和母音，最後才收到底部。左右組合讀左、右、下；上下組合讀上、中、下。

  • 각：ㄱ → ㅏ → ㄱ
  • 곰：ㄱ → ㅗ → ㅁ
  • 문：ㅁ → ㅜ → ㄴ
ㄱ + ㅏ + ㄱ

03

不是把子音完整拉長

收尾音通常短而收住，不會像後面再加一個母音。각 的結尾不是完整的 그，而是在 ㄱ 的位置停止。

  • 각 不讀成 가그
  • 문 不讀成 무느
  • 保持短而清楚的收尾

곰 的 받침 是什麼？

ㅁ，位於方塊底部。

각 可以讀成 가그 嗎？

不可以；底部 ㄱ 是短收尾，後面沒有 ㅡ。
