TODAY / 15 MIN

從已學過的 ㅏ、ㅓ、ㅗ、ㅜ 推導四個 y 系列母音。

LEARNING GOALS

  • 從基本母音推導 y 系列
  • 聽辨 야／여／요／유
  • 讀取包含 y 系列母音的單字
01

ㅏ、ㅓ 多一筆

ㅏ 增加一條短線變成 ㅑ，讀成 야；ㅓ 增加一條短線變成 ㅕ，讀成 여。多出的短線可以視為多出的 y 起音。

  • ㅏ → ㅑ：아 → 야
  • ㅓ → ㅕ：어 → 여
  • 兩者仍是直式母音
y + ㅏRRya
ㅇ + ㅑRRya
y + ㅓRRyeo
ㅇ + ㅕRRyeo
02

ㅗ、ㅜ 多一筆

ㅗ 增加一條短線變成 ㅛ，讀成 요；ㅜ 增加一條短線變成 ㅠ，讀成 유。它們仍放在子音下方。

  • ㅗ → ㅛ：오 → 요
  • ㅜ → ㅠ：우 → 유
  • 兩者仍是橫式母音
y + ㅗRRyo
ㅇ + ㅛRRyo
y + ㅜRRyu
ㅇ + ㅠRRyu
03

在真實單字裡讀

여우、우유、요리 都使用今天的母音。先把單字分成音節，再找每個方塊的母音。

  • 여우 → 여 + 우
  • 우유 → 우 + 유
  • 요리 → 요 + 리
狐狸RRyeou
牛奶RRuyu
料理RRyori

RECAP

今天要帶走的事

  1. 01基本母音多一條短線，通常會多出 y 起音。
  2. 02ㅑ、ㅕ 放在右邊，ㅛ、ㅠ 放在下方。
  3. 03可以從舊母音推導新母音，不必獨立死背。

CHECK YOURSELF

先想一想，再看答案

ㅗ 多一條短線後變成什麼？

ㅛ，獨立音節寫成 요。

우유 有幾個音節？

兩個：우 和 유。

2 MIN PRACTICE

今天的練習

  1. 依序跟讀 아-야、어-여、오-요、우-유。
  2. 拆解 여우、우유、요리，圈出 y 系列母音。
