形容詞と否定

情境描述整合任務

描述餐廳、商品、天氣與房間

TODAY / 15 MIN

綜合兩類形容詞的肯定、否定與名詞修飾。

LEARNING GOALS

  • 依詞類選形式
  • 比較兩項事物
  • 完成生活描述
01

先辨認詞類

看到新形容詞時，筆記應包含詞類、肯定、否定與名詞前形式。例如 静か：な形容詞／静かです／静かではありません／静かな部屋。

  • 記詞類
  • 記否定變化
  • 記名詞前連接
安靜的房間Hshizukanaheya
不安靜。Hshizukadewārimasen
02

比較兩個選項

Aは安いですが、Bは便利です 使用 が 連接對比描述。初學可先用兩個短句，確認形容詞形式正確再合併。

  • は 設定對比主題
  • が 表示轉折
  • 不必強迫選出唯一最佳
這家店很便宜。Hkonomisewayasuidesu
那家店很方便。Hanomisewabenridesu
03

真實描述與修正

感受可能不是全肯定，可用 あまり〜くないです 或 ちょっと〜です 柔和表達。餐廳或住宿評價應描述具體面向。

  • あまり高くないです：不太貴
  • ちょっと狭いです：有點窄
  • でも、きれいです：但很乾淨
房間有點窄。Hheyawachottosemaidesu
但是很乾淨。Hdemo、kireidesu

RECAP

今天要帶走的事

  1. 01形容詞應連同詞類與變化記憶。
  2. 02比較時可用 は 設定兩個主題。
  3. 03ちょっと 與 あまり 能柔和描述負面感受。

CHECK YOURSELF

先想一想，再看答案

静か 的名詞前形式是什麼？

静かな＋名詞。

「房間有點窄」怎麼說？

部屋はちょっと狭いです。

2 MIN PRACTICE

今天的練習

  1. 比較兩家餐廳的價格、味道與便利性。
  2. 用肯定與柔和否定描述一間房間。
