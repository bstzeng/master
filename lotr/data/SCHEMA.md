# 魔戒課程資料格式

每位 agent 只能修改指定的 Python 資料檔，不要修改其他檔案。資料檔需提供 `UNITS = [...]`。

每個單元使用以下結構：

```python
{
    "number": 1,                         # 全課程連續 1–60
    "phase": 1,                          # 1–10
    "slug": "tolkien-and-legendarium",  # 小寫英文與連字號，唯一
    "title": "托爾金與中土世界的誕生",
    "english": "TOLKIEN & THE LEGENDARIUM",
    "timeframe": "現實世界／創作史",
    "subtitle": "一句準確的頁面說明。",
    "opening": "至少 70 個中文字，交代本單元核心問題與歷史位置。",
    "objectives": ["恰好三項", "...", "..."],
    "sections": [
        {
            "heading": "章節標題",
            "body": "至少 90 個中文字的完整解說；使用摘要與分析，不得長篇引用原文。",
            "points": ["恰好四項具體重點", "...", "...", "..."],
            "lens": "至少 30 個中文字的深度閱讀提示，指出因果、人物動機、主題或常見誤解。",
        },
        # 每單元恰好四個 sections
    ],
    "characters": [
        {"name": "人物名", "role": "本單元身分", "arc": "至少 25 個中文字的動機或轉變"},
        # 每單元 3–6 人；純設定單元也可列勢力、族群或文本
    ],
    "connections": [
        "恰好三項，說明本單元和前後時代、《哈比人》或《魔戒》的呼應。",
        "...",
        "...",
    ],
    "takeaways": ["恰好四項", "...", "...", "..."],
    "quiz": [
        ("問題一", "有解釋的答案一"),
        ("問題二", "有解釋的答案二"),
        ("問題三", "有解釋的答案三"),
    ],
    "practice": "一項具體閱讀、時間線、人物比較或主題分析練習。",
    "sources": [
        {"title": "資料名稱", "url": "https://...", "note": "這項資料支援哪些內容"},
        # 每單元 2–4 個；優先 Tolkien Estate、作者文本資訊、出版社、Bodleian、學術來源
    ],
}
```

## 寫作規則

- 使用繁體中文；首次出現的重要人物／地名可附英文或原文，之後用一致中文名稱。
- 以托爾金原著為主。電影、影集內容只能在改編單元，或明確標示為改編差異。
- 《精靈寶鑽》、遺稿與《中土世界的歷史》存在版本差異時，必須明確說明，不得假裝只有唯一正史。
- 每單元都要深度解析「事件因果、人物動機、主題意義、後續影響」，不能只重述劇情。
- 不得抄錄長段原文、詩歌、歌詞、魔戒銘文、官方地圖或精靈文字。短語也盡量改述。
- 避免未經文本支持的網路傳聞。來源優先使用 `https://www.tolkienestate.com/`，並可補出版社、Bodleian、可靠學術資料。
- 所有 Python 字串必須可解析，檔案需通過 `python3 -m py_compile`。
