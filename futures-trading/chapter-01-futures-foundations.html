WHY FUTURES EXIST

期貨的起源、用途與核心特性

期貨不是『猜漲跌的按鈕』，而是一份有標的、數量、月份、價格與結算規則的標準化契約。先看懂它為何存在，才有資格討論策略。

70–90 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能用自己的話說明期貨如何移轉價格風險、結算所扮演什麼角色，以及到期、沖銷與現金結算的差別。

RISK BOUNDARY

本課程只做教育與模擬練習，不提供即時訊號或獲利保證。期貨有槓桿，損失可能超過最初存入的保證金。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

從不確定價格，轉成可管理的契約

農產品、能源、金屬與金融市場的參與者，常在今天就面對未來價格的不確定。期貨把未來某一時間、某一標的的買賣條件標準化，使生產者、使用者與投資人能在公開市場移轉一部分價格風險。 例如進口商擔心原料上漲，可以用相應期貨建立避險；持有股票組合者擔心市場短期下跌，也可能用股價指數期貨降低整體曝險。避險不是讓風險消失，而是把價格風險換成基差、口數與執行風險。

實際決策時，先寫清楚自己要管理的曝險，再找契約；不能因為看到熱門商品就反過來發明交易理由。把期貨當成快速致富工具，會忽略它本來是風險移轉機制，以及每一口背後的巨大名目價值

現貨端真實曝險

原料、庫存、投資組合或未來現金流。

契約端標準條件

標的、月份、乘數與結算方式固定。

市場端價格發現

多方需求與空方供給共同形成價格。

管理端剩餘風險

基差、流動性、追繳與執行仍需承擔。

圖解｜期貨為何出現 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

持有期貨部位，代表承擔契約損益

買進股票通常取得公司權益；買進期貨則建立一份在契約規則下受價格變動影響的多方部位。你沒有用保證金『買下』等值資產，保證金只是履約擔保，名目價值仍按價格乘以契約乘數計算。 期貨有月份與到期日，同一標的不同月份是不同契約。持倉者可以在到期前以反向交易沖銷，或依規則進入現金或實物交割；初學者絕不能假設平台會自動替自己做最有利的處理。

實際決策時，每次下單前都要朗讀契約名稱、月份、方向、口數與預計退出方式。只看畫面上的保證金數字，容易把可承受的最大部位誤認為適合的部位

名目價值 = 期貨價格 × 契約乘數 × 口數
保證金 ≠ 名目價值；它是履約擔保
不是買下一整份資產

保證金不是商品售價或股票市值。

而是建立多空義務

損益隨契約價格每日結算。

必查契約月份

近月與遠月價格、流動性可能不同。

必寫退出方式

平倉、轉倉或依規則進入結算。

圖解｜合約而不是資產 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

交易所先定義共同語言

交易所把標的品質、契約大小、最小跳動、可交易月份、時段、價格限制、最後交易日與結算方式寫進規格。買賣雙方主要議價的是價格，不必每筆重新協商所有條件，因此市場更容易集中流動性。 標準化也意味著不能任意改份量或到期日。若契約乘數太大、交易時段不適合，正確選擇可能是換小型商品或不交易，而不是因保證金看起來付得起就勉強建立部位。

實際決策時，先用規格表篩選契約，再用策略判斷是否進場。把不同商品的『一點』當成同樣金額，是新手最常見且昂貴的規格錯誤

標的你在交易什麼

指數、利率、匯率、能源或商品。

乘數一點值多少

把報價變成名目價值與損益。

月份契約何時結束

決定到期、轉倉與流動性。

結算最後如何履約

現金結算或實物交割依契約而定。

圖解｜標準化的力量 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

同一張合約承載不同目的

避險者已有現貨或營運曝險，建立方向相反的期貨部位以降低總體價格敏感度；投機者沒有對應現貨曝險，主動承擔價格變動以追求報酬；套利者則觀察相關價格偏離，嘗試同時買低賣高。 三者都需承擔執行、流動性與模型錯誤。避險也可能因口數、期間或標的不完全匹配而留下基差風險；套利也不是無風險，融資、交易成本與成交不同步都可能使價差擴大。

實際決策時，在交易計畫第一行標示目的，因為避險單與投機單的成功標準不同。用『這是避險』合理化一筆原本沒有對應曝險的虧損投機單，會讓風險無限延長

HEDGE降低既有曝險

看總組合，而不是只看期貨單盈虧。

SPECULATE主動承擔方向

需要明確優勢、失效點與風險額度。

ARBITRAGE管理相對價格

重點是同步、成本與資金占用。

ALL仍有剩餘風險

沒有任何標籤能免除風險管理。

圖解｜避險、投機與套利 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

交易不是只靠對手信用

集中市場由結算制度在買方與賣方之間管理履約，透過保證金、每日結算與風險措施降低單一對手違約的連鎖影響。你的直接操作對象通常是合法期貨商，部位與資金仍受契約、帳戶與結算規則約束。 價格每天變動會形成損益並反映在權益數；因此即使你計畫持有數日，也不能把虧損只當成帳面波動。權益不足時可能面臨補繳或平倉，而且期貨商的風險控管可能比交易所最低要求更嚴格。

實際決策時，盤後確認成交、部位、權益與保證金，不把通知當成唯一風險監控。相信『只要不平倉就不算虧』，完全不適用於每日結算的期貨帳戶

成交買賣撮合

價格與數量形成成交紀錄。

結算損益入帳

依結算價更新帳戶權益。

風控保證金檢查

不足時可能需補繳或減倉。

責任自行核對

成交回報與對帳單都要查驗。

圖解｜結算所與每日結算 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

大多數交易以反向交易結束，但不可依賴想像

持有一口多單，通常可在同契約月份賣出一口而沖銷；空單則以買進沖銷。是否可當沖、最後可下單時間、到期處理、現金結算或實物交割，都取決於契約與期貨商規則。 接近到期時，成交可能移轉到下一活躍月份，近月與遠月價格不一定相同。若策略要延續，轉倉是先處理舊約、再建立新約的兩筆決策，產生價差、成本與執行風險，不是免費延長。

實際決策時，在日曆提前標示最後交易日、期貨商最後處理時點與預定轉倉日。把不同月份視為同一商品直接相減，會忽略價差與期限結構造成的策略改變

OPEN建立部位

確認月份、方向與口數。

HOLD每日管理

權益、失效點、事件與流動性。

OFFSET反向沖銷

在同月份以相反方向結束。

EXPIRY依規則結算

勿在不了解交割時被動留到到期。

圖解｜沖銷、交割與到期 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

名稱相似，不代表權利義務相同

股票、ETF、選擇權、差價合約與期貨都能表達方向看法，但所有權、到期、槓桿、最大損失、交易對手與監管架構不同。期貨多空通常具有線性損益；選擇權買方則支付權利金取得權利，損益具有非線性。 比較商品不能只看『哪個賺比較快』，應比較最壞情境、資金需求、時間限制、流動性、費用、稅務與自己是否能正確監控。若無法清楚說明最大風險，先不交易就是合格決策。

實際決策時，用同一個市場情境比較各工具的權利義務，而不是只比較槓桿倍數。把受監管交易所期貨與場外高槓桿產品混為一談，可能低估對手與平台風險

STOCK權益資產

通常無契約到期，資金結構不同。

FUTURES線性契約

到期、每日結算與保證金。

OPTION非線性權利

買賣方風險結構不同。

OTC先查對手

平台、報價與監管不可忽略。

圖解｜期貨與其他商品 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

把不交易的條件先寫下來

期貨教育的第一個產出不是一張訂單，而是一份個人安全契約：只使用可承受完全損失的風險資本、先模擬、只交易看得懂的契約、不借款補保證金、不在疲勞或情緒化時下單。 同時查核期貨商資格、費用、出入金與客訴管道；帳號開啟多因素驗證，任何自稱保證獲利、要求交付密碼或催促匯款的訊息都停止處理。合法平台也無法消除市場損失。

實際決策時，把安全契約放在每次交易檢查表最前面，違反任一條就取消交易。用生活費、緊急預備金或借貸資金承受槓桿，會把市場波動變成生活危機

CAPITAL只用風險資本

完全損失也不影響生活與債務。

PRACTICE先模擬 30 筆

建立操作與統計，不急著實盤。

VERIFY查核合法業者

網址、客服、監管與出入金都核對。

STOP保留不交易權

沒有清楚優勢與風險就不下單。

圖解｜開始前的安全契約 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

DECISION REHEARSAL

把第 1 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「期貨的起源、用途與核心特性」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  1. 01

    判斷題期貨用標準化契約移轉價格風險並協助價格發現。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  2. 02

    判斷題保證金是履約擔保，不是名目價值或商品售價。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題多數部位可沖銷，但到期、轉倉與結算規則必須事前確認。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  4. 04

    判斷題期貨有槓桿，先模擬、只用風險資本，並保留不交易的權利。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

把『我覺得會漲』改寫成契約語言

IMPULSIVE

台股可能會漲，所以我想買期貨。畫面顯示只要一筆保證金，看起來比買股票便宜。

DISCIPLINED

我先選定合約月份，核對乘數、跳動點值、到期、結算與交易時段；再用名目價值與失效距離計算風險。若不符合風險額度，本次不交易。

WHY IT MATTERS

方向看法被轉換成可核對的契約與風險條件，不再把保證金誤認為商品售價。

CHECK YOUR MODEL

先回答，再展開。

保證金是不是買下一口期貨的價格？

不是。保證金是履約擔保；契約曝險看價格乘數與口數形成的名目價值。

避險是不是一定不會虧？

不是。避險降低特定價格曝險，但仍有基差、口數、流動性、執行與剩餘曝險。

期貨多單一定要持有到交割嗎？

通常可在到期前以同月份反向交易沖銷，但必須依契約與期貨商規則處理。

不同月份可以當成完全相同的商品嗎？

不行。它們是不同契約，價格、流動性、到期與基差可能不同。

何時『不交易』是正確答案？

看不懂契約、風險超額、無清楚失效點、平台未查核或資金不是風險資本時。
