PAPER TRADE END TO END

完成一筆期貨交易的全生命週期

最後一章不增加新指標，而是把前十一章串成一次紙上交易：每一步都有輸入、判斷、失敗出口與紀錄，直到平倉後復盤完成。

120–150 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能獨立完成選合約、查規格、判斷狀態、寫策略、算口數、模擬送單、管理退出、對帳與復盤。

RISK BOUNDARY

本章的『完成』指完成教育與模擬流程，不代表已準備好實盤。沒有任何課程能替你承擔資金、法律、稅務與心理風險。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

從可理解、可觀察與可承受三個條件開始

選擇你能取得官方規格與可靠報價、在可專注時段觀察、且最小一口風險可被帳戶承受的商品。熱門、波動大或保證金低都不是充分理由。 建立候選清單後比較乘數、跳動、流動性、盤別、到期、結算、成本與事件。若沒有一個商品通過，流程在這裡正常結束，保持空手。

實際決策時，先篩商品適配度，再研究圖表；不適合的契約不因機會看似漂亮而例外。先被行情吸引才查規格，容易為了參與而合理化過大的一口

UNDERSTAND看得懂

知道標的、制度與主要風險。

ACCESS看得到

官方規格、即時資料與可靠連線。

AFFORD承受得起

最小一口通過壓力測試。

FLAT全部不通過

不選也是完整結果。

圖解｜選市場與合約 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

把會變動的外部事實在當天重新驗證

打開交易所與期貨商官方頁，核對商品代碼、月份、乘數、跳動、交易時段、最後交易日、結算、價格限制、保證金與最新公告；再比對模擬平台實際合約。 保存查閱日期與來源。若官方頁、期貨商畫面和自己的規格卡不一致，停止流程並向官方客服確認；不能選擇最有利於下單的那一個數字。

實際決策時，所有動態欄位必須是當日資料並可追溯，確認後才解鎖下一步。依賴上週的保證金與時段截圖，會在制度調整或到期週產生錯誤

BROKER期貨商規則

收取、風控與處理時點。

PLATFORM實際代碼

帳號環境、月份與即時資料。

MATCH三方一致

不一致則停止並查明。

03

CORE MODEL

先完成儀表板，再讓策略申請進場

記錄主要與背景尺度、結構、位置、波動、量與未平倉、基差、期限結構、活躍月份與事件。分開寫事實與假設，再將市場歸為趨勢、區間、轉換或不確定。 只有與狀態相容的策略可進入候選；若在區間中央、事件不可評估、資料延遲、流動性不足或人的狀態不佳，直接標記不交易。這不是錯過，而是拒絕沒有優勢的曝險。

實際決策時，設定一張『否決清單』，任何一項紅燈都比買賣訊號優先。先決定今天要做多再挑證據，會使儀表板變成確認偏誤工具

FACT市場事實

可觀察且含時間與月份。

HYPOTHESIS狀態假設

包含改判條件。

FIT策略相容

只保留與狀態匹配者。

VETO否決清單

事件、資料、流動性或人的紅燈。

圖解｜狀態與不交易判斷 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

把方向假設轉成完整的風險契約

選一種策略，寫背景、觸發、失效、理論進場、停損、目標、時間與事件退出。接著用每筆風險除以單口完整風險，向下取整口數，並檢查風險群組與帳戶壓力。 本章模擬例：若每筆預算 2,500，停損價格風險 2,000，成本與滑價 250，單口完整風險 2,250，可做一口；任何假設惡化使單口超過 2,500，答案改為零口。

實際決策時，計畫、算術與壓力測試全數簽核後，才允許打開模擬委託票。因為行情接近觸發就跳過壓力測試，會把速度置於帳戶安全之前

示例：⌊NT$2,500 ÷ NT$2,250⌋ = 1 口
若單口完整風險 > NT$2,500，則為 0 口
PLAN策略六欄

背景、觸發、失效、大小、管理、退出。

ONE RISK單口完整風險

價格、成本、滑價與緩衝。

SIZE向下取整

不可超過每筆與群組上限。

STRESS帳戶壓力

通過後才進委託階段。

圖解｜寫計畫與計算口數 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

按鈕只執行已批准的計畫，不在委託票上重新思考策略

核對模擬環境、帳號、商品、月份、方向、開平、口數、委託類型、價格與效期；口頭讀出後送單。記錄訂單編號與狀態，部分成交時依預案處理，不重複按送出。 成交後立即核對實際持倉、均價、滑價、未成交與保護性退出。若實際持倉和目標不同，停止新單並先降低意外曝險；未成交條件失效則取消。

實際決策時，用『計畫持倉—實際成交—目前持倉』三欄核對，全部一致才進管理。看到成交提示就離開畫面，可能漏掉剩餘委託、錯誤口數或沒有停損

READ BACK口頭覆誦

環境、合約、方向、口數、價格。

ORDER ID追蹤狀態

接受、排隊、部分、成交或拒絕。

POSITION持倉核對

實際均價與口數。

PROTECTION退出委託

數量、觸發與有效性正確。

圖解｜模擬送單與成交核對 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

盤中只執行預先定義的條件，不重新發明理由

監控策略失效、目標、時間、事件、流動性、保證金與熔斷；每次調整只能降低風險或依預定規則管理。不要因短期損益改變時間尺度、加碼邏輯或交易目的。 系統斷線、報價異常、未成交保護或意外事件都應有備援：保存期貨商官方電話、使用另一可靠連線並知道如何核對部位。備援是處理風險，不是趁亂建立新交易。

實際決策時，把所有允許的盤中動作預先列舉，清單外動作必須等到平倉後研究。虧損時把短線單改稱長線避險，會讓失效與退出失去邊界

INVALID假設失效

按計畫退出，不討價還價。

TARGET管理達標

固定、分批或追蹤依規則。

CIRCUIT熔斷

單日、連敗或操作錯誤立即停。

BACKUP系統備援

只核對與降低曝險。

圖解｜持倉管理 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

平倉送出不是結束，最終持倉與帳務一致才是

退出時追蹤委託直到全部成交，核對剩餘口數為零並取消相關保護單；若只部分退出，更新剩餘風險。跨日後以正式對帳單核對成交、手續、稅、每日結算與權益。 若策略要跨到下一月份，將舊約退出與新約建立視為兩筆獨立委託，記錄轉倉價差與成本。不要用連續圖隱藏真實成交，也不要讓期貨商被動替你決定到期處理。

實際決策時，完成『持倉零／未成交零／帳務已核對』三項才關閉交易。平倉後忘記取消停損單，後續觸發可能建立一個意外反向部位

EXIT FILL退出成交

部分或全部都要追蹤。

ZERO持倉與掛單

確認部位零、相關委託零。

STATEMENT正式對帳

成交、成本、結算與權益。

ROLL兩筆交易

舊約退出與新約建立分別紀錄。

圖解｜退出、對帳與轉倉 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

一筆交易在資料完整、過程評分與改善動作寫完後才結束

先封存事前計畫與圖，再填實際成交、最大有利／不利移動、成本、淨損益與 R；用好／壞過程和獲利／虧損四象限評分。改善只選一個具體流程變更。 累積 30 筆同版本模擬後，檢查遵守率、期望、回撤、連敗、滑價、最差交易與壓力測試。只有全部門檻通過、財務與心理也適合，才可另行考慮最低風險；繼續模擬或停止都是成功結果。

實際決策時，把是否轉實盤視為獨立決策，不由最近一筆獲利或完成課程自動觸發。課程看完就放大口數，等於跳過最重要的前向樣本與個人承受驗證

ARCHIVE封存事前資料

防止事後改寫理由。

GRADE過程四象限

先評紀律，再看結果。

IMPROVE一個具體動作

改流程，不改人格評語。

GATE獨立畢業決策

繼續模擬與停止都是有效。

圖解｜復盤與下一步門檻 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

全課最重要的能力

不是預測漲跌，而是在沒有足夠證據、口數為零或風險不可承受時，平靜地不交易。

DECISION REHEARSAL

把第 12 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「完成一筆期貨交易的全生命週期」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  1. 01

    判斷題從可理解、可觀察、可承受的商品開始，不合格就空手。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  2. 02

    判斷題所有動態規格在當日從交易所與期貨商重新核對。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題策略、口數、壓力與委託逐關通過，持倉中不臨時改寫理由。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  4. 04

    判斷題平倉後還要清除掛單、正式對帳與復盤；實盤永遠是獨立決策。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

從一個買賣念頭，變成可重複的完整生命週期

IMPULSIVE

看到機會就下單，賺賠後截一張圖；下一筆再調整。

DISCIPLINED

商品篩選、當日規格、狀態否決、策略六欄、口數壓力、模擬送單、持倉管理、退出對帳與復盤逐關通過；任何紅燈立即結束流程。

WHY IT MATTERS

交易被拆成可驗證的決策鏈，錯誤能被定位，風險能在建立部位前被拒絕。

CHECK YOUR MODEL

先回答，再展開。

整個流程第一個可以結束的位置在哪裡？

商品沒有同時通過可理解、可觀察與可承受時，就應直接空手結束。

為什麼規格要在交易當日重查？

保證金、時段、公告與到期處理可能變動，舊規格會導致真實操作錯誤。

送單前最後一個風險閘門是什麼？

口數、群組曝險與帳戶壓力測試全部通過，且沒有否決紅燈。

平倉成交後還要做什麼？

確認持倉與相關掛單為零、核對正式帳單，並完成日誌與過程復盤。

完成課程與 30 筆模擬是否必須實盤？

不必。轉實盤是另一次獨立風險決策，繼續模擬或停止期貨同樣合理。
