BUILD A LONG PLAN

做多策略的建立方式

做多策略不是『覺得會漲』，而是一份條件式計畫：什麼背景允許、哪個行為觸發、哪裡證明錯、可承受多少、如何退出。

95–120 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能設計突破、拉回與區間收復三種多方策略，並用同一套風險與模擬流程比較。

RISK BOUNDARY

以下是策略研究框架，不是當前市場建議。所有規則都要在指定商品與時間尺度重新測試，先模擬，結果不保證延續。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

可執行策略必須同時回答背景、觸發、失效、大小、管理與退出

背景說明何種市場狀態允許尋找多單；觸發是可觀察的進場事件；失效點說明原假設何時不成立；部位大小把價格距離換成帳戶風險；管理與退出則涵蓋獲利、時間與事件。 這六項缺一就不是完整策略。只有進場沒有失效，是看法；只有漂亮圖例沒有即時可辨識條件，是事後解說；只有勝率沒有成本與最大回撤，也不能評估。

實際決策時，把每條規則寫成可由另一個人依相同資料判斷的句子。使用『感覺強』『差不多站穩』等模糊字眼，會讓規則隨盈虧改變

REGIME背景

何種狀態才允許找多。

TRIGGER觸發

可觀察、可記錄的進場事件。

INVALID失效

證明原假設錯誤的位置。

RISK大小與退出

先定損失，再談報酬。

圖解｜策略的六個零件 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

突破策略假設市場從平衡轉向上方價格發現

先定義有效區間、壓力區與突破確認，例如收在區域上方、回測不破或成交活動改善。觸發不必越複雜越好，但要能排除單一瞬間刺穿。 失效可設在突破重新被市場拒絕、回到區間且無法收復的位置。追價距離過大會讓失效很遠，導致口數為零或報酬風險惡化，此時等待回測或放棄。

實際決策時，事前量出突破價到結構失效的距離，符合風險額度才允許送單。看到長紅後才把前方任何線稱為突破，會用結果反向創造設定

BASE明確平衡區

上下邊界在事前可辨識。

BREAK突破確認

接受在壓力區上方。

RETEST回測選項

以較小追價換取可能錯過。

FAIL跌回區間

多方價格發現假設失效。

圖解｜突破做多 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

拉回策略假設主要上升結構仍有效，短期回撤提供較佳位置

背景需先有上升結構與可辨識支撐區，拉回過程再觀察賣壓減弱、低點守住或重新轉強。單純價格比昨天低不是拉回策略，因為下降趨勢也會不斷創造更低價格。 失效點放在主要結構被破壞處，目標可先看前高再決定是否追蹤。若拉回波動劇烈、量價顯示市場已轉換，策略應取消而不是用『更便宜』加碼。

實際決策時，把『趨勢仍在』與『短期重新轉強』拆成兩個獨立條件。越跌越買會把尚未確認的下降趨勢誤包裝成多次拉回機會

TREND上升背景

高尺度結構仍未破壞。

PULLBACK回到參考區

位置改善但尚未觸發。

TURN重新轉強

買方證據出現才進場。

BREAK結構失效

不因價格更低而自動加碼。

圖解｜拉回做多 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

假跌破後收復，交易的是市場拒絕更低價格

價格短暫跌破區間下緣後重新站回，可能顯示下方沒有持續接受。策略需定義跌破幅度、收復條件與確認時間；並注意這也可能只是高波動噪音。 失效通常在再次跌破並被接受的位置，第一目標可參考區間中段或上緣。因為屬逆轉型策略，進場前更要限制口數並避免在重大事件中把劇烈震盪誤認為假跌破。

實際決策時，先標區間，再等待跌破與收復順序完整發生，不能事後補畫。看到任何下影線就做多，忽略位置、時間尺度與後續接受程度

RANGE事前區間

下緣需在事件前明確。

SWEEP短暫跌破

市場探索更低價格。

RECLAIM重新收復

拒絕下方的可觀察證據。

REFAIL再次失守

策略假設被否定。

圖解｜區間收復做多 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

相同策略可用不同委託，執行結果也不同

確認後市價進場重視參與但可能滑價；限價等待回測改善價格但可能錯過；停損觸發可自動化突破條件但遇跳空會偏離。委託選擇需和策略證據及流動性匹配。 記錄理論觸發價、送單時間、委託類型、實際均價與滑價，否則無法分辨策略無效或執行太差。任何未成交單在條件失效後都必須取消。

實際決策時，事前定義『沒成交怎麼辦』，禁止因錯過而追價超過最大容許距離。把錯過交易視為損失，會讓限價計畫在盤中變成無上限追價

CONFIRM等待證據

降低假訊號但進場較晚。

LIMIT等待價格

改善價格但可能沒有部位。

STOP ENTRY觸發跟進

跳空與滑價需預估。

CANCEL條件失效

未成交單也要有退出規則。

圖解｜觸發與委託設計 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

先用失效距離計算口數，再決定是否有交易

每筆可承受金額除以單口從進場到停損的完整損失，向下取整得到口數。若為零，代表帳戶、契約與策略距離不匹配；不能把停損移近到無意義位置只為得到一口。 退出可結合固定目標、分批、追蹤與時間停損，但每種方法都要事前定義。移動停損只為避免帳面獲利回吐，可能在正常回撤中過早出場；完全不移則可能失去已建立的風險報酬。

實際決策時，以 R 倍數記錄每次退出，分開統計各管理方法。在盤中根據盈虧隨意改目標，會讓策略無法被重複或評估

INVALID結構停損

價格證明多方假設錯。

1R每筆金額風險

含滑價與成本的估計。

SIZE向下取整口數

零口也是有效答案。

EXIT事前管理規則

目標、追蹤、時間或事件。

圖解｜停損、口數與退出 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

策略優勢無法取消跳空和流動性風險

財經數據、政策決議與假日可能讓價格跳過停損；做多也可能遭遇向下缺口。若策略不是專門研究事件，最保守做法是縮小、提前退出或空手等待。 留倉需額外計算極端跳空損失、保證金提高與下個可交易時點。事件風險不能用平常平均波幅代替，模擬中也要手動加入不利成交，避免平台給出過度理想結果。

實際決策時，在每筆計畫標示是否跨事件、跨盤與跨日，沒有勾選就不得留倉。因為停損已掛就安心過夜，忽略停損不保證成交價格

CALENDAR事件日曆

數據、決策、假日與到期。

GAP不連續價格

停損可能在更差位置成交。

BUFFER額外緩衝

口數與現金都需更保守。

FLAT空手等待

不確定事件不是必須參與。

圖解｜事件與隔夜規則 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

把策略當成待反駁的假設，而不是需要證明的信念

先以明確規則標記一段歷史樣本，再在未用於設計的資料或後續時間前向模擬。每筆都含真實成本與保守滑價，並記錄市場狀態、策略類型、觸發品質與是否違規。 比較的不只是淨利，也包括最大回撤、連敗、平均 R、尾端損失、交易頻率與可執行性。若稍微改一個參數結果就崩潰，策略可能只是過度擬合。

實際決策時，先寫規則並鎖定，再看未見樣本；失敗結果也完整保留。每次測試還要保存資料區間、契約月份、成本假設與程式版本，讓之後的自己可以重現同一份結果。反覆調參直到歷史曲線漂亮，會把噪音當成可重複優勢

DEFINE先固定規則

背景、觸發、失效與成本。

TEST開發樣本

找出明顯錯誤，不追求完美。

VALIDATE未見樣本

不再任意修改規則。

PAPER前向模擬

檢查執行、滑價與紀律。

圖解｜模擬與驗證 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

策略驗證底線

歷史回測與模擬都可能高估真實成果。沒有保證獲利的策略，也沒有義務把研究結果轉成實盤。

DECISION REHEARSAL

把第 8 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「做多策略的建立方式」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  1. 01

    判斷題完整策略包含背景、觸發、失效、大小、管理與退出。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  2. 02

    判斷題突破、拉回與收復交易不同的市場行為，不可混成事後故事。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題口數由失效距離與金額風險決定，零口代表不交易。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  4. 04

    判斷題用未見樣本與前向模擬反駁策略，所有成本和失敗都需保留。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

從『看漲』改成可反駁的多方策略

IMPULSIVE

價格很強，我覺得還會漲；先買一口，跌了再看。

DISCIPLINED

只有在指定尺度與狀態中，突破／拉回／收復的客觀觸發成立才進場；結構失效即退出，口數由金額風險向下取整，事件前依規則處理。

WHY IT MATTERS

方向意見被轉成能事前執行、事後統計，也能清楚判定錯誤的條件式假設。

PAPER-TRADE ASSIGNMENT

寫出一份完整多方模擬計畫

三種策略只選一種，不混合最佳部分。

  1. 01

    選定狀態與尺度說明為何策略和背景相容。

  2. 02

    定義觸發與失效使用可觀察、無模糊詞的條件。

  3. 03

    計算口數與退出加入成本、滑價與事件規則。

  4. 04

    收集十筆紙上樣本不改規則，完整保留未成交與虧損。

CHECK YOUR MODEL

先回答，再展開。

策略只有進場訊號夠嗎？

不夠，還需背景、失效、口數、管理、退出與成本。

拉回做多和越跌越買有何不同？

拉回需要主要上升結構仍在，且短期重新轉強；不是只因價格更低。

突破追價距離太大時怎麼辦？

等待回測、換較小契約或放棄；不能任意縮短結構停損塞入口數。

零口是計算錯誤嗎？

不是，表示在目前帳戶、契約與失效距離下沒有可接受部位。

回測漂亮是否足以實盤？

不足。還需未見樣本、含成本驗證、前向模擬與可承受的風險分布。
