MIRROR MECHANICS, DIFFERENT RISKS

做多與做空的完整比較

做多與做空的公式像鏡子，但市場行為不是鏡子。下跌常更急、空頭可能遭遇擠壓，多空都需要獨立的觸發、失效與退出設計。

85–110 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能列出多空相同的風控流程與不同的行情風險，並把同一市場看法分別寫成多方與空方計畫。

RISK BOUNDARY

本章比較策略結構，不主張任何方向較容易獲利。市場可能長時間不符合任一條件，空手是完整策略的一部分。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

多單買進建立、賣出結束；空單賣出建立、買進結束

對線性期貨而言，同樣大小的有利或不利點數，毛損益絕對值相同、符號相反。兩個方向都需要保證金、每日結算、成本、到期管理、成交核對與明確退出。 因此流程檢查表可以共用：合約、月份、口數、名目價值、失效點、單筆風險與最晚退出日都要填。唯有方向、觸發邏輯與部分風險情境不同。

實際決策時，先共用一套機械檢查，再為方向增加專屬情境。認為空單只是多單按相反按鈕，會漏掉擠壓、反彈速度與借用錯誤框架

LONG買進 → 賣出

上漲有利、下跌不利。

SHORT賣出 → 買回

下跌有利、上漲不利。

SAME共同流程

規格、口數、成本、到期與核對。

DIFFERENT專屬情境

速度、跳空、擠壓與市場狀態。

圖解｜對稱的機械結構 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

市場長期漂移與短期恐慌可能形成不同節奏

股票指數長期可能受經濟成長與企業盈餘推動而有上行漂移，但短期下跌常伴隨槓桿解除與流動性收縮，速度較快。這是常見特徵，不是每次都成立的規則，也不能直接變成交易訊號。 做多策略可能需要忍受緩慢整理；做空策略則常面臨快速下跌後急彈。停損距離、追蹤方式與持有時間應來自該方向實際分布，而不是把圖形上下翻轉。

實際決策時，分方向統計有利與不利移動的速度、幅度與跳空，不用印象決定。把『跌得快』誤解成追空一定容易，常在波動放大與流動性最差時進場

DRIFT慢速上行

可能伴隨長整理與回撤。

SELL-OFF快速下跌

去槓桿可放大速度。

REBOUND急速反彈

空單可能在短時間回吐。

MEASURE分方向統計

以樣本而非敘事設參數。

圖解｜不對稱的價格路徑 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

空單的虧損會在價格上漲時持續擴大

大量空單集中時，價格上漲可能迫使空方回補，而買回本身又推升價格，形成擠壓。政策消息、意外利多、流動性不足或突破關鍵區域都可能讓上漲加速。 期貨空單與放空股票制度不同，但方向性風險仍存在。不要因價格已跌很多就認為上方空間有限；空單也必須有預定失效點、最大滑價情境和緊急退出方式。

實際決策時，在空方計畫額外列出上方跳空、成交量急增與回補擁擠情境。攤平上漲中的空單，會在擠壓中同時增加口數與損失速度

CROWD空單集中

同方向部位形成潛在回補需求。

CATALYST意外利多

價格穿越空方失效區。

COVER被迫買回

回補訂單進一步推升。

LIMIT預先限損

不在擠壓途中增加口數。

圖解｜空頭擠壓與反彈風險 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

多方理由要由市場證據確認，而不是只因價格下跌

做多觸發可以是突破並站穩、上升趨勢中的拉回止穩，或區間跌破後重新收復。失效點應位於讓原始多方邏輯不成立的位置，而不是任意固定金額或『我不想再虧』的位置。 進場前先估停損距離再算口數。若合理失效點太遠導致零口可做，代表這個契約與帳戶不匹配；縮短停損只為塞進一口，會讓正常波動頻繁觸發。

實際決策時，用條件句寫：若證據 A 與 B 成立才進場；跌破 C 則邏輯失效。把『跌多了應該反彈』當成多方理由，沒有任何可驗證的狀態轉變

SETUP多方背景

趨勢、區間與事件允許。

TRIGGER買方證據

突破、止穩或收復。

INVALID多方失效

結構被破壞即退出。

SIZE依距離算口數

不能先決定一口再找停損。

圖解｜做多的觸發與失效 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

空方理由來自支撐失守或反彈失敗，而非單純覺得太高

做空觸發可包括區間下緣有效跌破、下降趨勢中反彈無法站回壓力，或向上假突破後重新跌回。失效點通常位於空方結構被否定的位置。 快速下跌後的新空單可能離合理失效點很遠，又面臨急彈。此時等待反彈、換較小契約或放棄，比追逐一根長黑線更符合風險報酬。

實際決策時，寫出你需要看見的賣方證據，以及哪個價格行為會證明判斷錯誤。因為新聞很壞就市價追空，常把已反映的恐慌當成新的優勢

SETUP空方背景

弱勢趨勢或區間破壞。

TRIGGER賣方證據

跌破、反彈失敗或假突破。

INVALID空方失效

站回關鍵結構並獲確認。

CHASE?距離過遠

寧可等待或不交易。

圖解｜做空的觸發與失效 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

相同點數不代表相同達標機率與滑價

同樣 50 點停損，在慢速上行與恐慌下跌中的觸發頻率、滑價和持有時間可能不同。策略參數要從該方向、該市場狀態的歷史模擬與前向觀察產生。 目標也要符合行情路徑：趨勢策略可分批或追蹤，區間策略則通常在對側壓力前管理。多空各自記錄最大有利移動、最大不利移動與達標時間，才能檢查是否真的需要不同規則。

實際決策時，分方向、分市場狀態建立統計，不共享未經驗證的固定停損。為了讓回測好看而事後替多空挑不同參數，會造成過度擬合

LONG DATA多方分布

回撤、延續、持有時間。

SHORT DATA空方分布

急跌、反彈、滑價。

REGIME狀態分組

趨勢與區間不能混算。

RULE事前固定

前向模擬確認，而非事後挑選。

圖解｜停損與目標不能只鏡像 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

相同方向，成功標準完全不同

持有股票組合者用指數期貨空單避險，目標是降低總組合下跌敏感度；期貨空單本身虧損，可能被現貨上漲抵銷，整體仍是成功避險。投機空單則要以自身風險報酬與規則判斷。 避險口數需估算現貨市值、beta 或敏感度、期貨名目價值與避險比例。完全對沖可能放棄上漲，也可能因基差與組合不匹配而不完全；不能把粗略口數稱為無風險。

實際決策時，避險日誌以總組合波動與目標曝險衡量，不只看空單盈虧。把虧損投機空單改名成避險，卻沒有任何對應現貨部位，是目的漂移

粗略避險口數 ≈（現貨市值 × 市場敏感度 × 目標避險比例）÷ 單口期貨名目價值
PORTFOLIO既有多方曝險

股票市值與市場敏感度。

HEDGE期貨空單

降低部分系統性方向風險。

BASIS不完全匹配

現貨組合與期貨標的走勢不同。

REVIEW看總組合

以風險下降而非單腿獲利評估。

圖解｜避險空單與投機空單 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

同一時刻可以同時沒有多方與空方優勢

建立左右兩欄：多方背景、觸發、失效、目標與風險；空方也填相同欄位。中間再加一欄『不交易』條件，例如位於區間中央、重大事件前、流動性不足或合理口數為零。 盤前填表，盤中只接受事先定義的條件，不能因第一個方向失敗就立刻反手報復。反手是新的交易，需要新的背景、觸發、風險計算與冷卻時間。

實際決策時，讓多、空、空手三個選項公平競爭，沒有證據就維持空手。預設今天一定要做一個方向，會把噪音硬解讀成訊號並提高交易頻率

LONG多方條件成立

按多方計畫與口數執行。

SHORT空方條件成立

按空方計畫並加入擠壓風險。

FLAT條件都不完整

空手是主動風控。

RESET方向失敗後

冷卻並重新評估，不自動反手。

圖解｜雙情境決策表 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

三個方向

交易者其實有多、空、空手三種選擇。第三種不會產生手續費，也不需要為了無聊承擔槓桿。

DECISION REHEARSAL

把第 6 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「做多與做空的完整比較」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  1. 01

    判斷題多空機械方向相反，規格、口數、成本與核對流程相同。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  2. 02

    判斷題價格路徑與流動性可能不對稱，參數必須分方向驗證。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題避險與投機即使方向相同，也有不同成功標準。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  4. 04

    判斷題多、空、空手是三個平等選項，反手必須視為新交易。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

從鏡像按鈕，改成兩套證據與一個空手選項

IMPULSIVE

覺得高就空、覺得低就多；停損和目標都設一樣，空單失敗就立刻反手。

DISCIPLINED

多空各自定義背景、觸發、失效與路徑風險；停損距離由結構決定，口數再由風險計算。兩邊都不完整就空手，失敗後先冷卻。

WHY IT MATTERS

機械計算保持一致，策略證據與風險分布則被獨立驗證，不再為交易而交易。

PAPER-TRADE ASSIGNMENT

完成多／空／空手三欄決策表

選同一個假設交易日，不能使用事後結果修改條件。

  1. 01

    填多方計畫背景、觸發、失效、退出與最大風險。

  2. 02

    填空方計畫加入擠壓、跳空與追價限制。

  3. 03

    填空手條件列出至少四個不交易理由。

  4. 04

    紙上演練各走一次獲利、停損與未成交路徑。

CHECK YOUR MODEL

先回答，再展開。

期貨多空的哪些部分是對稱的？

線性毛損益的點值、多數契約流程、保證金管理、成本、到期與成交核對。

為什麼策略規則不能只上下翻轉？

多空的價格速度、跳空、擠壓、流動性與達標時間分布可能不同。

空頭擠壓如何自我強化？

價格上漲迫使空方買回，回補買盤又推高價格，可能迫使更多空方退出。

避險空單該如何評估？

看整體組合曝險與波動是否降低，而不是只看期貨空單本身盈虧。

反手是否只是原交易的下一步？

不是。反手是新交易，需重新取得背景、觸發、失效、口數與退出條件。
