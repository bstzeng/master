READ THE REGIME

期貨價格結構與市場資訊

價格不是單獨一條線。期貨還有成交量、未平倉量、現貨基準、不同月份與訂單簿；把它們組合起來，才能描述市場此刻是趨勢、區間還是高波動失序。

95–120 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能建立市場狀態分類，解釋成交量與未平倉量的差別、計算基差，並辨識正價差、逆價差與轉倉風險。

RISK BOUNDARY

市場資訊只能形成假設，不能保證下一步。任何單一指標、價量組合或期限結構都不應被當成確定訊號。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

市場狀態是對價格行為的壓縮描述，不是永恆標籤

上升趨勢常呈現較高高點與較高低點，下降趨勢相反；區間則在可辨識上下邊界內反覆。真正困難的是轉換期：突破可能延續，也可能快速回到區間。 狀態判斷需指定時間尺度。同一市場在日線上升、60 分鐘整理、5 分鐘下降都可能同時成立；你的持有期間決定主要尺度，較高尺度只提供背景。

實際決策時，盤前用固定時間尺度寫出目前狀態與『何種證據會讓我改判』。價格一根長紅就把所有尺度改成上升，會讓狀態隨情緒來回翻轉

UP上升結構

高點與低點整體抬高。

RANGE區間平衡

上下邊界內反覆交易。

DOWN下降結構

高點與低點整體下移。

TRANSITION轉換期

突破需確認，失敗則回到原狀態。

圖解｜趨勢、區間與轉換 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

市場記憶不是一條精確到小數點的魔法線

前高低、成交密集區、缺口與區間邊界常形成參考區域，因為參與者在附近有部位與決策。價格可能穿越後收回，也可能在尚未觸及前提前反應，因此應用區域而非單點思考。 區域的用途是定義情境：接近區域後觀察接受還是拒絕，並將失效放在結構真正被否定的位置。線畫得越多，越容易事後找到一條解釋任何結果。

實際決策時，每個尺度只保留少數有明確來源的區域，記錄它如何被建立與何時失效。事後移動線條配合結果，會使任何策略都看似準確、卻無法前向執行

SOURCE區域來源

前高低、區間、成交密集或缺口。

APPROACH接近方式

速度、量能與波動提供背景。

RESPONSE接受／拒絕

以收復、站穩或失守確認。

INVALID區域失效

結構改變後刪除，不無限沿用。

圖解｜支撐與壓力是區域 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

相同的十點，在不同波動環境代表不同意義

波動度描述價格變動的幅度與分散程度。當波動上升，正常回撤、合理停損、滑價與保證金需求可能一起增加；若仍使用低波動時的固定點數停損，可能只是被日常噪音觸發。 可以用真實區間、歷史波動或簡單的近期平均波幅做相對比較，不必迷信單一指標。策略目標、持有時間與口數都應隨波動環境重新估算。

實際決策時，用『停損距離 ÷ 近期典型波幅』檢查規則是否在不同環境仍合理。波動變大時只把目標放遠、卻不縮小口數，會讓帳戶金額風險同步放大

LOW VOL壓縮

假突破與等待時間可能增加。

EXPANSION波動擴張

機會與滑價同時上升。

STOP結構＋尺度

不能只沿用固定點數。

SIZE波動高則縮口數

維持固定金額風險。

圖解｜波動度與交易尺度 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

一個描述交易活動，一個描述尚未沖銷的契約

成交量計算期間內成交的契約數，雙方每次成交都形成市場活動；未平倉量則是尚未以沖銷或到期結束的契約總量。成交量高不等於全部是新部位，也不能直接判定多方或空方較強。 價格上漲搭配未平倉量增加，可能表示新資金建立部位，但無法只靠這兩項得知誰會獲利；未平倉下降可能來自雙方平倉。它們是背景證據，需要和結構、月份移轉與事件一起讀。

實際決策時，觀察同一實際月份的價、量與未平倉，不混用連續合約或轉月資料。用『量大＝有人買＝一定漲』解讀，忘記每筆成交同時有買方和賣方

VOLUME期間成交量

衡量活動與流動性。

OPEN INTEREST未平倉量

尚未結束的契約總量。

PRICE方向與結構

提供市場接受的價格資訊。

CONTEXT月份與事件

轉倉會扭曲單月變化。

圖解｜成交量與未平倉量 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

期貨價格和現貨基準之間存在可變的差

基差可依市場慣例定義為現貨減期貨或期貨減現貨，使用前必須標明公式。本課程採期貨價減現貨價；正值代表期貨高於現貨，負值代表低於現貨。到期附近兩者通常受結算機制驅動而收斂。 避險成效取決於基差是否如預期變化。即使方向判斷正確，期貨與現貨走幅不同仍可能造成損益落差；不同現貨指標、交易時間與資料延遲也會影響計算。

實際決策時，在每個基差數字旁寫公式、資料來源、時間戳與可比性。引用別人的『基差擴大』卻未確認對方採用相反定義，會把方向整個讀反

本課程基差 = 期貨價格 − 現貨價格
使用任何資料前，先確認對方採用哪一種定義
SPOT現貨基準

需確認指標與時間。

FUTURES特定月份價格

不可用模糊連續價代替。

BASIS期貨 − 現貨

本課程採用的明確定義。

CONVERGE到期收斂

依最後結算制度連結。

圖解｜基差與收斂 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

不同月份價格排列，反映持有成本、供需與風險溢酬

遠月高於近月的排列常稱正價差結構，近月高於遠月則常稱逆價差結構；商品市場中倉儲、融資與便利收益會影響曲線，金融期貨也受利率、股息與預期影響。名稱不是買賣訊號。 持續持有時必須從舊月轉到新月，轉倉價差會影響總報酬。只看連續圖的方向而忽略每次換月，可能高估策略表現；歷史資料也需知道採何種調整方法。

實際決策時，同時畫出至少三個月份，記錄價格、量與未平倉，再描述曲線而非預測。看到逆價差就斷言一定缺貨或一定續漲，會把多重原因簡化成單一故事

NEAR近月

最接近到期，對現貨連結更直接。

FAR遠月

含更多時間與持有因素。

CURVE期限排列

正價差或逆價差是描述。

ROLL轉倉報酬

進出不同月份會產生價差。

圖解｜期限結構 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

螢幕上的最佳價只代表最前面的一小部分

買賣價差顯示立即成交的基礎成本，訂單簿深度顯示各價位可見數量；但可見委託可能取消，隱藏單與高速變化也使畫面不是保證。大單相對深度越大，平均成交價越可能偏離。 流動性有時間與狀態依賴：開收盤、事件、盤後、到期與極端行情都可能改變。回測若只用收盤價、沒有滑價模型，會高估實際可執行性。

實際決策時，記錄下單當時價差、前三檔深度與實際滑價，建立自己的執行資料。看到成交量很大就假設任何口數都能在最後價成交，忽略瞬間深度與市場衝擊

SPREAD買賣價差

立即進出最基本摩擦。

DEPTH可見深度

不同價位可供成交的數量。

IMPACT市場衝擊

訂單相對深度越大，偏離越高。

TIME時間依賴

盤別、事件與到期改變品質。

圖解｜流動性與訂單簿 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

把多個證據壓縮成可行動的狀態，而不是指標投票

一個簡潔儀表板可包含：主要尺度結構、目前位置、近期波動、成交量／未平倉變化、基差、期限結構、活躍月份與重大事件。每欄只寫觀察事實，再單獨寫假設。 最後輸出只能是趨勢策略候選、區間策略候選或不交易，而不是強迫每個指標給買賣分數。若證據衝突或資料品質不足，標示不確定並縮小風險或空手。

實際決策時，保留事前截圖與文字，盤後檢查狀態分類而非只檢查賺賠。把八個指標加權成一個漂亮分數，卻無法說明失效條件，會製造虛假精確

FACTS客觀觀察

價格、量、基差、期限與事件。

REGIME狀態假設

趨勢、區間、轉換或混亂。

FIT策略相容

只允許符合狀態的候選。

FLAT不確定

資料衝突時不必下單。

圖解｜市場狀態儀表板 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

儀表板不是預言機

它的價值是排除不相容的策略、定義改判條件，而不是把不確定性消成一個買賣分數。

DECISION REHEARSAL

把第 7 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「期貨價格結構與市場資訊」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

IMPULSE / DISCIPLINE

從單一指標，改成市場狀態敘述

IMPULSIVE

成交量放大，所以明天一定漲；我直接找買點。

DISCIPLINED

我先標示主要尺度結構、位置與波動，再記錄同月份成交量、未平倉、基差、期限與事件；證據若衝突，就歸為轉換或不確定。

WHY IT MATTERS

資訊用來限制可用策略與定義改判，不再假裝單一指標能確定未來。

建立一日市場狀態儀表板

    固定時間尺度選主要與背景尺度，不盤中任意更換。

  2. 02

  3. 03

CHECK YOUR MODEL

先回答，再展開。

同一市場可以同時有不同趨勢嗎？

可以，不同時間尺度可呈現不同結構；持有期間決定主要尺度。

成交量大是否代表買方較多？

不能這樣解讀，每筆成交同時有買賣雙方；成交量主要描述活動。

未平倉量與成交量有何不同？

成交量是期間成交數，未平倉量是尚未沖銷或到期的契約總量。

基差為何必須先寫公式？

市場慣例可能採現貨減期貨或相反定義，不標明會把擴大與縮小讀反。

期限結構名稱是否能直接交易？

不能。它是價格排列描述，成因與未來變化需結合供需、成本與風險。
