READ THE CONTRACT

讀懂一張期貨合約規格

合約規格就是期貨的使用說明書。只要月份、乘數或最小跳動看錯一欄，方向判斷正確仍可能得到完全不同的損益與風險。

75–95 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能從官方規格表計算名目價值與一個最小跳動的金額，辨識交易月份、時段、最後交易日與結算方式。

RISK BOUNDARY

本章引用的 TX 規格僅是查表示範，規則可能調整；實際交易前必須以臺灣期貨交易所與期貨商最新公告為準。

01

CORE MODEL

用固定順序掃描，避免只挑熟悉的欄位

一張規格表至少要找出：契約標的、報價單位、契約乘數、最小升降單位、可交易月份、交易時段、每日價格限制、最後交易日、最後結算價與交割方式。建議每次都用同一張檢查表逐欄勾選。 規格表不是開戶時看一次就結束。交易所可能因市場與制度調整規則，期貨商也可能設定更早的到期處理時間或更高保證金，所以每次換商品、換月份或準備留倉前都要重新核對。

實際決策時，先從官方頁面建立規格卡，再把券商畫面的合約代碼逐字對照。從社群貼圖或舊文章抄規格，可能在不知情下使用過時乘數、時段或風險措施

1標的與代碼

確認商品、交易所與契約月份。

2乘數與跳動

把報價變成真實金額。

3時間與到期

判斷能交易、需退出的時點。

4結算與限制

知道最終履約與市場風控規則。

圖解｜規格表閱讀順序 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

報價是一個數，乘數才把它變成金額

股價指數期貨通常以指數點報價；商品期貨可能以重量或容量的單位報價。契約乘數定義每一報價單位代表多少貨幣價值，因此相同的價格變動，在不同契約上會造成完全不同的損益。 名目價值可用期貨價格乘以契約乘數估算。它是理解曝險的起點，不等於你一定會損失全部名目價值；但只用保證金除以帳戶資金評估大小，也會嚴重低估部位對價格的敏感度。

實際決策時，同時記錄報價、乘數、名目價值與帳戶權益，才能看到有效槓桿。把『一口』當成固定風險單位毫無意義，因為不同契約的一口大小不同

名目價值 = 報價 × 契約乘數 × 口數

03

CORE MODEL

價格能走的最小格，決定每格盈虧

最小升降單位是合法報價的最小刻度。跳動價值通常等於最小升降單位乘以契約乘數；若價格從 100.0 到 100.5 而最小跳動是 0.5，便是一個跳動，不是 0.5 個任意單位。 停損與目標都要換算成跳動數和金額，再加上可能滑價。若每一跳的金額已超過你的單筆風險上限，正確選擇是更小型契約、調整策略或不交易，不能用『停損設近一點』硬塞。

實際決策時，把圖表距離先換成跳動數，再乘跳動價值與口數。只用百分比思考而忽略最小跳動，可能設定無法掛出的價格或錯估成本

每一跳金額 = 最小升降單位 × 契約乘數
價格風險 = 跳動數 × 每一跳金額 × 口數
TICK SIZE最小價格變動

合法報價的最小格。

TICK VALUE每格金額

最小跳動 × 乘數。

STOP失效距離

進場到停損共幾格。

RISK金額風險

格數 × 每格金額 × 口數。

圖解｜最小跳動與跳動價值 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

同一標的有一條由月份組成的時間軸

期貨代碼通常包含商品與到期月份資訊，畫面也可能顯示連續合約圖。連續圖便於觀察歷史，但它不是可直接下單的真實契約；下單時必須選定一個實際月份。 流動性常集中在近月或特定月份，但不能用習慣猜測。要觀察成交量、買賣價差與未平倉量，並留意市場是否正在轉移到下一月份。價格最接近不等於成本最低，價差與深度也要看。

實際決策時，在委託送出前把商品代碼與年月念一次，並與規格卡對照。看連續圖做決策、卻誤下遠月或即將到期月份，是典型操作風險

研究方便，但通常不能直接成交。

CONTRACT實際月份

每月是獨立可交易契約。

05

CORE MODEL

能看到價格，不代表此刻適合或可以成交

契約可能有一般交易時段與盤後交易時段，不同時段的參與者、流動性、事件風險與價格跳動可能不同。最後交易日也可能提早收盤，某些委託在跨盤別後不會延續。 留倉跨越收盤、國際數據發布或假日，會承擔無法即時退出的跳空風險。交易計畫需記錄進場盤別、預計持有時間、重大事件與最晚退出時點，不把『有夜盤』誤認為任何時候都有充分流動性。

實際決策時，用官方交易日曆與期貨商公告核對可交易時段和特殊休市。把手機 App 顯示的灰色價格當成可成交即時價，可能造成錯誤停損與追價

06

CORE MODEL

風控規則不能保證你能在想要的價位退出

交易所可能設定漲跌幅、動態價格穩定措施或其他風險措施。價格到達限制時，市場仍可能只有單邊委託，停損單並不能保證成交；下一時段開盤也可能直接跳過你的停損價。 現金結算通常依指定的最後結算價計算差額，實物交割則涉及標的交付。即使初學者只做現金結算商品，也要知道最後結算價可能不是自己最後看到的成交價，並避免在不了解規則時留到到期。

實際決策時，把價格限制視為『可能無法退出』的壓力情境，而不是最大損失保證。以為有漲跌幅就不會損失更多，忽略跨日、跳空與強制平倉價格的不確定性

CASH現金差額

DELIVERY實物交割

涉及交付資格、時點與程序。

CORE MODEL

用真實頁面練習，但把日期一起記下來

以臺灣期貨交易所 TX 規格頁查閱示範：頁面列出以臺灣加權股價指數為標的、每點新臺幣 200 元、最小升降單位 1 點、現金交割，以及交易月份、時段與到期規則。這些是課程查閱當下的官方資訊，不是永久常數。 假設報價 20,000 點，一口名目價值是 20,000 × 200 = 4,000,000 元；價格移動 50 點，單口毛損益變化為 10,000 元。這個算例只教換算，不代表行情預測、建議口數或當前保證金。

08

CORE MODEL

不要背一堆數字，要建立可更新的查閱流程

一張好規格卡包括官方來源、查閱日期、商品與月份、報價單位、乘數、跳動、時段、最後交易日、結算、價格限制、目前活躍程度與期貨商特殊規則。每一筆數字旁都要能追溯來源。 規格卡完成後，用三個假設價格變化做心算與試算表驗證，再和模擬平台盈虧欄比對。若結果不同，先停止操作並找出是乘數、方向、口數、費用或幣別哪一項錯誤。

實際決策時，把『查表—手算—平台核對』變成每個新商品的入場門檻。依賴記憶或只抄別人的摘要，會在規則更新時失去警示

DECISION REHEARSAL

把第 2 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

CHECK YOUR MODEL

先回答，再展開。

為什麼只知道保證金仍無法判斷一口有多大？

因為曝險由報價、乘數與口數形成的名目價值及價格敏感度決定。

最小跳動和每點價值一定相同嗎？

不一定。每一跳金額要用最小升降單位乘以契約乘數計算。

連續合約圖可以直接下單嗎？

通常不行；它是拼接研究資料，下單必須選實際契約月份。

價格限制是否保證停損成交？

不保證。單邊市場、排隊與跳空都可能讓成交遠離停損觸發價。

規格卡為何需要查閱日期？

交易所與期貨商規則會調整；日期能提示資料是否過時並支援重新驗證。
