FROM TICKET TO FILL

期貨交易介面與完整訂單流程

交易介面只是把契約指令送進市場。真正重要的是你能否在按下送出前，辨識商品、月份、方向、開平、口數、價格、委託效期與最壞結果。

80–105 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能從報價到成交逐步解釋訂單生命週期，區分市價、限價、停損與停損限價，並完成一張模擬委託單。

RISK BOUNDARY

不同期貨商的按鈕名稱、開平倉處理、委託效期與風控不同。本章只教共同模型；操作真實介面前必須閱讀該平台說明並先用模擬環境驗證。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

先辨識資料，再辨識能改變帳戶的控制項

常見介面可拆成報價區、委託區、未成交區、持倉區與帳戶區。報價顯示市場狀態；委託區建立指令；未成交區可取消或改單；持倉區顯示已成交曝險；帳戶區顯示權益、保證金與可用餘額。 畫面上同時出現很多數字時，先確認資料時間戳與契約月份。持倉損益不是唯一風控指標，還要核對口數、平均價、可用餘額與是否有未成交停損；切換帳號或模擬／實盤環境後再次確認。

實際決策時，把介面分區畫在紙上，任何按鈕都先回答它會建立、修改或取消什麼。在未辨識帳號、月份與持倉時快速連點，可能留下重複委託或反向新倉

QUOTE報價

時間、買賣價、量與契約月份。

ORDER委託

方向、口數、價格與效期。

POSITION持倉

已成交曝險與平均價。

ACCOUNT帳戶

權益、占用與可用資金。

圖解｜介面的五個區塊 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

買與賣描述方向，開與平描述部位變化

沒有部位時買進通常建立多單，賣出通常建立空單；已有多單後賣出同商品同月份可減少或結束多單，已有空單後買進則可回補。某些市場或平台採淨額處理，某些介面要求明確選開倉或平倉。 因此『按反向』不一定只是退出：月份、口數或帳戶選錯，都可能建立新曝險。送單前先寫目標持倉，例如目前 +2、賣出 1 後應為 +1；成交後立即用實際持倉核對，而不是只看委託成功提示。

實際決策時，每次下單先寫目前持倉、委託動作與預期持倉三個數字。把送出成功當作平倉完成，忽略未成交或部分成交，會留下意外曝險

預期持倉 = 目前持倉 + 已成交買進口數 − 已成交賣出口數
NOW目前持倉

+2 多單、-1 空單或 0。

ACTION委託變化

買進增加、賣出減少，依淨額規則。

FILL實際成交

可能零、部分或全部。

AFTER成交後持倉

必須與交易計畫一致。

圖解｜買賣、開倉與平倉 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

成交確定性和價格控制之間存在交換

市價單優先追求成交，但實際價格取決於當時訂單簿深度，快速或流動性差的市場可能產生明顯滑價。限價單設定最差可接受價格，但市場沒有碰到或排隊未輪到時可能完全不成交。 選委託類型要由任務決定：緊急退出重視降低剩餘曝險，耐心進場可重視價格；不能為避免小幅滑價而讓失效部位繼續暴露，也不能為了保證成交在薄市場無限制追價。

實際決策時，事前定義優先級：我要價格控制、立即成交，還是兩者在一定範圍內折衷。把市價單誤認為『以畫面最後價成交』，或把限價單誤認為『一定會成交』

MARKET成交優先

價格不保證，可能跨越多檔。

LIMIT價格優先

不接受更差價格，但可能不成交。

DEPTH訂單簿

可成交量決定滑價。

PURPOSE依任務選擇

進場、退出與緊急風控不同。

圖解｜市價與限價 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

觸發條件和成交方式是兩個不同問題

停損委託在價格達到觸發條件後，轉成平台規定的後續委託；若轉為市價，成交機率較高但價格不保證。停損限價在觸發後只接受限價範圍，價格可控但劇烈穿越時可能完全留在市場中。 還要確認觸發依據是成交價、買價、賣價或其他價格，以及委託保存在交易所、期貨商伺服器或本機。斷線、休眠與跨盤別是否仍有效，不能靠直覺。

實際決策時，在模擬環境測試一次觸發、部分成交、跳空與取消流程，記下平台實際行為。把停損當作最大損失保證，或把觸發價與可成交價混成同一個數字

TRIGGER觸發條件

依平台指定的價格來源判斷。

MARKET STOP觸發後求成交

可能有大幅滑價。

STOP LIMIT觸發後限價

可能完全無法退出。

HOSTING委託保存位置

斷線與跨盤有效性要查清。

圖解｜停損與停損限價 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

送出之後，訂單還可能經歷多種狀態

委託可能是待送出、已接受、排隊中、部分成交、全部成交、已取消、被拒絕或已失效。改價有時等同取消舊單再送新單，會失去原排隊順位；網路延遲也可能讓畫面狀態落後。 每次取消或改單後，都要等系統回報最終狀態再做下一步。若在不確定時連續重送，原單可能剛好成交，新單又建立額外部位。緊急時依事先記錄的官方客服與備援方式處理。

實際決策時，以訂單編號追蹤每次狀態改變，成交回報才是部位變化的依據。看到畫面卡住就重複按送出，是造成重複部位最常見的人為錯誤之一

SUBMIT送出

取得訂單編號與時間。

ACCEPT接受／拒絕

檢查錯誤原因，不盲目重送。

PARTIAL部分成交

剩餘數量仍可能繼續成交。

FINAL成交／取消

最後再核對持倉與未成交。

圖解｜委託生命週期 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

同一張單在不同時間可能有不同命運

委託可能只在當日有效，也可能有立即成交否則取消、全部成交否則取消等條件。一般盤與盤後盤是否共用委託、收盤後未成交單如何處理，都依市場與平台規則。 盤後或重大事件前後，買賣價差可能擴大、深度下降；一張平常可輕易成交的市價單，可能吃掉多個價位。使用即時報價與訂單簿也要確認資料權限及延遲。

實際決策時，在交易計畫寫出委託效期、取消時點和最大可接受滑價。把白天的流動性假設搬到盤後，會低估進出成本與停損偏離

DAY當日有效

收盤後是否取消要查平台。

IOC立即部分成交

剩餘數量取消。

FOK全數立即成交

否則整筆取消。

SESSION盤別差異

深度、事件與資料延遲不同。

圖解｜盤別、效期與流動性 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

交易流程必須有時間出口

每個部位都應設定最晚處理日，早於交易所最後交易日與期貨商限制。若要延續策略，先判斷新月份的流動性與價差，再分別處理舊約與新約；轉倉後平均價與損益基準必須重新記錄。 每天收盤前做『三方核對』：持倉、未成交委託、帳戶權益。若發現月份、方向或口數不符，先停止新策略，依風控順序降低意外曝險並聯絡期貨商，不能用另一筆猜測性的單試圖攤平。

實際決策時，把到期日與個人最晚處理日放進日曆，設定兩次提醒。把期貨當永久持倉，或以為平台一定會自動轉倉，都可能導致非預期結算

T-10開始觀察轉月

量、價差與未平倉量移轉。

T-5完成決策

平倉、轉倉或依規則到期。

BROKER確認更早限制

期貨商可能提前停止新倉。

RECONCILE每日三方核對

部位、委託、權益完全一致。

圖解｜到期、轉倉與意外持倉 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

把交易理由與機械指令放在同一張票上

模擬委託票分兩半：上半是策略條件，包括市場狀態、進場觸發、失效點、最大風險與退出規則；下半是執行欄位，包括帳號環境、商品、月份、方向、開平、口數、委託種類、價格與效期。 送出前做口頭核對，成交後記錄訂單編號、時間、成交均價與滑價；立即確認保護性退出是否存在且數量正確。若任何欄位無法回答，取消這次練習，補足資料再開始。

實際決策時，把完整委託票在紙上走讀兩次，再進模擬平台送出一口假設單。先按按鈕、成交後才補理由，會讓每次結果都無法重複與檢驗

PLAN策略半部

狀態、觸發、失效、風險、退出。

TICKET指令半部

合約、方向、數量、價格、效期。

FILL成交紀錄

時間、均價、滑價與部分成交。

PROTECT成交後核對

持倉與退出委託數量一致。

圖解｜完整模擬委託票 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

模擬環境也要認真

模擬成交可能比真實市場理想，尤其在排隊與滑價上。目的是練流程，不是證明策略已能獲利。

DECISION REHEARSAL

把第 4 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「期貨交易介面與完整訂單流程」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

IMPULSE / DISCIPLINE

從『按下買進』升級成可稽核的訂單流程

IMPULSIVE

看到突破就按市價買進，成交後再想停損；要平倉時直接按賣出。

DISCIPLINED

送單前核對帳號、商品、月份、方向、目標持倉、失效與口數；選擇符合任務的委託類型，成交後核對持倉、未成交與保護性退出。

WHY IT MATTERS

每一次點擊都有預期狀態與驗證點，能阻止重複下單、月份錯誤與沒有退出的裸露部位。

PAPER-TRADE ASSIGNMENT

走完一張模擬委託票

全程使用模擬帳戶，不追求盈虧。

  1. 01

    填策略半部先寫狀態、觸發、失效、風險與退出。

  2. 02

    填指令半部核對環境、月份、方向、口數、價格與效期。

  3. 03

    模擬成交記錄訂單狀態、部分成交與滑價。

  4. 04

    三方核對持倉、未成交與權益一致後才結束。

CHECK YOUR MODEL

先回答，再展開。

送出成功是否代表已成交？

不代表。委託可能排隊、部分成交、被拒絕或取消，部位要以成交與持倉核對。

市價單保證什麼？

通常優先追求成交，不保證成交價；深度不足時會有滑價。

停損限價最大的操作風險是什麼？

價格穿越限價範圍後可能無法成交，部位繼續留在市場。

反向委託一定是平倉嗎？

不一定。月份、口數或開平欄位錯誤可能建立新曝險，需看成交後持倉。

轉倉是一筆免費延長嗎？

不是。它包含平舊約與開新約的決策，會產生價差、成本和執行風險。
