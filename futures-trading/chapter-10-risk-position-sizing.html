SURVIVE THE DISTRIBUTION

停損、部位大小與帳戶風險

風險管理不是替預測加一個停損，而是先決定帳戶可以承受多少錯誤，再讓口數、停損、事件與總曝險全部服從這個限制。

105–135 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能用每筆風險計算口數，區分四種停損，設計單日／單週熔斷與組合曝險上限，並完成壓力測試。

RISK BOUNDARY

任何百分比都不是通用建議。風險上限必須依財務責任、經驗、商品波動與最壞情境保守設定；損失仍可能超過停損估計。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

先從帳戶可承受的金額出發，不從想買幾口出發

每筆風險預算可用帳戶權益乘一個保守比例估計，但比例只是上限，仍要受商品跳動、事件與組合曝險限制。新手在模擬階段也應使用固定風險模型，避免因為是假錢就建立不可能實盤執行的習慣。 風險預算包含進場到合理失效點的價格損失、預估手續與稅費、正常滑價，以及必要的跳空緩衝。若任何一項未知，先使用更保守估計或不交易。

實際決策時，在看報酬目標之前，先寫出這筆最願意承擔多少帳戶金額。把停損點數乘口數後剛好等於上限，卻沒有留成本和滑價，會系統性超額

每筆風險預算 = 帳戶權益 × 個人風險率
EQUITY帳戶權益

風險預算的基礎，不含借貸期待。

RATE個人風險率

上限而非必須花完的額度。

COST完整摩擦

手續、稅與滑價都納入。

BUFFER尾端緩衝

隔夜與事件需額外保守。

圖解｜每筆風險預算 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

02

CORE MODEL

策略決定停損距離，風險預算決定可做口數

先找出使交易假設不成立的價格，計算進場到停損的跳動數；單口完整風險等於跳動數乘每跳價值，再加單口預估成本與滑價。風險預算除以單口風險後向下取整。 例：預算 3,000 元，單口價格風險 2,400 元、成本滑價估 300 元，完整單口 2,700 元，只能一口；若完整單口 3,200 元，答案是零口。向上取整等於主動超額。

實際決策時，固定停損的結構意義，再向下取整口數；不能交換順序。先決定兩口後把停損壓近到符合預算，會讓策略在正常波動中失效

單口完整風險 = 停損跳動數 × 每跳價值 + 單口成本與滑價
口數 = ⌊每筆風險預算 ÷ 單口完整風險⌋
INVALID結構失效

先決定合理停損位置。

ONE CONTRACT單口完整風險

跳動價值＋成本＋滑價。

BUDGET每筆上限

帳戶可承受金額。

FLOOR向下取整

零口表示這次不交易。

圖解｜用失效距離算口數 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

價格停損只是其中一層，時間、波動與行為也能使交易失效

結構停損在市場證明假設錯誤時退出；波動停損把正常波幅納入距離；時間停損在預期行為未於期限內發生時退出；事件停損則在不願承擔的公告或收盤前主動處理。 這些規則可以組合，但不能互相矛盾。價格尚未觸及、時間條件先到，就按時間退出；事件前規定空手，就不能因目前小虧臨時改成留倉。停損只降低風險，不保證成交價格。

實際決策時，為每筆交易指定主要停損與所有提前退出條件，盤中不任意放寬。把停損往不利方向移動，稱作給市場空間，實際上是增加未預算損失

STRUCTURE結構停損

原始市場假設被否定。

VOLATILITY波動停損

避免停在一般噪音內。

TIME時間停損

預期催化未在期限內出現。

EVENT事件退出

不承擔無法估計的跳空。

圖解｜四種停損 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

好看的目標比例必須搭配達標分布

預計報酬風險比把目標淨利除以停損淨損，但不包含達標機率。策略可能常到停損、偶爾大賺，也可能常小賺、偶爾跳空大虧；需要勝率、平均輸贏、尾端與成本共同形成期望。 用 R 標準化每筆結果：按計畫停損約 -1R，獲利可能 +0.7R、+2R；若滑價造成 -1.4R，不能硬改成 -1R。實際 R 分布能揭露執行與尾端風險。

實際決策時，同時報告平均 R、最大虧損 R、連敗與樣本量，不只報勝率。把目標畫到很遠得到 5:1，卻從未檢查價格是否常到達，是虛構報酬

PLAN R預計結構

目標與停損的含成本比例。

ACTUAL R實際結果

以真實成交與成本計算。

DISTRIBUTION結果分布

平均、尾端、連敗與回撤。

EXPECTANCY長期估計

須有一致規則與足夠樣本。

圖解｜報酬風險與期望值 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

阻止情緒和市場失配把單筆損失變成連鎖反應

單日熔斷可用累計損失 R、連續虧損筆數、嚴重違規或系統異常觸發；單週熔斷則處理較長的策略失配。觸發後停止新倉，只允許降低既有曝險與保存資料。 熔斷門檻要在平靜時設定，不能虧損後臨時延長。停下來不是認輸，而是把有限樣本交給復盤；若策略確有優勢，明天仍存在，不必在疲勞狀態證明自己。

實際決策時，把熔斷做成介面旁的實體卡，觸發後登出並執行固定冷卻流程。每次接近上限就提高上限，會讓『日限損』變成沒有約束的裝飾

DAILY單日損失上限

以 R 與金額雙重監控。

STREAK連敗上限

避免報復交易與狀態失配。

ERROR操作異常

重複單、斷線或資料延遲即停。

RESET冷卻與復盤

隔日也需通過重新開機檢查。

圖解｜單日與單週熔斷 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

不同商品名稱不代表真正分散

同時持有股價指數多單、相關產業期貨與高 beta 現貨，可能本質上都是同一個風險因子。壓力時相關性常上升，多個看似獨立的停損可能同時被觸發。 建立風險群組，把部位按股票、利率、美元、能源等主要因子歸類，計算同方向總名目價值與總停損風險。個別交易都在上限內，不代表合計安全。

實際決策時，新單送出前先問：它增加哪個既有風險因子，群組壓力損失是多少。用三個高度相關商品各冒 1R，卻宣稱單筆只風險 1R，實際可能同時損失 3R

GROUP風險因子

依共同驅動而非商品名稱分組。

DIRECTION淨方向

多空可能抵銷，也可能基差失配。

STRESS同時不利

用相關性上升情境計算。

CAP群組上限

新單必須通過總曝險檢查。

圖解｜相關性與組合曝險 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

07

CORE MODEL

可用餘額不是可自由花完的風險額度

隔夜部位面臨跳空、保證金提高、盤後流動性與無法即時聯絡等風險。個人安全緩衝應高於最低保證金，並以壓力損失後仍能主動減倉為目標。 現金緩衝也不能來自信用借款或生活預備金。若需要靠隔日轉帳才能避免追繳，代表部位已把流動性需求外包給一個可能來不及的流程。

實際決策時，把壓力後可用餘額列為硬性門檻，低於門檻就於收盤前縮小或退出。看到帳戶仍有正權益就認為安全，忽略可用餘額和外部風控會先限制行動

GAP LOSS跳空損失

遠於停損成交的尾端情境。

MARGIN+保證金提高

相同部位占用更多資金。

LIQUID可用緩衝

壓力後仍能自主處理。

NO DEBT不用借款

風險資本與生活資金完全分離。

圖解｜隔夜現金緩衝 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

08

CORE MODEL

把多項壞事同時發生，而不是一次只測一項

建立正常停損、兩倍正常波動、極端跳空、價格限制與保證金提高五個情境；對所有相關部位同時套用，計算總損益、期末權益、保證金占用與可用餘額。 再做反向檢查：假設網路斷線、停損未成交、期貨商先平倉哪一個部位。若結果不可接受，降低總口數、取消隔夜或不交易；不能用更高勝率假設覆蓋壓力缺口。

實際決策時，每次新增部位或保證金公告變動後重跑，保存版本與決策。分別測每一口都安全，卻沒有測相關部位同時惡化，會漏掉帳戶層級風險

PRICE價格壓力

停損、兩倍波動與極端跳空。

LIQUIDITY成交壓力

滑價、未成交與價格限制。

FUNDING資金壓力

保證金提高與可用餘額。

OPERATION操作壓力

斷線、錯單與強制平倉順序。

圖解｜完整帳戶壓力測試 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

壓力測試的答案可以是零口

模型不是用來批准每一筆交易，而是讓不可承受的部位在進場前被拒絕。

DECISION REHEARSAL

把第 10 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「停損、部位大小與帳戶風險」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  2. 02

    判斷題合理停損先決定，口數再由預算向下取整。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題單日熔斷與風險群組阻止錯誤在時間與部位間擴散。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

從固定一口，改成帳戶可生存的部位

IMPULSIVE

這個商品大家都做一口，我也做一口；停損設 50 點，今天輸了再做一筆賺回來。

DISCIPLINED

我先定每筆與每日上限，從結構停損換算單口完整風險並向下取整；再檢查相關曝險、跳空、保證金提高與熔斷，零口就取消。

WHY IT MATTERS

部位大小不再由習慣或最低保證金決定，連續錯誤也有明確斷路器。

CHECK YOUR MODEL

先回答，再展開。

口數為什麼必須向下取整？

因為任何零頭向上都會超過既定風險預算；零口是有效結果。

結構停損和時間停損有何不同？

前者因價格證明假設錯誤，後者因預期行為未在期限內發生。

個別交易都在 1R 內，帳戶就安全嗎？

不一定；相關部位可能同時虧損，需看群組與總帳戶壓力。

日熔斷觸發後可以做什麼？

停止新倉，只降低既有曝險、保存資料並執行固定冷卻與復盤。

為何現金緩衝不能用生活預備金？

期貨損失不能危及房租、債務與家庭責任；風險資本必須完全分離。
