BUILD A SHORT PLAN

做空策略的建立方式

做空不是把多方圖表倒過來。下跌可能很快，追空位置很差；反彈也可能因擠壓而猛烈。空方策略因此更需要等待、失效點與流動性計畫。

95–120 分鐘8 個完整段落公式＋案例＋作業先模擬

LEARNING OUTCOME

讀完後，你能設計跌破、反彈失敗與假突破反轉三種空方策略，並處理擠壓、跳空、避險與退出。

RISK BOUNDARY

空方範例不是看空任何市場，也不是當前訊號。期貨空單有槓桿且上漲會造成損失，極端行情可能遠超預設停損。

模擬優先案例為假設，不是即時交易建議停損不保證成交價損失可能超過初始保證金

01

CORE MODEL

空方也必須由背景、觸發、失效、口數、管理與退出組成

下降結構或區間破壞只是背景，不能直接等同下單。需要一個可觀察的賣方觸發，並定義哪個價格行為證明供給假設錯誤；口數仍由可承受金額與停損距離決定。 空方還要加兩個專屬欄位：上方擠壓情境與追價限制。因為快速下跌後合理失效點可能很遠，錯過一筆比在最差位置建立過大曝險便宜。

實際決策時，在一般六欄之外，額外填寫最大追價距離與上方跳空壓力損失。因為空方行情快就省略計畫，會讓速度成為違規交易的藉口

REGIME空方背景

下降、區間破壞或轉弱。

TRIGGER賣方證據

跌破、反彈失敗或假突破。

INVALID空方失效

重新接受上方價格。

SQUEEZE專屬壓力

跳空與回補加速的最壞路徑。

02

CORE MODEL

跌破交易的是市場接受更低價格，而非一瞬間刺穿

先建立清楚支撐或平衡區下緣，再定義有效跌破，例如收在區域下方、反彈無法收復或成交活動支持。若只用單一觸價，容易在假跌破中進場。 失效通常在重新站回原區間並被接受的位置。若觸發後已快速遠離，下單的停損距離與滑價都惡化，應等待回測或取消，而不是因害怕錯過追空。

實際決策時，先量下緣到失效區距離並設定最大追價，超過就不送單。看到破底才事後把附近低點稱為支撐，無法形成可前向測試的規則

BASE明確支撐

事前可辨識的平衡下緣。

BREAK接受更低

不只瞬間觸價。

RETEST反彈失敗

提供較可控的進場位置。

RECLAIM重返區間

空方突破假設失效。

圖解｜跌破策略 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

03

CORE MODEL

下降趨勢中的反彈提供靠近失效區的觀察位置

背景是主要下降結構仍有效，價格反彈到先前支撐轉壓力、下降趨勢區或成交密集區後，出現無法繼續上行的賣方證據。它不是因為價格『反彈夠多』就自動放空。 失效設在下降結構真正被破壞處，目標可先看前低或依趨勢追蹤。若反彈放量站穩壓力，空方背景可能已轉換，不能把停損不斷上移。

實際決策時，區分『到達觀察區』與『出現反轉觸發』，兩者缺一不進場。只因價格比低點高就空，可能在真正趨勢反轉的早期持續逆勢

DOWNTREND下降背景

高點與低點整體下移。

RALLY回到觀察區

位置較好但不是訊號。

REJECT反彈失敗

賣方證據恢復。

BREAK UP站穩壓力

下降假設需撤銷。

圖解｜反彈失敗 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

04

CORE MODEL

向上突破失敗後跌回區間，交易市場拒絕更高價格

先有明確區間上緣，價格向上探索後無法維持，再跌回並確認，才形成空方候選。策略本質是失敗的上方價格發現，不是看到長上影線就猜頂。 失效通常在再次站回突破區並被接受，目標可分別參考區間中段與下緣。事件行情可能在兩邊快速掃動，因此口數與滑價假設要比平常保守。

實際決策時，把原區間、突破、失敗、跌回的順序寫成四個可觀察事件。用事後最高點畫線再宣稱假突破，會忽略當下根本沒有可交易定義

RANGE事前上緣

必須在突破前就存在。

BREAK UP探索上方

多方嘗試價格發現。

FAIL無法維持

重新跌回區間。

REACCEPT再次站回

空方反轉假設失效。

圖解｜假突破反轉 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

05

CORE MODEL

空方最壞路徑不一定是緩慢上漲

意外利多或擁擠回補可讓價格快速上跳，多張停損同時觸發又增加買盤。停損市價可能大幅滑價，停損限價則可能不成交；兩者都沒有消除風險。 壓力測試至少加入正常停損、向上跳空與價格限制三種路徑。若任一路徑會讓帳戶失去主動管理空間，應縮小口數、避免跨事件或完全不做。

實際決策時，空單計畫額外估計『停損價上方再跳一段』的成交與權益。因為理論上有停損就以正常損失估口數，會忽略空頭擠壓的尾端風險

NEWS意外催化

價格跳過預定失效區。

COVER回補買盤

擁擠部位自我強化。

SLIP成交偏離

市價停損可能付出大代價。

NO FILL限價未成交

空方曝險仍完整存在。

圖解｜擠壓與跳空管理 依序核對四個節點；任何一格無法回答，就先停止並補齊資料。

06

CORE MODEL

空方進場速度快，更需要在盤前完成算術

先由結構失效距離估計單口損失，再用每筆風險向下取整口數，並加入上方跳空緩衝。若價格已遠離觸發導致口數變零，取消交易，不把停損壓回沒有結構意義的位置。 退出可在前低、區間下緣分批，也可依下降結構追蹤；但價格快速下跌後反彈同樣快，預先定義部分獲利、追蹤距離與時間退出能降低臨場改規則。

實際決策時，空方委託票先算口數與追價上限，觸發時只執行已通過版本。行情開始才打開計算器，容易因速度而跳過成本、滑價和口數檢查

STOP DIST結構距離

進場到空方失效區。

GAP BUFFER上方緩衝

壓力情境納入口數。

SIZE向下取整

零口即取消。

COVER PLAN回補規則

目標、追蹤與時間退出。

07

CORE MODEL

避險目標是降低總組合敏感度，不是讓期貨腿單獨賺錢

持有多方現貨組合時，可用相近指數期貨空單降低部分市場曝險。口數須依現貨市值、beta 或風險敏感度、期貨名目價值與目標避險比率估算。 避險仍有基差、標的不匹配、轉倉、成本與再平衡風險。市場上漲時空單虧損可能被現貨獲利抵銷，不能因空單紅字就自動拆掉；成功標準要用總組合風險判斷。

實際決策時，事前寫目標曝險範圍與再平衡門檻，避免盤中依空單盈虧改變目的。沒有現貨敏感度計算就用整數口數完全對沖，可能反而形成淨空曝險

EXPOSURE估計現貨敏感度

市值、beta 與集中度。

RATIO目標避險比率

不必預設 100%。

FUTURES換算空單口數

用單口名目價值向下調整。

REBALANCE定期重估

價格與組合改變後口數需更新。

08

CORE MODEL

把最糟的快速反彈放進樣本，而不是當成例外刪除

空方回測要保留跳空、停板、重大消息與流動性惡化期間，使用保守成交模型。分開比較跌破、反彈失敗與假突破，避免把三套進場混成一條漂亮權益曲線。 前向模擬記錄追價取消率、停損滑價、最大有利後回吐與空方擠壓。若策略只在排除危機時期後才有效，就沒有回答實際最重要的風險。

實際決策時，將最差五筆逐筆重播，檢查是否仍在事前可承受範圍。把極端虧損稱為黑天鵝後從資料刪除，會精確移除你最需要管理的資訊

TAILS保留極端期

跳空、停板與流動性惡化。

COST保守成交

追空與停損都加入滑價。

SPLIT策略分組

跌破、反彈、假突破各自統計。

REPLAY重播最差五筆

檢查帳戶與流程是否可存活。

錯過急跌不會損失帳戶；在急跌末端追空、遭擠壓後加碼，才可能。

DECISION REHEARSAL

把第 9 章變成一次紙上決策

先遮住事後價格，只使用當時可取得的規格、報價與帳戶資料。建立兩條路徑：第一條假設所有必要證據完整，寫出你會如何限制曝險；第二條故意放入一個資料缺漏、風險超限或操作異常，練習在真正損失出現前否決交易。

PATH A / QUALIFY條件通過也不能省略風控

以「做空策略的建立方式」為題，使用本章公式或流程做一次完整模擬。方向看對不是通過條件；規格、口數、委託、退出與紀錄全部可驗證，才算完成。

PATH B / VETO練習主動取消

假設關鍵資料過時、合理口數為零、流動性突然下降，或人的狀態不合格。請明確寫出停止在哪一關、如何處理既有委託，以及何種新證據出現後才可重新評估。

  1. 01

    判斷題跌破、反彈失敗與假突破是三種不同空方假設。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  2. 02

    判斷題空單口數要額外納入向上跳空、擠壓與停損滑價。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  3. 03

    判斷題避險空單以總組合風險衡量，不能和投機單混用目的。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

  4. 04

    判斷題驗證必須保留危機期與最差交易，錯過永遠比失控便宜。請用一個假設數字或一項官方資料證明你已完成，而不是只勾選「知道」。

IMPULSE / DISCIPLINE

從『跌破就追』改成有擠壓預案的空方策略

IMPULSIVE

新聞很差、價格破底，現在不空就來不及；如果反彈就再加一口拉高均價。

DISCIPLINED

只在事前定義的跌破、反彈失敗或假突破完整觸發時進場；超過追價距離就取消，口數含上方跳空緩衝，站回失效區不加碼。

WHY IT MATTERS

速度不再凌駕風控，最危險的回補與跳空路徑在下單前就被計入。

PAPER-TRADE ASSIGNMENT

寫出一份完整空方模擬計畫

三種空方策略只選一種，加入擠壓壓力測試。

  1. 01

    定義背景與觸發用明確順序描述賣方證據。

  2. 02

    設定失效與追價上限站回何處取消，遠離多少不追。

  3. 03

    計算含跳空口數正常停損與上方跳空都要承受。

  4. 04

    模擬十筆並重播最差筆完整記錄未成交、滑價與違規。

CHECK YOUR MODEL

先回答，再展開。

價格瞬間跌破支撐就一定是有效跌破嗎？

不一定。策略需定義市場是否接受更低價格，以及是否快速收復。

反彈失敗為什麼不等於價格反彈就空？

需要下降背景、到達有效觀察區，並出現可觀察的賣方重新控制證據。

停損限價能避免空頭擠壓滑價嗎？

它限制可成交價格，但擠壓穿越限價時可能完全無法回補。

避險空單虧損是否代表失敗？

不一定，要看現貨與期貨合併後的總組合曝險是否達到目標。

空方回測為何不能刪除極端期？

極端期正是擠壓、跳空和流動性風險最重要的樣本，刪除會高估可生存性。
