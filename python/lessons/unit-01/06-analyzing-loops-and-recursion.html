Algorithm Foundations

分析迴圈與遞迴

從執行次數與問題縮小方式讀出複雜度

入門進階28 分鐘PYTHON 3

WHY THIS MATTERS

練習分析依序、巢狀與倍增迴圈，以及線性和二分遞迴的時間與呼叫堆疊。

LEARNING GOALS

  • 用相加或相乘分析迴圈
  • 辨認每次倍增造成的 O(log n)
  • 根據遞迴分支與縮小幅度估算成本
01

依序相加，巢狀通常相乘

兩段各執行 n 次的迴圈依序執行，成本相加為 O(n + n)，簡化成 O(n)。若內層每次都完整執行 n 次，外層也執行 n 次，總次數是 n × n，因此為 O(n²)；但若內層長度不同，應保留如 O(nm) 的參數。

  • 依序區塊：先相加，再保留主導項
  • 獨立巢狀迴圈：執行次數相乘
  • 提前 return 會改善部分情況，但最壞情況仍可能走完
02

倍增或減半帶來對數

如果控制變數每輪乘以 2，執行 k 輪後約為 2ᵏ；到達 n 所需的 k 約是 log₂n，所以迴圈為 O(log n)。二分搜尋也是每次排除約一半候選範圍，因此具有相同的成長等級。

  • i += 1 通常對應線性次數
  • i *= 2 通常對應對數次數
  • 對數底數只造成常數倍率，Big O 中可省略
03

遞迴要看呼叫數與深度

遞迴分析要問每次產生幾個子問題、每個子問題縮小多少，以及每層還做多少工作。單一路徑每次把 n 減 1 通常有 O(n) 次呼叫與 O(n) 堆疊；每次減半通常深度 O(log n)，而每層分成兩個重疊分支則可能接近 O(2ⁿ)。

  • Base case 必須讓遞迴終止
  • 時間計入所有呼叫執行的工作
  • 空間通常至少包含最深呼叫路徑
  • 尾端呼叫在 Python 中不會自動消除堆疊

RECAP

這堂課要帶走的事

  1. 01依序執行的成本相加，完整巢狀走訪的成本通常相乘
  2. 02每輪倍增或減半通常形成 O(log n)
  3. 03遞迴時間看總呼叫量，空間看最深呼叫路徑

CHECK YOURSELF

先想一想，再看答案

外層走訪 n 次、內層走訪固定 10 次，Big O 是什麼？

是 O(10n)，忽略固定常數後為 O(n)，不是 O(n²)。

單一遞迴每次把 n 除以 2，且每層只做 O(1) 工作，時間與堆疊空間是多少？

遞迴深度約為 log₂n，因此時間與呼叫堆疊空間都是 O(log n)。

PRACTICE

延伸練習

  1. 分析三角形巢狀迴圈：外層 i 從 0 到 n-1，內層執行 i 次；寫出精確加總與 Big O。
  2. 將 recursive_sum 改成迴圈版本，比較兩者的時間與輔助空間。
