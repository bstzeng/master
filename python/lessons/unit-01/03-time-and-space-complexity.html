時間與空間複雜度

用輸入規模描述成本如何成長

入門22 分鐘PYTHON 3

WHY THIS MATTERS

學會定義輸入規模、計數主要操作，並分辨執行時間與額外空間。

LEARNING GOALS

  • 為問題選擇合理的輸入規模 n
  • 以操作次數而非秒數描述成長
  • 區分輸入本身與輔助空間
01

先定義輸入規模

複雜度（Complexity）描述成本如何隨輸入規模成長，而 n 的意義必須依問題說清楚。對 list 搜尋，n 通常是元素數量；對文字處理，n 可能是字元數；圖問題則常同時使用頂點數 V 與邊數 E。

  • n 不是固定代表某一種資料
  • 同一問題可能需要兩個以上的規模參數
  • 先定義規模，複雜度敘述才有意義
02

時間複雜度計算主要操作

實際秒數會受到電腦、Python 版本與當時負載影響，因此分析時通常計算主要操作執行幾次。線性搜尋最壞情況要比較 n 次，所以時間成本隨 n 成正比，記為 O(n)。

  • 關注輸入變大時的成長趨勢
  • 最壞情況可提供較穩健的上限
  • 平均情況必須說明對輸入分布的假設
03

空間複雜度看額外記憶體

空間複雜度衡量演算法需要多少記憶體，分析時常特別標示輔助空間（Auxiliary Space），也就是不計輸入本身的額外用量。只使用幾個變數是 O(1)，建立與輸入同長的新 list 則是 O(n)；遞迴呼叫堆疊也算空間。

  • 原地處理通常能降低輔助空間
  • 複製切片會配置新的 list
  • 時間與空間有時可以互相交換

CHECK YOURSELF

先想一想，再看答案

處理一個 n 列、m 欄表格時，輸入規模只寫 n 是否足夠？

通常不足，應以 n 與 m 描述；若逐格處理，時間通常是 O(nm)。

函式建立 numbers[:] 後再走訪副本，額外空間是多少？

切片建立 n 個元素的新 list，因此額外空間是 O(n)。

PRACTICE

延伸練習

  1. 為計算字串中母音數量的函式定義 n，並寫出時間與空間複雜度。
  2. 比較直接反轉 list 與建立反轉副本時，輔助空間可能有何不同。
