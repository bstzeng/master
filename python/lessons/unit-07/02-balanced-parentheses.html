UNIT 07 / LESSON 02

Stacks, Queues, and Heaps

經典題型：括號配對

用 Stack 驗證巢狀結構

入門25 分鐘PYTHON 3

WHY THIS MATTERS

從單一括號擴充到多種括號，建立以 Stack 處理巢狀配對的標準模板。

LEARNING GOALS

  • 解釋括號配對為何需要 Stack
  • 正確處理不同括號種類與錯誤邊界
  • 分析一次走訪解法的成本
01

最近開啟者必須先關閉

合法巢狀括號具有 LIFO 性質：最近讀到但尚未關閉的左括號，必須由下一個右括號先配對。讀到左括號時推入 Stack，讀到右括號時與頂端比較，正好符合這個規則。

  • 左括號代表尚未完成的結構
  • 右括號只能關閉 Stack 頂端
  • 右括號出現時 Stack 為空，立即失敗
  • 掃描結束後 Stack 必須為空
02

多種類括號模板

可用 Dictionary 把右括號映射到預期左括號，讓判斷規則集中而容易擴充。每個符號最多被推入與彈出一次，所以長度 n 的字串可在 O(n) 時間處理，最壞需要 O(n) Stack 空間。

  • mapping 保存右括號到左括號的關係
  • 頂端不相符時立即回傳 False
  • 走訪時間 O(n)
  • 全為左括號時額外空間 O(n)
03

邊界條件與延伸

常見錯誤是只比較左右括號數量，卻忽略順序與種類；例如 ([)] 數量相同但巢狀關係錯誤。相同模板還能解析 HTML 標籤、計算巢狀深度，或找出未配對符號的位置。

  • 空字串通常視為合法
  • 測試提早出現的右括號
  • 測試種類交錯與掃描後仍有左括號
  • 需要位置時可在 Stack 保存 (符號, 索引)
輸入結果原因
{[]}合法種類與順序皆正確
([)]不合法右括號與頂端種類不符
(()不合法掃描後仍有未關閉項目
][不合法右括號出現時 Stack 為空

RECAP

這堂課要帶走的事

  1. 01括號配對的核心是最近開啟的結構必須最先關閉
  2. 02多種括號以 Stack 配合映射表可在 O(n) 時間完成
  3. 03右括號時先檢查空 Stack，結束時再檢查 Stack 是否清空

CHECK YOURSELF

先想一想，再看答案

為什麼只計算左右括號數量不足以判斷合法？

數量不能保證關閉順序與種類，例如 ([)] 的數量相等但配對順序錯誤。

括號字串全部是左括號時，空間複雜度是多少？

O(n)，因為所有左括號都會留在 Stack 中。

PRACTICE

延伸練習

  1. 修改演算法，回傳第一個未配對括號的索引，而不只回傳布林值。
  2. 計算合法括號字串的最大巢狀深度。
