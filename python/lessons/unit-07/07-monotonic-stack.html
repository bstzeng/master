Monotonic Stack：尋找下一個更大元素

丟棄不可能再成為答案的候選

進階35 分鐘PYTHON 3

WHY THIS MATTERS

理解單調堆疊的不變量，以一次走訪解決下一個更大元素與跨度問題。

LEARNING GOALS

  • 維護 Monotonic Stack 的單調不變量
  • 實作 Next Greater Element
  • 以攤銷分析證明總時間 O(n)
01

單調不變量與候選

Monotonic Stack（單調堆疊）讓 Stack 中的值保持遞增或遞減，只保留仍可能成為未來答案的候選。新元素破壞單調性時，持續 pop 並同時為被移除元素確定答案。

  • 找下一個更大值：常維護遞減 Stack
  • 找下一個更小值：常維護遞增 Stack
  • Stack 通常保存索引，方便算距離
  • 相等值是否 pop 取決於題目是嚴格大於或大於等於
02

Next Greater Element 模板

先以預設值 -1 表示尚未找到答案，再由左到右掃描；當目前值大於 Stack 頂端的值，就能確定頂端的下一個更大元素。掃描結束仍留在 Stack 的索引，代表右側沒有更大值。

  • 答案陣列先填 -1
  • while 負責解決已找到答案的舊候選
  • append 保存目前索引等待未來
  • 若求距離，寫成 current_index - previous_index
03

攤銷 O(n) 與常見變形

雖然程式有巢狀 while，但每個索引最多 push 一次、pop 一次，所有迭代加總為 O(n)，額外空間 O(n)。每日溫度、股票跨度與直方圖最大矩形都建立在同一種候選淘汰思維上。

  • 不要把巢狀迴圈直接判為 O(n²)
  • 向左找可反向掃描或調整 Stack 意義
  • 循環陣列可模擬走訪 2n 次
  • 先寫清楚 Stack 由底到頂的單調方向
題型Stack 保存pop 條件
下一個嚴格更大尚未解決的遞減索引舊值 < 新值
下一個嚴格更小尚未解決的遞增索引舊值 > 新值
距離問題索引條件成立後相減
KEY IDEA

單調結構最重要的不是背模板，而是說明被 pop 的候選為何永遠不再需要。

RECAP

  3. 03保存索引能同時取得值、位置與距離

CHECK YOURSELF

先想一想，再看答案

Next Greater Element 為何常保存索引而非只保存值？

索引可定位答案欄位、讀回原值，並能計算與下一個更大值之間的距離。

演算法有 for 包 while，為何仍是 O(n)？

每個索引整體只會 push 一次、pop 一次，while 的總執行次數不超過 n。

PRACTICE

延伸練習

  1. 回傳每一天要等幾天才會遇到更高溫，沒有則回傳 0。
  2. 修改模板，找出每個元素右側第一個嚴格更小元素。
