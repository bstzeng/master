Stacks, Queues, and Heaps

Stack：後進先出的解題模型

從基本操作到常見使用時機

入門25 分鐘PYTHON 3

WHY THIS MATTERS

理解 Stack 的 LIFO 規則，以 Python List 建立操作介面，並追蹤每一步狀態。

LEARNING GOALS

  • 說明 LIFO 與 Stack 的核心操作
  • 以 List 實作 push、pop 與 peek
  • 辨認適合 Stack 的問題特徵
01

LIFO 與操作介面

Stack（堆疊）遵守後進先出（Last In, First Out，LIFO）：最後放入的元素最先離開。它只開放頂端操作，因此很適合記錄尚未完成、需要依相反順序處理的工作。

  • push：把元素放到頂端
  • pop：移除並回傳頂端元素
  • peek：查看頂端但不移除
  • is_empty：確認是否還有元素
02

Python 實作與複雜度

List 的 append 與尾端 pop 都是攤銷 O(1)，查看 stack[-1] 也是 O(1)，因此通常不必另外建立 Stack 類別。Stack 保存 n 個元素時需要 O(n) 空間，而 pop 前必須先處理空堆疊情況。

  • append(value)：攤銷 O(1)
  • pop()：O(1)
  • stack[-1]：O(1)
  • 不要用 insert(0) 或 pop(0) 當作 Stack 頂端
03

辨認 Stack 題型

當問題出現巢狀結構、復原最近操作、反向處理或深度優先探索時，可以先考慮 Stack。解題時要明確寫出 Stack 裡每個元素代表什麼，以及何時推入、何時彈出。

  • 編輯器 Undo：先復原最近動作
  • 函式呼叫：最近呼叫先返回
  • DFS：保存尚待探索的節點
  • 運算式解析：保存未配對符號或運算子
問題訊號Stack 中保存
最近一項優先操作或值
巢狀結構尚未結束的開頭
反向輸出依正向讀入的元素
KEY IDEA

只要能清楚描述 Stack 元素的意義，演算法通常就已完成一半。

CHECK YOURSELF

先想一想，再看答案

依序 push A、B、C 後連續 pop 兩次，取出順序為何？

先 C 再 B，因為 Stack 遵守後進先出。

為何用 List 尾端作為 Stack 頂端？

尾端 append 與 pop 都是 O(1) 或攤銷 O(1)；若使用開頭，元素位移會使操作成為 O(n)。
