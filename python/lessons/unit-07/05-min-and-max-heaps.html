Stacks, Queues, and Heaps

Min Heap 與 Max Heap

理解堆積規則、建堆與 Python 慣例

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

理解 Heap 的陣列表示與局部順序，以 heapq 建立 Min Heap，並掌握 Max Heap 的相容寫法。

LEARNING GOALS

  • 說明 Heap 的局部順序與陣列索引
  • 使用 heapify、heappush 與 heappop
  • 以負值慣例實作 Max Heap
01

完全二元樹與局部順序

Binary Heap（堆積）通常以 List 表示完全二元樹；Min Heap 保證每個父節點不大於子節點，因此根節點是全域最小值。這只是局部順序，走訪底層 List 不會得到由小到大的完整排序。

  • 索引 i 的左子節點為 2i + 1
  • 右子節點為 2i + 2
  • 父節點為 (i - 1) // 2
  • 根節點 heap[0] 是最小值
02

heapify 與核心操作

heapq.heapify 可在 O(n) 時間把既有 List 原地轉成 Min Heap，比逐一 heappush 的 O(n log n) 更適合批次建立。取出 n 次可得到排序結果，但總成本仍為 O(n log n)，而且會清空 Heap。

  • heapify：O(n)
  • heappush／heappop：O(log n)
  • heap[0]：O(1)
  • heappushpop 可在一次調整中加入後取出
03

Max Heap 的 heapq 慣例

經典 Python heapq 介面以 Min Heap 為主，跨版本最常見的 Max Heap 慣例是存入負數，取出後再取負號還原；Tuple 時只反轉作為優先權的數值欄位。部分新版 Python 提供名稱帶 _max 的 API，但教材與面試程式通常仍使用負值寫法以保持相容。

  • push 原值 x 時存 -x
  • pop 得到 negated 後回傳 -negated
  • 零與負數仍可正確處理
  • 不要忘記只反轉優先值，不要破壞附帶資料
結構根節點heapq 相容寫法
Min Heap最小值直接存原值
Max Heap最大值數值取負後存入

CHECK YOURSELF

先想一想，再看答案

為何 heapify 是 O(n)，不是直覺的 O(n log n)？

自底向上建堆時，多數靠近葉節點的元素只需很少調整，所有調整高度加總可證明為 O(n)。

Max Heap 存入原值 12 時，負值慣例實際存什麼？取出後如何還原？

存 -12；heappop 得到 -12 後再取負號還原成 12。

延伸練習

  2. 以負值 Max Heap 持續取得遊戲排行榜目前最高分。
