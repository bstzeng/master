Dynamic Programming

Fibonacci 與 Climbing Stairs

從遞迴關係到一維 DP

基礎25 分鐘PYTHON 3

WHY THIS MATTERS

以兩個入門問題練習狀態轉移與 O(1) 空間。

LEARNING GOALS

  • 推導兩題轉移
  • 處理初始狀態
  • 使用滾動變數
01

Fibonacci 的前兩項

fib[i] 只依賴 fib[i-1] 與 fib[i-2]，Base Case 是 0 與 1。這個模型展示 DP 如何消除重複遞迴。

  • transition：F(i)=F(i-1)+F(i-2)
  • 時間 O(n)、可用 O(1) 空間
02

Climbing Stairs

每次走一或兩階，到第 i 階的最後一步必來自 i-1 或 i-2。令 ways[i] 為到達第 i 階的方法數，兩類路徑互斥，因此相加。

  • ways[0]=1 表示什麼都不走的一種方式
  • ways[1]=1
  • 方法數問題通常加總來源
03

相同公式，不同語意

兩題公式相似，但狀態與 Base Case 來自不同問題定義，不能只背數列。若允許步長集合改變，轉移就要加總所有合法前一階。

  • 先說明最後一步，再寫加法
  • 步長為 1、3 時依賴 i-1 與 i-3
  • 輸入邊界要依題目定義
題目dp[i]Base

RECAP

這堂課要帶走的事

  1. 01一維相鄰轉移常可滾動優化。
  2. 02方法數問題通常加總互斥來源。
  3. 03公式相同不代表 Base Case 與語意相同。

CHECK YOURSELF

先想一想，再看答案

ways[0]=1 的意義？

到達起點有一種空路徑，讓後續轉移一致。

允許走 1 或 3 階時依賴哪些狀態？

ways[i-1] 與 ways[i-3]，索引合法者相加。

PRACTICE

延伸練習

  1. 求每次可走 1、2、3 階的方法數。
  2. 要求不能連續走兩次 2 階，重新設計狀態。
