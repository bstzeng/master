UNIT 13 / LESSON 08

Dynamic Programming

LCS 與 Edit Distance

用二維前綴狀態比較兩字串

進階40 分鐘PYTHON 3

WHY THIS MATTERS

以兩字串前綴建立共同子序列與編輯距離。

LEARNING GOALS

  • 推導 LCS
  • 推導 Edit Distance
  • 比較二維轉移
01

Longest Common Subsequence

dp[i][j] 是 first 前 i 字元與 second 前 j 字元的 LCS 長度。末字元相同就接 dp[i-1][j-1]+1，否則丟棄其中一側末字元取最大。

  • 子序列不要求連續
  • 空前綴 LCS 為 0
  • 時間與空間 O(mn)
02

Edit Distance

dp[i][j] 是把 a 前 i 字元轉成 b 前 j 字元的最少操作數。末字元不同時，從刪除、插入、替換三種前態取最小再加一。

  • dp[i][0]=i
  • 相同末字元不增加成本
  • 不同時取 min(刪、插、換)+1
03

壓縮與重建

兩題每列只依賴上一列與本列左側，可用兩列或一列將空間降為 O(min(m,n))。若要回傳實際 LCS 或編輯步驟，通常保留完整表並反向追蹤。

  • 長度答案可壓縮
  • 重建解需要來源資訊
  • 一維更新要保存左上角舊值
題目相同末字元不同末字元
LCS左上+1max(上,左)
Edit左上1+min(上,左,左上)

RECAP

這堂課要帶走的事

  1. 01雙字串問題常以兩個前綴長度作狀態。
  2. 02LCS 最大化保留，Edit Distance 最小化操作。
  3. 03只求數值可壓縮，重建通常需完整來源。

CHECK YOURSELF

先想一想，再看答案

LCS 與最長共同子字串差在哪？

LCS 不要求字元連續，子字串要求連續。

Edit Distance 的 dp[i][0] 為何是 i？

把 i 個字元轉成空字串需刪除 i 次。

PRACTICE

延伸練習

  1. 由 LCS 表反向重建一個實際共同子序列。
  2. 把替換成本改為 2，修改 Edit Distance。
