UNIT 13 / LESSON 06

Dynamic Programming

Coin Change 與 Word Break

最少數量與可行性 DP

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

練習最小化與布林可行性兩種 DP。

LEARNING GOALS

  • 設計 Coin Change 狀態
  • 設計 Word Break 狀態
  • 選擇正確初值
01

Coin Change

令 dp[a] 為湊出金額 a 的最少硬幣數，最後一枚為 coin 時由 dp[a-coin]+1 轉移。不可達狀態初始化為 infinity。

  • dp[0]=0
  • 對每個 amount 嘗試所有 coin
  • 答案仍為 inf 時回傳 -1
02

Word Break

令 dp[i] 表示 text 前 i 個字元能否由字典單字切分。若存在 j 使 dp[j] 為真且 text[j:i] 在字典，就令 dp[i] 為真。

  • dp[0]=True 代表空前綴可切分
  • set 提供平均 O(1) 單字查找
  • 找到一個 j 後即可停止
03

最小值與可行性

兩題都枚舉最後一段，但聚合方式不同：Coin Change 取 min，Word Break 取 any。若需重建硬幣或單字，需為每個狀態保存 predecessor。

  • 最佳化問題保存數值
  • 存在性問題保存 bool
  • 一維表已是常見空間界線
題目初值聚合
Coin Changeinf, dp0=0min
Word BreakFalse, dp0=Trueany

RECAP

這堂課要帶走的事

  1. 01不可達最小值狀態可用 infinity。
  2. 02Word Break 以可切分前綴作狀態。
  3. 03聚合運算由題目問最小值、最大值、數量或存在性決定。

CHECK YOURSELF

先想一想，再看答案

Coin Change 為何 dp[0]=0？

金額零不需任何硬幣，且它是加入第一枚硬幣的合法起點。

Word Break 的 dp[0] 為何是 True？

空字串視為已完成切分，讓第一個單字可由空前綴轉移。

PRACTICE

延伸練習

  1. 回傳 Coin Change 的一組最少硬幣。
  2. 限制單字最多使用一次，思考狀態需增加什麼資訊。
