UNIT 13 / LESSON 11

Dynamic Programming

LIS：O(n²) 與 O(n log n)

從結尾狀態到 tails 二分搜尋

進階40 分鐘PYTHON 3

WHY THIS MATTERS

比較標準 DP 與二分優化的 LIS。

LEARNING GOALS

  • 推導 O(n²) LIS
  • 理解 tails 語意
  • 用 bisect 完成 O(n log n)
01

以 i 結尾的 LIS

dp[i] 是必須以 numbers[i] 結尾的最長遞增子序列長度。枚舉所有 j<i 且 numbers[j]<numbers[i]，由 dp[j]+1 取最大。

  • 每個位置至少長度 1
  • 答案是 max(dp) 而非固定 dp[-1]
  • 時間 O(n²)、空間 O(n)
02

tails 的最小尾值

tails[k] 保存長度 k+1 遞增子序列中可得到的最小尾值；尾值愈小，未來愈容易延伸。它不一定是實際 LIS，但 tails 長度就是答案。

  • 用 lower_bound 找第一個 >= value 的位置
  • 替換尾值不改變目前最長長度
  • value 大於所有尾值時 append
03

嚴格與非嚴格遞增

嚴格遞增使用 bisect_left，遇到相同值會替換而不延長；若允許相等，改用 bisect_right。要重建實際 LIS，需額外保存前驅與每長度代表索引。

  • 先確認 < 還是 <=
  • tails 是壓縮摘要，不直接等於答案序列
  • O(n²) 版較容易重建與解釋
方法時間空間
結尾 DPO(n²)O(n)
tails+二分O(n log n)O(n)

RECAP

這堂課要帶走的事

  1. 01標準 LIS 狀態是以某位置結尾的最佳長度。
  2. 02tails 用最小尾值保留最佳延伸機會。
  3. 03嚴格與非嚴格遞增需選不同二分邊界。

CHECK YOURSELF

先想一想，再看答案

答案為何是 max(dp)？

最長子序列可能在任何位置結尾，不一定是最後元素。

tails 為何不一定是實際 LIS？

替換不同長度的尾值可能來自不相容路徑，它主要保存長度資訊。

PRACTICE

延伸練習

  1. 為 O(n²) 版本保存 parent 並重建 LIS。
  2. 改求最長非遞減子序列。
