UNIT 13 / LESSON 07

Dynamic Programming

Grid、Unique Paths 與 Minimum Path Sum

依上方與左方狀態填表

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

建立網格路徑數與最小成本 DP，並壓縮為一列。

LEARNING GOALS

  • 定義網格二維狀態
  • 處理第一列與第一欄
  • 實作一維空間優化
01

Unique Paths

只能向右或向下時，到 (r,c) 的路徑來自上方與左方，兩者數量相加。第一列與第一欄各只有一條路。

  • dp[r][c]=dp[r-1][c]+dp[r][c-1]
  • 時間與空間 O(rows·cols)
02

Minimum Path Sum

若格子帶成本，dp[r][c] 表示到該格的最小總成本，取上方與左方較小值再加目前成本。邊界只有單一來源，需個別初始化或使用 infinity。

  • 起點成本要計入
  • 轉移使用 min 而非加總
  • 負值不影響此 DAG 式依賴
03

障礙與空間壓縮

遇到障礙格時可把該狀態設為 0 條路徑，其他格仍從上與左累加。因每列只依賴上一列與本列左側，可將空間由 O(rows·cols) 降為 O(cols)。

  • 內層沿左到右更新
  • 障礙會切斷經過該格的轉移
  • 可選較短維度作 dp 以降至 O(min(rows,cols))
題型聚合壓縮空間
路徑數上+左O(cols)
最小成本min(上,左)+成本O(cols)

RECAP

這堂課要帶走的事

  1. 01網格 DP 的方向決定依賴與填表順序。
  2. 02路徑數加總來源，最小成本取來源最小值。
  3. 03只依賴上一列時可壓縮成一維。

CHECK YOURSELF

先想一想，再看答案

一維更新時 dp[c] 更新前代表什麼？

上一列同一欄，也就是目前格的上方狀態。

障礙格的路徑數為何設 0？

沒有合法路徑能進入或通過它。

PRACTICE

延伸練習

  1. 實作含障礙的 Unique Paths。
  2. 允許右、下、右下三方向，修改轉移與空間分析。
