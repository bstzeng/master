UNIT 13 / LESSON 02

Dynamic Programming

Memoization 與 Tabulation

自頂向下與自底向上

入門30 分鐘PYTHON 3

WHY THIS MATTERS

比較記憶化搜尋與表格法的流程及取捨。

LEARNING GOALS

  • 實作 memoization
  • 實作 tabulation
  • 比較兩者空間與可達狀態
01

Memoization 記憶化

記憶化保留原遞迴結構，在進入狀態時先查 cache。它只計算實際可達狀態，但仍使用 Call Stack。

  • 快取鍵必須完整描述狀態
  • 先查 cache，再展開子問題
02

Tabulation 表格法

表格法從已知 Base Case 開始，依依賴順序填出較大狀態。它沒有遞迴深度問題，通常更容易做空間優化。

  • 先初始化最小狀態
  • 迴圈順序必須先算依賴項
03

選擇與滾動優化

若每個狀態只依賴前兩項，就不必保留整張表，可用兩個變數將空間降為 O(1)。需要重建解或查看所有狀態時，則保留表格。

  • 記憶化適合狀態稀疏或轉移複雜
  • 表格法適合順序清楚且重視常數成本
  • 空間優化前先確認未來依賴

RECAP

這堂課要帶走的事

  1. 01Memoization 自頂向下，只算可達狀態。
  2. 02Tabulation 自底向上，避免遞迴堆疊。
  3. 03只依賴少數前態時可使用滾動變數。

CHECK YOURSELF

先想一想，再看答案

記憶化已用 cache，為何空間仍可能 O(n)？

除 cache 外，最深遞迴仍保留 O(n) 個呼叫框架。

何時不宜刪除完整 dp 表？

需要重建選擇路徑或後續查詢所有狀態時。

PRACTICE

延伸練習

  1. 將遞迴爬樓梯改成 lru_cache。
  2. 把只依賴前三項的 DP 優化為三個變數。
