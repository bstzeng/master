Dynamic Programming

0/1 Knapsack

每件物品最多選一次

進階40 分鐘PYTHON 3

WHY THIS MATTERS

建立物品與容量狀態，理解一維壓縮必須反向更新。

LEARNING GOALS

  • 推導 0/1 背包
  • 完成二維與一維轉移
  • 說明容量反向迴圈
01

選或不選物品

dp[i][c] 表示只看前 i 件、容量 c 的最大價值。第 i 件可不選沿用上方，或在容量足夠時選取並加上前 i-1 件的剩餘容量答案。

  • 不選：dp[i-1][c]
  • 選：dp[i-1][c-weight]+value
  • 兩者取 max
02

一維反向容量

壓縮成 dp[c] 後，容量必須由大到小更新，讓 dp[c-weight] 仍代表上一輪、尚未使用目前物品的答案。正向更新會讓同一物品在同輪被重複使用。

  • 外層逐物品
  • 內層 c 從 capacity 降到 weight
  • 空間降為 O(C)
03

狀態與限制

0/1 的名稱表示每件物品只能取零或一次，容量 C 是偽多項式維度。若要重建物品清單，可保留二維表或額外決策資訊。

  • 容量不是輸入位數而是數值大小
  • 恰好裝滿時不可達狀態需設為負無限
  • 價值最大與方案數的聚合不同
版本容量方向空間
二維皆可依前列O(nC)
一維 0/1由大到小O(C)

RECAP

這堂課要帶走的事

  1. 010/1 背包比較選與不選目前物品。
  2. 02一維壓縮必須反向更新容量。
  3. 03重建選項通常需保留更多狀態。

CHECK YOURSELF

先想一想，再看答案

容量正向更新會發生什麼？

本輪新值會再次被讀取，使同一物品可能選多次。

O(nC) 為何稱偽多項式？

C 是容量數值，而非表示 C 所需的位元數。

PRACTICE

延伸練習

  1. 回傳 0/1 背包選中的物品索引。
  2. 改為價值恰好達標時最小重量。
