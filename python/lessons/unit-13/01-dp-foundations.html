UNIT 13 / LESSON 01

Dynamic Programming

DP 核心：重疊子問題與最佳子結構

把重複計算保存起來

入門25 分鐘PYTHON 3

WHY THIS MATTERS

辨認 DP 的兩項核心性質，從決策樹理解重複工作。

LEARNING GOALS

  • 辨認重疊子問題
  • 說明最佳子結構
  • 區分 DP 與一般分治
01

重疊子問題

若遞迴樹反覆以相同參數求解相同答案，就存在重疊子問題。DP 將答案保存，使每種狀態只計算一次。

  • fib(5) 會多次呼叫 fib(3)
  • 狀態數常遠少於遞迴呼叫數
02

最佳子結構

若原問題的最佳答案能由較小問題的最佳答案組合而成，就具有最佳子結構。轉移式必須涵蓋最後一步的所有合法選擇。

  • 先定義子問題答案代表什麼
  • 局部最佳不一定能組成全域最佳
性質檢查問題
重疊子問題相同狀態是否重算？
最佳子結構大答案能否由小答案組成？
03

DP 不是公式背誦

DP 的工作是定義有限狀態與依賴關係，再依正確順序求值。若狀態遺漏影響未來的資訊，即使程式能跑也可能錯誤。

  • 先寫暴力選擇有助找轉移
  • 時間通常是狀態數乘每狀態轉移成本
  • 空間取決於保存多少狀態
KEY IDEA

先用一句話定義 dp[state]，再寫公式。

RECAP

這堂課要帶走的事

  1. 01重疊子問題讓保存答案有價值。
  2. 02最佳子結構讓小答案能組成大答案。
  3. 03DP 複雜度可由狀態數與轉移成本估算。

CHECK YOURSELF

先想一想，再看答案

分治一定是 DP 嗎？

不一定；子問題若互不重疊，就沒有保存重複答案的主要需求。

狀態定義為何重要？

它決定已保存資訊是否足以完成後續轉移。

PRACTICE

延伸練習

  1. 畫出 fib(5) 遞迴樹並圈出重複狀態。
  2. 判斷二分搜尋是否有重疊子問題。
