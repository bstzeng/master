Tree Data Structures

DFS 前序、中序與後序走訪

改變處理根節點的時機，就得到三種深度優先順序

入門進階30 分鐘PYTHON 3

WHY THIS MATTERS

以遞迴實作三種二元樹 DFS 走訪，理解順序、用途與呼叫堆疊成本。

LEARNING GOALS

  • 區分前中後序
  • 實作遞迴走訪
  • 依問題選擇處理節點的時機
01

DFS 沿子樹深入

二元樹的深度優先搜尋（Depth-First Search, DFS）會先深入一個子樹再回來處理另一側。前序、中序與後序都先遞迴探索左、右子樹，名稱差異來自根節點在兩者之前、之間或之後處理。

  • 前序：根、左、右
  • 中序：左、根、右
  • 後序：左、右、根
  • 遞迴呼叫堆疊扮演 Stack
02

一個模板三種位置

base case 遇到 None 就返回；把 append 放在兩次遞迴呼叫的不同位置即可表達走訪順序。以下中序版本先完成左子樹才記錄根，若輸入是合法 BST，結果會是非遞減順序。

  • 先定義空節點行為
  • 每個節點恰好加入一次
  • 更換 append 位置可改成前序或後序
03

處理時機對應問題語意

前序在孩子前處理根，適合複製結構或輸出前綴表示；中序常用於 BST 依序讀值；後序等孩子結果完成才處理根，適合刪除子樹或計算依賴孩子的性質。三者都訪問每個節點一次，時間 O(n)，空間取決於高度 O(h)。

  • 前序：先建立或處理父節點
  • 中序：BST 產生排序結果
  • 後序：先取得孩子結果
  • 退化鏈的 h 可達 n

RECAP

這堂課要帶走的事

  1. 01三種 DFS 的差別是根節點的處理位置
  2. 02所有節點只訪問一次，因此時間 O(n)
  3. 03遞迴空間是 O(h)，平衡與退化樹差異很大

CHECK YOURSELF

先想一想，再看答案

需要先計算左右子樹大小再計算根的大小，應使用哪種順序？

後序，因為根的結果依賴左右孩子先完成。

中序走訪任何二元樹都會得到排序結果嗎？

不會；只有滿足 BST 排序規則的樹，中序結果才是非遞減順序。

PRACTICE

延伸練習

  1. 將 inorder 的 append 移動，分別實作 preorder 與 postorder。
  2. 對同一棵七節點樹手算三種走訪順序，再用程式驗證。
