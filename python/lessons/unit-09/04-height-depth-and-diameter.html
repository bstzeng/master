Tree Data Structures

高度、深度與直徑

先統一定義，再用後序一次收集子樹資訊

中階32 分鐘PYTHON 3

WHY THIS MATTERS

區分節點深度與樹高，並用後序 DFS 在 O(n) 內計算二元樹直徑。

LEARNING GOALS

  • 清楚定義深度與高度
  • 遞迴計算樹高
  • 以子樹高度推導直徑
01

深度向上數，高度向下數

節點深度（Depth）是從根到該節點的距離，高度（Height）是從節點往下到最遠葉節點的距離；樹高就是根的高度。距離可以用邊數或節點數定義，兩者只差一，但整份程式必須一致。

  • 本課以節點數表示高度
  • 空樹高度定義為 0
  • 葉節點高度為 1
  • 根深度可定義為 0
02

高度是左右結果加一

根到最遠葉節點必定經過左或右子樹，因此高度等於左右高度最大值加一。這是後序問題：必須先取得兩個孩子的結果，才能計算目前節點。

  • base case：None 回傳 0
  • 每個節點只計算一次
  • 時間 O(n)
  • 呼叫堆疊 O(h)
03

直徑不一定經過根

直徑（Diameter）是任兩節點之間最長路徑；它可能完全位於某個子樹。後序走訪取得左右高度時，以 left_height + right_height 更新經過目前節點的邊數直徑，同時向父節點回傳高度，便能一次 O(n) 完成。

  • 經過某節點的直徑由左右高度相加
  • 全域答案取所有節點候選最大值
  • 時間 O(n)，堆疊 O(h)
  • 若每個節點另算高度會退化到 O(n²)

RECAP

這堂課要帶走的事

  1. 01深度由根往下量，高度由節點往最遠葉量
  2. 02先統一邊數或節點數定義才能避免差一錯誤
  3. 03後序同時回傳高度並更新直徑可在 O(n) 完成

CHECK YOURSELF

先想一想，再看答案

本課定義下，空樹與單節點樹高度各是多少？

空樹為 0，單節點樹為 1，因為高度以路徑上的節點數表示。

為什麼只計算 left_height + right_height 在根節點不夠？

最長路徑可能完全位於左或右子樹，未必經過整棵樹的根。

PRACTICE

延伸練習

  1. 改寫 tree_height，以邊數定義高度並清楚設定空樹值。
  2. 擴充直徑程式，額外記錄最長路徑的兩個端點。
