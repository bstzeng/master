UNIT 09 / LESSON 05

Tree Data Structures

BST 查找、插入與刪除

用排序性沿單一路徑排除子樹

中階38 分鐘PYTHON 3

WHY THIS MATTERS

建立 Binary Search Tree 規則，實作核心操作並理解高度控制其成本。

LEARNING GOALS

  • 說明 BST 不變量與重複值政策
  • 實作查找、插入與刪除
  • 以樹高 h 分析操作
01

BST 把較小與較大值分開

二元搜尋樹（Binary Search Tree, BST）要求每個節點左子樹的鍵都較小、右子樹的鍵都較大，且所有子樹也遵守相同規則。重複鍵要事先決定禁止、固定放一側或在節點內計數，否則操作規格不完整。

  • 比較一次就能選擇一個子樹
  • 中序走訪得到排序鍵
  • BST 不是自動平衡
  • 本課程式忽略重複鍵
02

查找與插入沿同一路徑

查找由 root 開始，比目前值小就往左、大就往右，命中或遇到 None 結束；插入走相同路徑，在第一個 None 接上新節點。兩者最多經過樹高 h 個節點，時間 O(h)，迭代版本額外空間 O(1)。

  • 平衡時 h = O(log n)
  • 退化鏈時 h = O(n)
  • 插入後仍須維持全域 BST 規則
03

刪除分成三種情況

刪除葉節點可直接回傳 None；只有一個孩子時以該孩子取代；有兩個孩子時可用右子樹最小值作為中序後繼，複製其值後再從右子樹刪除它。搜尋與調整都沿少數路徑，時間 O(h)，遞迴堆疊 O(h)。

  • 零個孩子：移除節點
  • 一個孩子：提升唯一孩子
  • 兩個孩子：替換為後繼再刪後繼
  • 函式必須回傳更新後子樹根

RECAP

這堂課要帶走的事

  1. 01BST 以全域左右排序規則排除不可能子樹
  2. 02核心操作時間是 O(h)，不是無條件 O(log n)
  3. 03刪除兩孩子節點可用中序後繼維持排序性

CHECK YOURSELF

先想一想，再看答案

依序插入 1、2、3、4，普通 BST 的高度可能是多少量級？

會形成向右的鏈，高度為 O(n)，查找也可能退化成 O(n)。

刪除有兩個孩子的節點時，為何右子樹最小值適合取代它？

它大於所有左子樹鍵，又是右子樹中最小者，替換後能維持 BST 排序規則。

  2. 測試刪除葉節點、單一孩子與兩個孩子三種情況。
