Tree Data Structures

BFS Level Order 層序走訪

使用 Queue 由上到下、由左到右探索

入門進階26 分鐘PYTHON 3

WHY THIS MATTERS

以 deque 實作二元樹 BFS，按層收集節點並分析寬度空間。

LEARNING GOALS

  • 解釋 Queue 與層序的關係
  • 實作按層分組的 BFS
  • 比較 BFS 與 DFS 的空間形態
01

Queue 保持先發現先處理

層序走訪（Level Order Traversal）是一種廣度優先搜尋（Breadth-First Search, BFS），先處理深度 0，再處理深度 1。把孩子加到佇列尾端、從前端取出，可維持由上到下且同層由左到右的順序。

  • Queue 採先進先出
  • 孩子在父節點處理後入隊
  • 適合層級、最淺深度與最近節點問題
02

固定本層大小再處理

每輪開始時 queue 的長度就是本層節點數，固定這個數量再依序取出，便能把每層放進獨立 list。Python 使用 deque.popleft() 為 O(1)，避免 list.pop(0) 搬移元素的 O(n)。

  • 空樹直接回傳空 list
  • level_size 隔開相鄰層
  • 只將非 None 孩子入隊
03

空間由最寬一層決定

每個節點入隊與出隊一次，所以時間 O(n)；queue 同時保存的節點最多接近樹的最大寬度 w，額外空間 O(w)，輸出另需 O(n)。平衡樹底層可能很寬，而細長樹的 BFS queue 很小；這與 DFS 的 O(h) 堆疊形成對比。

  • 處理時間 O(n)
  • 工作 queue 空間 O(w)
  • 回傳所有值的輸出空間 O(n)
  • 選 DFS 或 BFS 時應考慮樹形

CHECK YOURSELF

先想一想，再看答案

為什麼不能在 for 迴圈中每次重新以目前 len(queue) 決定本層？

處理父節點時會加入下一層孩子，使 queue 長度改變；應在一層開始時固定原本長度。

完全二元樹的 BFS queue 最多可能保存多少量級節點？

最底層可占全樹約一半節點，因此最大寬度是 O(n)。

PRACTICE

延伸練習

  1. 修改 level_order，只回傳每層最大值。
  2. 使用 BFS 找出第一個葉節點所在的最小深度。
