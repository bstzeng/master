Tree Data Structures

樹與 Binary Tree 二元樹

用節點和邊表達有層次的資料

入門24 分鐘PYTHON 3

WHY THIS MATTERS

建立根、父子、葉節點、子樹與二元樹的共同術語，並以節點類別建立範例。

LEARNING GOALS

  • 辨認樹的基本組成
  • 區分一般樹與二元樹
  • 用 Python 節點表示二元樹
01

樹描述階層與分支

樹（Tree）由節點（Node）與連接節點的邊（Edge）構成，從唯一根節點向下形成階層。除根以外，每個節點恰有一個父節點；沒有子節點的是葉節點，而從某節點往下的完整部分稱為子樹。

  • 根節點沒有父節點
  • 兄弟節點共享同一父節點
  • 路徑是由邊連接的一串節點
  • 含 V 個節點的樹有 V - 1 條邊
02

二元樹限制每個節點的孩子數

二元樹（Binary Tree）的每個節點最多有左、右兩個孩子，左右位置具有區別；它不保證排序，也不保證每層填滿。滿二元樹、完全二元樹與二元搜尋樹是額外性質，不能只因為有兩個孩子就混為一談。

  • 每個節點可有零、一或兩個孩子
  • 左子樹與右子樹不可任意互換
  • 二元樹不等於 Binary Search Tree
  • 完全二元樹適合用陣列緊密儲存
03

以參照連接節點

最直覺的 Python 表示法讓每個節點保存值與左右孩子參照；整棵樹只需保留 root。這種結構適合形狀不規則的樹，但若要從孩子回到父親，就需額外保存 parent 或由走訪過程記錄路徑。

  • None 表示該方向沒有孩子
  • 建立節點是 O(1)
  • 存取已知節點的左右孩子是 O(1)

RECAP

  2. 02二元樹只限制左右孩子數，不自動具有排序性
  3. 03參照式節點適合表示形狀不規則的二元樹

CHECK YOURSELF

先想一想，再看答案

二元樹每個節點都必須有兩個孩子嗎？

不必；二元樹只規定最多兩個孩子，也可以有一個或沒有孩子。

有 12 個節點且連通無環的樹有幾條邊？

有 11 條邊，因為含 V 個節點的樹恰有 V - 1 條邊。

PRACTICE

延伸練習

  2. 用 TreeNode 建立三層二元樹，刻意讓部分節點只有一個孩子。
