Sorting Algorithms

Merge Sort 合併排序

分割問題，再線性合併兩個有序結果

中階30 分鐘PYTHON 3

WHY THIS MATTERS

以分治與合併實作穩定的 O(n log n) 排序，理解額外空間成本。

LEARNING GOALS

  • 描述分割與合併流程
  • 實作穩定合併排序
  • 推導 O(n log n) 時間
01

把大問題分成兩半

合併排序（Merge Sort）使用分治法：把序列分成兩半，分別排序後再合併。當序列長度小於二時本身已有序，這就是遞迴的 base case。

  • Divide：切成左右兩半
  • Conquer：遞迴排序兩半
  • Combine：合併兩個有序序列
02

雙指標線性合併

合併時比較左右目前最小值，取較小者放入結果，某側用完後接上另一側剩餘元素。相等時先取左側，可保留原本跨越兩半的相對順序，因此整體穩定。

  • 左右指標只向前移動
  • 一次合併 O(n)
  • 相等時取左側維持穩定
03

每層 O(n)，共有 O(log n) 層

問題每次減半，所以遞迴深度 O(log n)；同一層的所有合併合計處理 n 個元素，因此最好、平均與最壞時間都是 O(n log n)。典型陣列實作需 O(n) 額外空間，不屬於原地排序。

  • 所有情況時間 O(n log n)
  • 主要額外空間 O(n)
  • 穩定但通常非原地
  • 適合需要可預測最壞時間的情境

RECAP

這堂課要帶走的事

  1. 01合併排序以分治將問題反覆減半
  2. 02線性合併與相等時取左側使排序穩定
  3. 03時間固定 O(n log n)，代價是 O(n) 額外空間

CHECK YOURSELF

先想一想，再看答案

合併排序為什麼不是 O(n²)？

遞迴只有 O(log n) 層，而每層所有合併合計 O(n)，相乘為 O(n log n)。

合併時相等元素先取右側可能造成什麼結果？

右半元素可能越過原先位於左半的相同鍵元素，使排序不穩定。
