Sorting Algorithms

Quick Sort 快速排序

用 pivot 分割，小的放左、大的放右

中階30 分鐘PYTHON 3

WHY THIS MATTERS

理解 pivot 與 partition，實作清楚版本並比較平均效率與最壞退化。

LEARNING GOALS

  • 描述 partition 後的保證
  • 實作快速排序
  • 說明 pivot 對複雜度的影響
01

Partition 建立分界

快速排序（Quick Sort）選擇一個 pivot，將其餘元素分到較小、相等與較大區域，再遞迴排序兩側。關鍵不是 pivot 一開始在哪裡，而是 partition 後能確保左側不大於它、右側不小於它。

  • pivot 是分割基準
  • 每層 partition 走訪目前子序列
  • 遞迴只需繼續處理左右區域
02

先用清楚版本理解流程

下例建立三個新 list，容易閱讀並能妥善處理大量重複值；它不是原地版本，但相等元素依走訪順序收集，因此可維持此實作的穩定性。常見原地雙指標 partition 節省空間，通常不穩定。

  • 三向分割避免對相等值反覆遞迴
  • 此版本配置額外 list
  • 原地版本的交換會改變相同鍵順序
03

平衡分割決定效率

若 pivot 常把資料分得接近一半，遞迴深度 O(log n)，平均時間 O(n log n)；若每次只分出一個元素，深度 O(n)，最壞時間 O(n²)。隨機 pivot、三數取中與三向分割能降低退化風險，但不改變理論最壞上界。

  • 平均時間 O(n log n)
  • 最壞時間 O(n²)
  • 典型原地版本平均堆疊 O(log n)
  • 標準原地版本通常不穩定

CHECK YOURSELF

先想一想，再看答案

快速排序何時會退化成 O(n²)？

當 pivot 反覆造成極不平衡分割，例如每次只排除一個元素時，遞迴深度會達 O(n)。

教學程式為何另建 equal 區域？

它一次收集所有等於 pivot 的元素，避免大量重複值繼續進入不必要的遞迴。
