Sorting Algorithms

Bubble Sort 氣泡排序

反覆交換相鄰逆序元素

入門22 分鐘PYTHON 3

WHY THIS MATTERS

透過相鄰比較理解排序不變量、提前結束與平方時間。

LEARNING GOALS

  • 手動推演氣泡排序
  • 實作提前結束版本
  • 分析穩定性與複雜度
01

最大值逐輪移到右側

氣泡排序（Bubble Sort）由左向右比較相鄰元素，順序相反就交換。完整一輪後，尚未排序區域的最大值會移到最右端，因此右側已排序區域每輪增加一格。

  • 只比較相鄰元素
  • 第 k 輪可少檢查右側 k 個位置
  • 迴圈不變量是右側元素已在最終位置
02

用 swapped 偵測已排序

若某輪沒有發生交換，代表所有相鄰元素都已有序，可以立即結束。交換條件只在 left > right 時成立，不交換相等元素，因此這個版本維持穩定性。

  • 無交換時提前 return
  • 相等元素不交換以維持穩定
  • 直接修改輸入 list
03

平方成本限制用途

平均與最壞情況會執行約 n²/2 次比較，因此時間 O(n²)；已排序且有 swapped 最佳為 O(n)。它只用常數個變數，額外空間 O(1)，但大型資料通常不應使用。

  • 最佳時間 O(n)
  • 平均與最壞時間 O(n²)
  • 額外空間 O(1)
  • 穩定且原地

RECAP

這堂課要帶走的事

  1. 01每輪會把未排序區域最大值推到右端
  2. 02swapped 可讓已排序輸入提前結束
  3. 03氣泡排序穩定且原地，但平方時間不適合大型資料

CHECK YOURSELF

先想一想，再看答案

為何交換條件使用 > 而非 >= 有助於穩定性？

相等鍵不交換，便不會顛倒它們原本的相對順序。

沒有 swapped 最佳化時，已排序輸入的時間是多少？

仍會完成巢狀比較，時間為 O(n²)。

PRACTICE

延伸練習

  1. 手動推演 [5, 1, 4, 2] 的每一輪結果。
  2. 增加比較與交換計數器，比較已排序和反向排序輸入。
