Sorting Algorithms

排序基本觀念與 Python sorted

先說清楚順序規則，再選擇工具

入門25 分鐘PYTHON 3

WHY THIS MATTERS

理解排序鍵、穩定與原地排序，並使用 Python 內建排序處理實務資料。

LEARNING GOALS

  • 區分穩定與原地排序
  • 正確使用 sorted 與 list.sort
  • 用 key 表達單欄與多欄規則
01

排序需要明確規格

排序（Sorting）是依比較規則重新排列資料，不只限於數字由小到大。設計前要確認排序鍵、升降冪，以及鍵相同時是否必須保留原先順序。

  • 排序鍵決定比較哪個值
  • 升冪與降冪必須明確
  • 多欄位規則要決定優先順序
02

穩定與原地是不同性質

穩定排序（Stable Sort）會保留相同鍵元素的原相對順序，適合分階段排序；原地排序（In-place Sort）只使用少量額外空間修改原容器。穩定不代表原地，兩者也都不直接等於速度快。

  • 穩定性關心相同鍵的相對順序
  • 原地性關心額外記憶體
  • 需求不同時可能選擇不同演算法
KEY IDEA

Python 的排序是穩定的，因此可先按次要鍵排序，再按主要鍵排序。

03

Python 內建排序與 key

sorted(iterable) 回傳新 list，list.sort() 則原地修改 list 並回傳 None；兩者都可用 key 為每個元素計算比較鍵。Python 使用穩定的 Timsort，最壞時間 O(n log n)，實務程式通常應優先使用內建工具。

  • key 函式每個元素通常只計算一次
  • reverse=True 可反轉最終順序
  • tuple key 可依多欄位排序
  • 不要把 list.sort() 的回傳值當成結果

CHECK YOURSELF

先想一想，再看答案

sorted(items) 與 items.sort() 的主要差別是什麼？

sorted 接受任意可迭代物並回傳新 list；list.sort 原地修改該 list，回傳 None。

穩定排序對相同 key 的元素提供什麼保證？

它們在排序後仍保持輸入中的相對先後順序。
