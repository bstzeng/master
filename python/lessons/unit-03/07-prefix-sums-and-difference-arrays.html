Array and String Techniques

Prefix Sum 與差分陣列

用預處理加速區間查詢與批次更新

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

學習以一次 O(n) 預處理換取 O(1) 區間和查詢，並以差分陣列快速記錄多次區間加值。

LEARNING GOALS

  • 建立含前導零的前綴和
  • 以兩個前綴值回答閉區間總和
  • 使用差分陣列合併多次區間更新
01

Prefix Sum 前綴和

前綴和（Prefix Sum）先累積從開頭到各位置的總和，適合原陣列不變但需要多次區間查詢的情境。建立長度 n + 1 且 prefix[0] = 0 的陣列，可讓區間公式統一而不必特判左邊界。

  • prefix[i] 代表原陣列前 i 個元素總和
  • 閉區間 [left, right] 的和是 prefix[right + 1] - prefix[left]
  • 建立成本 O(n)，每次查詢 O(1)
02

Difference Array 差分陣列

差分陣列（Difference Array）適合對多個閉區間 [left, right] 加上同一數值。每次更新只在 left 記錄開始變化，並在 right + 1 記錄取消變化；全部更新完成後做一次累積，就能還原最終陣列。

  • difference[left] += amount
  • 若 right + 1 仍在範圍內，difference[right + 1] -= amount
  • 累積 difference 得到每個位置的總加值
03

選擇預處理方向

前綴和解決「多次讀取區間總和」，差分陣列解決「多次寫入區間增量後再取得結果」。若有 n 個元素、q 次操作，直接逐區間處理最壞可達 O(nq)，而這兩種方法通常能把總成本降為 O(n + q)。

  • 原陣列頻繁單點修改時，靜態前綴和不再方便
  • 差分更新期間不適合立即查詢任意區間的最終值
  • 區間是閉區間或半開區間必須從一開始統一
技巧主要用途預處理／還原單次操作
前綴和靜態區間和查詢O(n)查詢 O(1)
差分陣列批次區間加值還原 O(n)更新 O(1)
KEY IDEA

公式錯誤多半來自區間定義不一致；建議把 [left, right] 是否包含端點寫在函式說明中。

RECAP

這堂課要帶走的事

  1. 01前綴和以 O(n) 預處理換取 O(1) 區間和查詢。
  2. 02前導零讓閉區間公式統一為 prefix[right + 1] - prefix[left]。
  3. 03差分陣列以端點標記，把 q 次區間更新與還原控制在 O(q + n)。

CHECK YOURSELF

先想一想，再看答案

為什麼 prefix 陣列通常比原陣列多一格？

prefix[0] 可表示零個元素的總和，使從索引 0 開始的區間也能使用相同減法公式。

對閉區間 [left, right] 加 amount，為什麼要在 right + 1 扣回 amount？

扣回代表加值效果從 right 的下一個位置起停止，累積差分時便只影響指定閉區間。

PRACTICE

延伸練習

  1. 建立前綴和並回答多筆區間平均值查詢。
  2. 給定多段日期與訪客增量，用差分陣列計算每天的總訪客數。
