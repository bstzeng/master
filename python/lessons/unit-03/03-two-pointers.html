Two Pointers 雙指標

利用資料順序協調兩個索引

基礎25 分鐘PYTHON 3

WHY THIS MATTERS

理解左右夾逼與同向移動，並以已排序陣列配對和為例。

LEARNING GOALS

  • 辨認雙指標的兩種常見移動方式
  • 利用排序性排除不可能答案
  • 說明雙指標為何只需線性時間
01

兩個索引如何合作

雙指標（Two Pointers）同時維護兩個位置，常見形式是從左右兩端向中間靠近，或讓快慢指標同向前進。它適合能依目前結果決定要移動哪一側的問題，而不是單純把兩層迴圈換成兩個變數。

  • 左右夾逼：回文、已排序陣列配對
  • 同向指標：原地去重、篩選元素
  • 移動規則必須保證不會漏掉可能答案
02

已排序陣列的配對和

在遞增陣列中，左右值相加若太小，移動左指標才能讓總和變大；若太大，則移動右指標讓總和變小。排序提供了可預測的方向，因此一次移動就能安全排除一批組合。

  • 總和等於目標：回傳答案
  • 總和小於目標：left 向右
  • 總和大於目標：right 向左
03

正確性與複雜度

兩個指標最多各移動 n 次，總移動次數仍與 n 成正比，所以時間是 O(n)，額外空間是 O(1)。若輸入尚未排序而先進行排序，整體時間會成為 O(n log n)，並且要注意排序後索引可能改變。

  • 每次迴圈至少移動一個指標，避免無限迴圈
  • 先確認題目是否允許排序或已保證有序
  • 需要原索引時，不可忽略排序造成的位置變化
KEY IDEA

雙指標的核心不是「有兩個指標」，而是能根據單調關係排除答案。

RECAP

這堂課要帶走的事

  1. 01雙指標可左右夾逼，也可同向移動。
  2. 02已排序資料讓配對和能依總和大小決定移動方向。
  3. 03指標各自單向移動時，整體通常是 O(n)。

CHECK YOURSELF

先想一想，再看答案

已排序陣列的左右總和小於目標時，為什麼要移動左指標？

右端已是目前最大可選值；若連它相加都太小，保留較小的左值不可能達標，因此必須換成更大的左值。

未排序陣列先排序再用雙指標，時間複雜度是多少？

排序需 O(n log n)，雙指標需 O(n)，因此整體是 O(n log n)。

PRACTICE

延伸練習

  1. 忽略大小寫與非英數字元，判斷一句文字是否為回文。
  2. 在已排序陣列中找出與目標值最接近的兩數總和。
