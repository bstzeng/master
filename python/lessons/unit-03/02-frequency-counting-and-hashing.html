UNIT 03 / LESSON 02

Array and String Techniques

字元統計與雜湊表

把重複搜尋改成一次統計與快速查找

入門25 分鐘PYTHON 3

WHY THIS MATTERS

使用 dictionary 與 set 建立頻率表，解決字元計數與異位詞判斷。

LEARNING GOALS

  • 以 dictionary 建立頻率表
  • 區分 set 與 dictionary 的用途
  • 以雜湊降低重複搜尋成本
01

頻率表保留出現次數

雜湊表（Hash Table）能把字元或數值當作鍵，並將出現次數保存為值。走訪資料一次就能完成統計，之後不必為每個項目重新掃描整段資料。

  • dictionary 適合保存「項目 → 次數」
  • dict.get(key, 0) 能處理第一次出現的鍵
  • set 只回答是否存在，不保存出現幾次
02

經典題型：判斷異位詞

兩個字串若由完全相同的字元與次數組成，就是異位詞（Anagram）。先排除長度不同的情況，再比較兩份頻率表，便能直接表達問題條件。

  • 字元順序不同不影響結果
  • 字元種類相同但次數不同，仍不是異位詞
  • 是否忽略大小寫或空白，應由題目明確決定
03

效率與雜湊限制

設兩字串總長度為 n，建立與核對頻率表的平均時間是 O(n)，空間是 O(k)，其中 k 是不同字元數。dictionary 的查找平均為 O(1)，但這是雜湊表的平均表現，不代表所有情況都保證固定時間。

  • 有限字元集下，k 有固定上限
  • 一般 Unicode 文字中，k 最多可隨 n 成長
  • 排序解異位詞通常需要 O(n log n) 時間
KEY IDEA

看到大量「是否存在」或「出現幾次」的查詢時，先考慮 set 或 dictionary。

RECAP

這堂課要帶走的事

  1. 01dictionary 保存次數，set 保存是否出現。
  2. 02頻率表能把多次線性搜尋改為一次統計。
  3. 03雜湊解法平均耗時 O(n)，空間取決於不同鍵的數量。

CHECK YOURSELF

先想一想，再看答案

為什麼 set 不適合直接判斷 aab 與 abb 是否為異位詞？

兩者的 set 都是 {a, b}，但 set 沒有保存每個字元的次數。

頻率表中 k 代表什麼？

k 代表不同鍵的數量，例如字串中不同字元的種類數，也就是雜湊表最多需要保存的項目數。

PRACTICE

延伸練習

  1. 找出字串中第一個只出現一次的字元索引。
  2. 給定兩個整數陣列，判斷它們是否擁有完全相同的元素頻率。
