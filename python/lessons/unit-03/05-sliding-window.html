UNIT 03 / LESSON 05

Array and String Techniques

Sliding Window 滑動視窗

重用相鄰區間的計算結果

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

從固定長度視窗理解增量更新，再延伸到可伸縮的動態視窗。

LEARNING GOALS

  • 辨認連續區間問題
  • 維護固定長度視窗的統計值
  • 理解動態視窗的擴張與收縮條件
01

相鄰區間只差兩個元素

滑動視窗（Sliding Window）處理連續子陣列或子字串。固定長度 k 的視窗向右移一步時，只要扣除離開的元素並加入新元素，不必重新加總整個區間。

  • 視窗代表目前正在考慮的連續範圍
  • 先建立第一個視窗，再逐步向右更新
  • k 必須符合 1 ≤ k ≤ 序列長度
02

動態視窗會依條件收縮

視窗長度不固定時，通常讓 right 負責擴張，當視窗違反條件，再移動 left 直到恢復有效。能否使用此模式取決於條件是否具有可預測性，例如正整數總和過大時，移除左端元素一定不會讓總和更大。

  • right 加入新元素並更新狀態
  • while 條件不成立時移動 left
  • 每次狀態改變都要同步更新計數或總和
03

判斷適用性與複雜度

雖然動態視窗中有 for 與 while，left 和 right 都只會向右移動至多 n 次，所以時間是 O(n)，額外空間依維護狀態而定。若資料含負數，總和不再隨擴張或收縮保持單調，上述最短區間解法便可能失效。

  • 題目需關注連續區間，而非任意挑選元素
  • 固定視窗通常維護加入與移除的差異
  • 動態視窗必須有明確且安全的收縮規則
KEY IDEA

看到巢狀 while 不要立刻判定 O(n²)；應計算每個指標總共移動幾次。

RECAP

這堂課要帶走的事

  1. 01滑動視窗重用相鄰連續區間的計算結果。
  2. 02固定視窗移除左端並加入右端，動態視窗則依條件收縮。
  3. 03兩個邊界都只單向移動時，總時間通常是 O(n)。

CHECK YOURSELF

先想一想，再看答案

固定長度 k 的視窗右移時，總和要如何更新？

加入新的右端元素，並扣除剛離開視窗的左端元素。

為什麼最短總和視窗範例要求元素皆為正整數？

正數讓擴張不會減少總和、收縮不會增加總和，因此能依總和大小安全決定移動方向。

PRACTICE

延伸練習

  1. 求長度為 k 的連續子陣列最大平均值。
  2. 在只含正整數的陣列中，求總和不超過 target 的最長連續區間。
