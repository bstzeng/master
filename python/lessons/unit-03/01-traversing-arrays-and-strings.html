UNIT 03 / LESSON 01

Array and String Techniques

陣列與字串走訪

從索引、元素與相鄰關係建立基本功

入門20 分鐘PYTHON 3

WHY THIS MATTERS

比較直接走訪與索引走訪，練習處理相鄰元素及常見邊界。

LEARNING GOALS

  • 依需求選擇元素走訪或索引走訪
  • 避免索引超出範圍
  • 分析一次線性掃描的複雜度
01

先決定走訪時需要什麼

陣列與字串都能由左到右讀取；如果只需要元素，就直接迭代，如果還需要位置，則使用 enumerate。先釐清是否會查看前後鄰居，可避免不必要的索引操作。

  • 只讀取值：for value in values
  • 同時需要位置和值：for index, value in enumerate(values)
  • 字串不可變；修改字元通常先轉成 list 或建立新字串
02

相鄰比較與邊界

比較目前元素與下一個元素時，最後一個位置沒有下一個鄰居，所以迴圈只能走到 len(values) - 2。把有效索引範圍先寫清楚，比在迴圈中捕捉 IndexError 更容易驗證。

  • 合法索引是 0 到 len(values) - 1
  • 查看 values[index + 1] 時使用 range(len(values) - 1)
  • 空序列與單一元素通常需要確認是否仍符合題意
03

線性走訪的成本

走訪長度為 n 的序列一次，時間複雜度是 O(n)。範例只使用固定數量的計數變數，額外空間是 O(1)；若收集符合條件的索引，最壞情況會使用 O(n) 空間。

  • 一次完整掃描通常是 O(n)
  • 巢狀迴圈不一定都是 O(n²)，要看各層實際走訪範圍
  • 輸出本身有 n 個項目時，O(n) 輸出空間通常無法避免
KEY IDEA

分析額外空間時，應說明是否把回傳結果的空間計算在內。

RECAP

這堂課要帶走的事

  1. 01只需元素時直接迭代，需要位置時使用 enumerate。
  2. 02存取相鄰元素前，先縮小索引走訪範圍。
  3. 03一次線性走訪耗時 O(n)，額外空間取決於是否收集結果。

CHECK YOURSELF

先想一想，再看答案

為什麼比較 values[index] 與 values[index + 1] 時不能走到最後一個索引？

最後一個索引再加一會超出序列範圍，因此迴圈應使用 range(len(values) - 1)。

只想把所有元素加總時，需要使用 enumerate 嗎？

不需要，直接走訪元素即可，因為計算過程不使用索引。

PRACTICE

延伸練習

  1. 寫一個函式，回傳陣列中第一個負數的索引；若不存在則回傳 -1。
  2. 計算字串中相鄰且相同的字元對數，例如 aabcc 有兩對。
