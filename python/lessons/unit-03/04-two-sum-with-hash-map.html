UNIT 03 / LESSON 04

Array and String Techniques

經典題型：Two Sum

用互補值把 O(n²) 降為平均 O(n)

基礎25 分鐘PYTHON 3

WHY THIS MATTERS

從暴力配對推導出雜湊表解法，並處理索引與重複值。

LEARNING GOALS

  • 說明暴力解法的重複工作
  • 以雜湊表查找互補值
  • 正確處理相同數值與索引限制
01

從所有配對開始思考

Two Sum 要找出兩個不同索引，使其數值總和等於 target。暴力法為每個位置檢查後方所有位置，概念直接但會產生約 n² 個配對。

  • 同一個元素不能使用兩次
  • 題目通常要求回傳索引，而非數值
  • 暴力解法時間 O(n²)、額外空間 O(1)
02

儲存看過的數值

走到目前數值 value 時，需要的互補值是 target - value。若互補值已在 seen 中，就找到一對答案；否則把目前數值與索引記錄起來，供後面的元素查找。

  • seen 的鍵是數值，值是先前索引
  • 先查找再寫入，確保使用兩個不同索引
  • 重複數值可正常處理，例如 [3, 3] 與 target 6
03

時間換空間

雜湊表平均 O(1) 查找讓整體平均時間降為 O(n)，最壞需保存 n 個項目，因此額外空間是 O(n)。這是典型的空間換時間：使用更多記憶體，避免重複掃描。

  • 若輸入保證恰有一組答案，可找到後立即回傳
  • 若需全部配對，資料結構與重複值處理方式要重新設計
  • 已排序輸入也可用雙指標，以 O(1) 額外空間求解
KEY IDEA

修改題目輸出要求時，不要直接假設同一份 Two Sum 程式仍然正確。

RECAP

這堂課要帶走的事

  1. 01Two Sum 的關鍵查詢是 target - value 是否曾經出現。
  2. 02先查找再記錄可避免重複使用同一索引。
  3. 03雜湊解法平均時間 O(n)、額外空間 O(n)。

CHECK YOURSELF

先想一想，再看答案

為什麼不能先把目前值寫入 seen，再查找互補值？

當目前值剛好等於自己的互補值時，可能錯誤地使用同一索引兩次；先查找可確保互補值來自先前位置。

雜湊表解法相較暴力法付出什麼代價？

額外使用最多 O(n) 空間保存已看過的數值與索引，以換取平均 O(n) 時間。

PRACTICE

延伸練習

  1. 修改 Two Sum，使找不到答案時回傳 None，並補上空陣列與單元素測試。
  2. 給定已排序陣列，改用雙指標完成 Two Sum，並比較空間複雜度。
