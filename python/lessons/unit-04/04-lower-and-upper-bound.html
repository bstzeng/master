Searching Algorithms

Lower Bound 與 Upper Bound

在重複值中找插入邊界，而不只找任一相符位置

中階28 分鐘PYTHON 3

WHY THIS MATTERS

使用半開區間模板尋找第一個大於等於或第一個大於目標的位置，並以邊界差計算出現次數。

LEARNING GOALS

  • 定義 Lower Bound 與 Upper Bound
  • 實作兩種邊界搜尋
  • 應用邊界求範圍與出現次數
01

搜尋的是分界點

Lower Bound 是第一個大於等於 target 的位置，Upper Bound 是第一個嚴格大於 target 的位置。兩者都允許回傳 len(items)，表示分界在所有元素之後；因此它們同時也是維持排序時的插入位置。

  • Lower Bound：第一個 value >= target
  • Upper Bound：第一個 value > target
  • 不存在相符值時仍會回傳合法插入位置
  • 輸入必須按相同規則排序
02

半開區間實作

搜尋期間維持 [left, right)；符合邊界條件時，middle 可能就是答案，因此保留它並令 right = middle。否則 middle 與左側都不可能是第一個符合位置，令 left = middle + 1，最後 left == right 即為分界。

  • Lower Bound 判斷 items[middle] >= target
  • Upper Bound 只需改成 items[middle] > target
  • 每輪候選範圍都嚴格縮小
03

從兩個邊界得到範圍

在排序序列中，等於 target 的元素恰好位於 [lower_bound, upper_bound)，所以出現次數是兩者相減。若差為零就代表不存在；要取第一個相符索引時，還應檢查 lower 是否小於 n 且 items[lower] 等於 target。

  • 出現次數 = upper - lower
  • 相符範圍使用半開區間 [lower, upper)
  • 先檢查邊界再讀取 items[lower]
  • Python 標準庫 bisect_left 與 bisect_right 提供相同概念

RECAP

這堂課要帶走的事

  1. 01Lower Bound 找第一個大於等於，Upper Bound 找第一個嚴格大於
  2. 02邊界可能等於 len(items)，讀取元素前要檢查
  3. 03兩個邊界的差就是排序資料中目標的出現次數

CHECK YOURSELF

先想一想，再看答案

在 [1, 3, 3, 3, 8] 中，target = 3 的 lower 與 upper 是多少？

lower 是 1，upper 是 4，因此 3 出現 4 - 1 = 3 次。

在 [2, 4, 6] 中搜尋 target = 9 的 Lower Bound 回傳什麼？

回傳 3，也就是 len(items)；9 應插在所有元素之後。

PRACTICE

延伸練習

  1. 用 lower_bound 與 upper_bound 寫出 count_occurrences(items, target)。
  2. 列出 target 小於最小值、大於最大值、不存在於中間與重複出現時的預期邊界。
