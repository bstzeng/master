Searching Algorithms

二分搜尋的邊界處理

用區間語意與不變量消除 off-by-one 錯誤

中階25 分鐘PYTHON 3

WHY THIS MATTERS

比較閉區間與半開區間，學會檢查終止條件、更新規則與邊界測試。

LEARNING GOALS

  • 說明區間不變量
  • 一致使用閉區間或半開區間模板
  • 以系統化測試找出邊界錯誤
01

先決定區間代表什麼

二分搜尋常見錯誤不是不懂減半，而是混用不同區間的規則。閉區間 [left, right] 包含兩端；半開區間 [left, right) 不包含 right，兩者的初始值、迴圈條件與更新方式必須成套使用。

  • 閉區間初始 right = n - 1
  • 半開區間初始 right = n
  • 不要從一個模板拿條件、從另一個模板拿更新式
項目閉區間 [left, right]半開區間 [left, right)
初始值0, n - 10, n
非空條件left <= rightleft < right
排除 middle 後縮右界right = middle - 1right = middle
終止時left > rightleft == right
02

不變量是除錯工具

可以把不變量寫成『若答案存在，它一定還在目前候選區間』。每次比較後，只排除已證明不可能的部分，並確認區間嚴格縮小；若某條分支仍保留 middle，就要特別確認不會永遠卡在同一位置。

  • 更新前說明哪一段已不可能有答案
  • 更新後確認候選範圍變小
  • 整數除法方向會影響 middle 的位置
  • Python 不會整數溢位，但公式仍應保持清楚
KEY IDEA

看到無限迴圈時，先檢查某個分支是否把 left 或 right 留在原值。

03

用最小案例壓測邊界

空序列、單一元素、兩個元素、目標在最左或最右，最容易暴露 off-by-one 錯誤。含重複值時，基本二分搜尋只保證找到任一相符位置；若需求是第一個或最後一個位置，必須改用下一課的邊界搜尋。

  • 測試空序列與單一元素
  • 測試目標小於最小值或大於最大值
  • 測試兩元素序列的左右位置
  • 先寫清楚重複值的預期結果

RECAP

這堂課要帶走的事

  1. 01二分搜尋的初始值、條件與更新必須符合同一區間語意
  2. 02候選區間不變量能指導正確更新並保證終止
  3. 03最小與邊界案例是發現 off-by-one 錯誤的有效工具

CHECK YOURSELF

先想一想，再看答案

半開區間 [left, right) 為何初始 right 可以等於 len(items)？

因為 right 本來就不包含在候選區間內；有效索引仍只到 len(items) - 1。

更新式寫成 left = middle，可能出現什麼問題？

若 middle 恰好等於 left，區間不會縮小而可能無限迴圈；除非模板與取中點方式特別設計，通常應排除 middle。

PRACTICE

延伸練習

  1. 選擇閉區間或半開區間模板，逐項寫出初始值、條件、左右更新與終止狀態。
  2. 故意將 binary_search 的 right = middle - 1 改成 right = middle，找出一個會卡住或產生錯誤的測試。
