UNIT 16 / LESSON 08

Problem Solving and Algorithm Design

邊界條件與測試案例

用分類與性質捕捉錯誤

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

建立範例、邊界、反例與性質測試。

LEARNING GOALS

  • 分類輸入
  • 設計最小反例
  • 使用 oracle 測試
01

測試分類

至少覆蓋正常、最小、最大、空、單元素、重複、已排序與反序。不是每題都適用，但應逐項判斷。

  • 索引題測第一與最後位置
  • 數值題測零與負數
  • 圖題測孤立點與不連通
02

針對不變量造案例

每個演算法都有脆弱假設，例如視窗單調、二分邊界或 DP 初值。測試應直接攻擊這些假設，而非只增加隨機資料量。

  • abba 測視窗左界不倒退
  • 全負數測 Kadane 初值
  • 兩元素測二分相鄰邊界
03

Oracle 與性質

小輸入可用暴力法作 oracle，隨機產生案例比較答案。沒有唯一輸出時，改驗證必要性質，例如拓樸序中每條邊方向都正確。

  • 固定亂數種子便於重現
  • 比較結果前先統一順序語意
  • 測試失敗要保存最小案例

RECAP

這堂課要帶走的事

  1. 01測試要涵蓋輸入類別與演算法假設。
  2. 02小型反例比大型隨機資料容易除錯。
  3. 03暴力 oracle 與性質驗證都很實用。

CHECK YOURSELF

先想一想，再看答案

為何只測官方範例不足？

它通常未覆蓋所有邊界與錯誤假設。

輸出不唯一如何測？

驗證輸出滿足規格性質，而非固定內容。

PRACTICE

延伸練習

  1. 為二分搜尋列出六個邊界案例。
  2. 用暴力法交叉測試一個滑動視窗解。
