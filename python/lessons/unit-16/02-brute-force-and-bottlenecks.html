UNIT 16 / LESSON 02

Problem Solving and Algorithm Design

Brute Force 與瓶頸

先建立正確基準，再消除重複工作

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

以配對和展示基準解、量測與瓶頸定位。

LEARNING GOALS

  • 寫出基準解
  • 定位昂貴操作
  • 提出可驗證優化
01

Brute Force 是規格模型

暴力法直接枚舉所有合法候選，常最容易驗證。它可產生小輸入正解，作為優化版的測試 oracle。

  • 先求正確再求快
  • 明確列出候選空間
  • 保留小型基準版本
02

找最內層重複

檢查巢狀迴圈、重複排序、重算區間和與線性 membership。Two Sum 的瓶頸是為每個值重找互補值。

  • 問哪些答案曾算過
  • 問查找能否由 O(n) 降為 O(1)
  • 問是否可增量維護
03

一次只改一個瓶頸

以 set 保存已見值後，Two Sum 平均降為 O(n)，代價是 O(n) 空間。優化後仍用暴力版交叉驗證隨機小案例。

  • 記錄改變前後複雜度
  • 確認語意與輸出未改變
  • 空間換時間要明說

RECAP

這堂課要帶走的事

  1. 01暴力法提供正確性基準。
  2. 02瓶頸常是重複計算或慢查找。
  3. 03優化後應與基準解交叉測試。

CHECK YOURSELF

先想一想，再看答案

為何不立即刪掉暴力版？

它可驗證優化版的小輸入結果。

Two Sum 優化代價？

使用 O(n) 額外雜湊空間。

PRACTICE

延伸練習

  1. 為區間和寫暴力版與前綴和版。
  2. 找出三層迴圈中真正隨 n 成長的工作。
