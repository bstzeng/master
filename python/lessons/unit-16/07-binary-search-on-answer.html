UNIT 16 / LESSON 07

Problem Solving and Algorithm Design

Binary Search on Answer

在單調可行性上搜尋最佳答案

進階35 分鐘PYTHON 3

WHY THIS MATTERS

把最佳化問題轉為單調判定函式。

LEARNING GOALS

  • 定義搜尋範圍
  • 建立 monotonic predicate
  • 處理邊界模板
01

搜尋的不是陣列

若答案 x 的可行性具有單調性，就能在答案範圍二分。例如運送容量愈大愈可行，可尋找第一個可行容量。

  • 先定義 feasible(x)
  • 證明 False…False,True…True
  • 找清楚下界與上界
02

第一個可行模板

維持閉區間 [low,high]，可行時保留 mid 並向左，不可行時向右。迴圈結束的 low 是第一個可行值。

  • mid=(low+high)//2
  • feasible(mid) 時 high=mid
  • 否則 low=mid+1
03

驗證單調與上界

若 feasible 不是單調，二分會丟掉可能答案；若 high 不保證可行，回傳值也無意義。用最小、最大與相鄰邊界測試 off-by-one。

  • 先 assert feasible(high)
  • 測答案等於 low 或 high
  • 整數與浮點二分終止條件不同
KEY IDEA

二分前先寫出可行性序列的形狀。

RECAP

這堂課要帶走的事

  1. 01答案二分依賴單調 predicate。
  2. 02搜尋範圍必須包住答案。
  3. 03總成本是判定成本乘二分次數。

CHECK YOURSELF

先想一想，再看答案

high 不可行有何問題？

區間可能根本不含答案。

什麼情況不能答案二分？

可行性隨 x 非單調變化時。

PRACTICE

延伸練習

  1. 求最小可在 D 天運完貨物的容量。
  2. 為平方根整數下界設計 feasible。
