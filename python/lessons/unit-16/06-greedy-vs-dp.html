Problem Solving and Algorithm Design

Greedy vs DP 選型

局部決定能否安全固定

進階30 分鐘PYTHON 3

WHY THIS MATTERS

用硬幣與區間案例比較貪心證明與 DP 狀態。

LEARNING GOALS

  • 辨認貪心需求
  • 找反例
  • 改建 DP
01

Greedy 固定當下選擇

貪心每步選看似最佳且不回頭，必須證明存在交換性或貪心選擇性。區間排程選最早結束者可留下最大後續空間。

  • 速度通常快且狀態少
  • 局部合理不等於全域正確
  • 先嘗試交換論證
02

反例是快速檢查

硬幣 [1,3,4] 湊 6 時，先拿 4 得三枚，而 3+3 只需兩枚，推翻最大面額貪心。小型窮舉很適合找反例。

  • 測非典型與邊界組合
  • 反例只需一個
  • 失敗後找重疊子問題
03

DP 保留多條可能

若當下選擇會影響未來且無法安全固定，DP 以狀態保存不同子問題最佳值。代價通常是更多時間與空間。

  • Greedy 需正確性證明
  • DP 需重疊子問題與最佳子結構
  • 先問能否不可逆地丟棄其他選擇
方法核心問題
Greedy局部選擇可安全固定嗎？
DP需保存哪些子問題答案？

CHECK YOURSELF

先想一想，再看答案

一個反例能否推翻貪心？

能，演算法宣稱對所有合法輸入正確。

DP 一定比 Greedy 好嗎？

不是；若貪心可證明正確，通常更省資源。

PRACTICE

延伸練習

  1. 為最大面額硬幣策略再找一個反例。
  2. 比較活動選擇用 Greedy 與 DP 的狀態。
