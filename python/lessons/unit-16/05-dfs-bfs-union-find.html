Problem Solving and Algorithm Design

DFS、BFS 與 Union-Find 選型

路徑、距離或只問連通

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

依輸出需求選擇圖演算法。

LEARNING GOALS

  • 比較三種工具
  • 處理多元件
  • 辨認不適用情境
01

DFS 探索結構

DFS 適合可達性、列舉路徑、回溯與結構判斷。它深入優先，不保證未加權最短路徑。

  • 使用 Stack 或遞迴
  • 圖需 visited
  • 時間 O(V+E)
02

BFS 求層級距離

BFS 依邊數由近到遠，適合未加權最短路徑與擴散時間。加權邊則需依權重改用 Dijkstra 等方法。

  • 使用 deque
  • 入列時標記
  • 可由多起點同時開始
03

Union-Find 只維護群組

Union-Find 適合邊逐步加入時的連通查詢與無向環偵測，近似常數攤銷操作。它無法還原路徑，也不擅長刪邊。

  • 只問兩點是否同集合
  • 需要實際路徑改用搜尋
  • 多元件 DFS/BFS 要從每個未訪點啟動
需求選擇
深度探索DFS
未加權最短BFS
動態連通Union-Find

  3. 03Union-Find 適合只問動態連通。

CHECK YOURSELF

先想一想，再看答案

要回傳最短路徑為何不選 Union-Find？

它只保存集合代表元，不保存實際路徑。

DFS 從一點開始會漏什麼？

會漏掉其他不連通元件。
