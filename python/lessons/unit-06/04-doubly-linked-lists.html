UNIT 06 / LESSON 04

Linked Lists

雙向鏈結串列

用 prev 與 next 支援雙向移動

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

建立雙向節點，練習尾端加入與已知節點刪除時的對稱接線。

LEARNING GOALS

  • 說明 prev 與 next 的雙向關係
  • 維護 head 與 tail
  • 安全刪除已知雙向節點
01

每條連結都有反方向

雙向鏈結串列（Doubly Linked List）的節點同時保存 prev 與 next，因此可從 head 向後走，也可從 tail 向前走。代價是每個節點多一個參照，接線時也必須維持兩個方向一致。

  • 文字圖：None ← [10] ⇄ [20] ⇄ [30] → None
  • head.prev 應為 None，tail.next 應為 None
  • 若 A.next 是 B，正常情況下 B.prev 也應是 A
02

尾端加入要接兩個方向

尾端加入 new_node 時，舊 tail.next 要指向新節點，新節點的 prev 也要回指舊 tail，最後才更新 tail。空串列沒有舊尾端，因此 head 與 tail 必須同時指向第一個節點。

  • 加入前：[old_tail] → None
  • 接線後：[old_tail] ⇄ [new_node] → None
  • 最後更新 self.tail = new_node
03

刪除已知節點

刪除 node 時，讓左鄰居與右鄰居互相連接；若某側不存在，就代表需要更新 head 或 tail。已經握有 node 參照時，刪除時間是 O(1)，但先按值搜尋 node 仍需 O(n)。

  • 中間刪除：[left] ⇄ [node] ⇄ [right] 變成 [left] ⇄ [right]
  • node.prev 為 None 時更新 head
  • node.next 為 None 時更新 tail

RECAP

這堂課要帶走的事

  1. 01雙向節點以 prev 與 next 維持對稱連結。
  2. 02head 與 tail 讓兩端操作都能在 O(1) 完成。
  3. 03已知節點的刪除是 O(1)，按值尋找後刪除則是 O(n)。

CHECK YOURSELF

先想一想，再看答案

在 A 與 B 之間加入 X，至少要建立哪兩個方向的直接關係？

要讓 A.next 與 X.prev 互相對應，也要讓 X.next 與 B.prev 互相對應，共維護四個欄位。

刪除 tail 節點時，新的 tail 是誰？

新的 tail 是舊 tail.prev，並且它的 next 應更新為 None；若不存在前一節點，串列會變空。

PRACTICE

延伸練習

  1. 為 DoublyLinkedList 實作 prepend，在頭端 O(1) 加入節點。
  2. 寫一個函式從 tail 沿 prev 走訪，回傳反向的數值清單。
