UNIT 06 / LESSON 05

Linked Lists

反轉鏈結串列

以三個參照逐條翻轉箭頭

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

以 previous、current 與 next_node 迭代反轉單向鏈結串列。

LEARNING GOALS

  • 說明反轉時為何要先保存下一站
  • 實作迭代反轉
  • 追蹤反轉過程中的不變量與複雜度
01

斷開前先保存下一站

反轉要把每條 A → B 改成 A ← B，但改寫 current.next 之前必須先把原下一站存入 next_node。否則後半段串列會失去可達參照，無法繼續處理。

  • previous：已反轉區段的開頭
  • current：本輪要翻轉箭頭的節點
  • next_node：尚未反轉區段的下一站
02

逐輪閱讀指標圖

以 10 → 20 → 30 為例，第一輪先保存 20，再把 10.next 指向 None；此時已反轉區是 10 → None，未處理區仍從 20 開始。每輪完成後，previous 與 current 一起向原串列右方移動。

  • 開始：previous=None，current=[10] → [20] → [30]
  • 第一輪後：previous=[10] → None，current=[20] → [30]
  • 結束：previous=[30] → [20] → [10] → None
03

不變量與成本

每輪開始時，previous 指向已完整反轉的前段，current 指向尚未處理的第一個節點，這是不變量。每個節點只處理一次，時間 O(n)，並只使用三個參照，額外空間 O(1)。

  • 空串列反轉後仍為 None
  • 單一節點的 next 仍為 None
  • 遞迴版本時間也是 O(n)，但呼叫堆疊需 O(n) 空間
KEY IDEA

反轉最常見的錯誤是先改 current.next，才嘗試取得原本的下一站。

RECAP

這堂課要帶走的事

  1. 01改寫 current.next 前，必須先保存 next_node。
  2. 02previous 是已反轉區入口，最後會成為新 head。
  3. 03迭代反轉時間 O(n)、額外空間 O(1)。

CHECK YOURSELF

先想一想，再看答案

反轉迴圈中，next_node = current.next 為什麼必須排在 current.next = previous 前？

後者會覆寫通往未處理節點的唯一連結；先保存 next_node 才能繼續走訪原串列。

迴圈結束時為什麼回傳 previous，而不是 current？

current 已走過原尾端而成為 None，previous 才指向反轉後的第一個節點。

PRACTICE

延伸練習

  1. 在紙上逐輪追蹤 1 → 2 → 3 → 4 的 previous、current 與 next_node。
  2. 實作一個回傳新 head 的遞迴反轉版本，並說明其空間複雜度。
