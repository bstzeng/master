UNIT 06 / LESSON 01

Linked Lists

Node 與單向鏈結串列

用節點參照串起一條資料鏈

入門25 分鐘PYTHON 3

WHY THIS MATTERS

認識節點、head 與 next，並從陣列建立及讀回單向鏈結串列。

LEARNING GOALS

  • 說明節點的資料與連結欄位
  • 以 head 表示串列起點
  • 從 Python list 建立鏈結串列
01

節點不是索引格子

鏈結串列（Linked List）由分散的節點組成，每個節點保存資料以及下一個節點的參照。單向鏈結串列只能沿 next 向前走，最後一個節點的 next 是 None。

  • Node(value, next) 可讀成「資料加下一站」
  • head 指向第一個節點；空串列的 head 是 None
  • 文字圖：head → [10] → [20] → [30] → None
02

從陣列建立資料鏈

若依輸入順序建立串列，可保留 head 與 tail 兩個參照，每加入一個節點就把舊 tail.next 指向新節點。接線順序可讀成「舊尾端 → 新節點」，再將 tail 移到新節點。

  • 空串列加入第一個節點時，head 與 tail 都指向它
  • 後續加入：tail.next = new_node，再更新 tail
  • 文字圖：[舊 tail] → [new_node]，tail 再移到右側
03

與 Python list 的差異

建立 n 個節點需要 O(n) 時間與 O(n) 節點空間。鏈結串列無法像 Python list 一樣用索引 O(1) 取得第 i 個元素，但已知插入位置的節點時，接線可在 O(1) 完成。

  • 鏈結串列的節點不要求在記憶體中連續排列
  • 取得第 i 個節點要從 head 走訪，時間 O(n)
  • 每個節點除了資料，也需保存 next 參照
KEY IDEA

Python 的 list 是動態陣列，不是本單元所說的鏈結串列。

RECAP

這堂課要帶走的事

  1. 01單向節點保存 value 與指向下一站的 next。
  2. 02head 是串列入口，None 表示沒有下一個節點。
  3. 03鏈結串列擅長接線操作，但不支援常數時間的任意索引。

CHECK YOURSELF

先想一想，再看答案

空的單向鏈結串列中，head 應該是什麼？

head 應為 None，表示目前沒有第一個節點。

為什麼取得鏈結串列第 i 個元素不是 O(1)？

節點沒有可直接定位的連續索引，必須從 head 沿 next 逐節點走到目標位置。
