UNIT 06 / LESSON 03

Linked Lists

插入與刪除

先保存需要的參照，再重新接線

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

練習頭端與中間位置的插入刪除，並用 dummy node 統一邊界。

LEARNING GOALS

  • 正確安排插入時的接線順序
  • 以 previous 略過待刪節點
  • 使用 dummy node 簡化刪除 head 的特例
01

插入：先接後段，再接前段

在 node 後插入 new_node 時，必須先讓 new_node.next 保存原本後繼，再把 node.next 改指向 new_node。若先覆寫 node.next，原本的後半段就可能失去可達路徑。

  • 插入前：[A] → [B]
  • 第一步：[new] → [B]
  • 第二步：[A] → [new] → [B]
02

刪除：讓前一站略過目標

刪除 current 的本質，是讓 previous.next 直接指向 current.next。搜尋待刪節點時需同時保留 previous；如果目標就是 head，則必須更新 head 本身。

  • 刪除前：[previous] → [current] → [next]
  • 接線後：[previous] ─────────→ [next]
  • 刪除 head 時，新 head 是舊 head.next
03

Dummy Node 統一頭端特例

虛擬節點（Dummy Node）放在真正 head 前方，讓每個待刪節點都擁有 previous，因此不必另外處理刪除第一個節點。已知插入或刪除位置時接線是 O(1)，但若要先搜尋位置，整體仍是 O(n)。

  • 文字圖：[dummy] → [head] → ...
  • 刪除完成後回傳 dummy.next，而不是 dummy
  • dummy 的 value 通常不參與資料語意

RECAP

這堂課要帶走的事

  1. 01插入前先保存並接上原本後繼，避免斷鏈。
  2. 02刪除節點是讓前一個節點略過它。
  3. 03dummy node 能把 head 的邊界操作轉成一般接線。

CHECK YOURSELF

先想一想，再看答案

為什麼插入時要先執行 new_node.next = node.next？

這一步先保存原本後繼；若先改 node.next，可能失去通往後半段串列的參照。

使用 dummy node 刪除後，為什麼回傳 dummy.next？

dummy 只是輔助節點，真正串列的第一個節點位於 dummy.next，而且刪除原 head 後這個位置會自動更新。

PRACTICE

延伸練習

  1. 實作 prepend(head, value)，在頭端插入節點並回傳新 head。
  2. 使用 dummy node 刪除串列中所有等於 target 的節點。
