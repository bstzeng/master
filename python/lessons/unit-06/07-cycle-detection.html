UNIT 06 / LESSON 07

Linked Lists

環狀鏈結串列偵測

用 Floyd 演算法在常數空間判斷是否成環

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

從 visited set 推導 Floyd 快慢指標，並延伸尋找環的入口。

LEARNING GOALS

  • 說明環會使一般走訪無法到達 None
  • 實作 visited set 與 Floyd 偵測
  • 使用相遇點找出環入口
01

環讓走訪重返舊節點

若某節點的 next 指回前方節點，串列就形成環（Cycle），一般 while current 走訪將永遠到不了 None。最直覺的方法是用 set 記錄見過的節點參照，再次遇到同一節點便確認有環。

  • 文字圖：[1] → [2] → [3] → [4] ┐，且 [4].next 回到 [2]
  • set 應保存節點物件，而不是 value
  • 不同節點可以擁有相同 value，不能因此判定有環
02

Floyd 快慢指標偵測

Floyd 環偵測讓 slow 每次一步、fast 每次兩步；若沒有環，fast 會先到 None，若有環，較快的 fast 最終會在環內追上 slow。這像兩人在圓形跑道以不同速度同向前進，速度差會逐步縮短環上的相對距離。

  • 檢查 fast 與 fast.next 後，fast 才能安全走兩步
  • 比較 slow is fast，也就是是否為同一節點
  • 時間 O(n)、額外空間 O(1)
03

從相遇點找環入口

slow 與 fast 在環內相遇後，將其中一個指標移回 head，再讓兩者每次各走一步，下一次相遇的位置就是環入口。此結論來自相遇時所走距離的倍數關係，實作仍保持 O(n) 時間與 O(1) 空間。

  • 第一階段：以一倍與兩倍速度找相遇點
  • 第二階段：finder 從 head、slow 從相遇點同速前進
  • 無環時回傳 None，有環時回傳入口節點

RECAP

這堂課要帶走的事

  1. 01環必須依節點身分判斷，不能只比較 value。
  2. 02Floyd 演算法以快慢指標在 O(1) 額外空間偵測環。
  3. 03首次相遇後從 head 與相遇點同速出發，可找出環入口。

CHECK YOURSELF

先想一想，再看答案

為什麼 visited set 應保存節點物件，而不是節點值？

不同節點可能有相同值；成環的定義是再次到達同一個節點物件，而不是再次看見相同資料。

Floyd 演算法中，什麼情況可判定沒有環？

當 fast 變成 None 或 fast.next 是 None 時，快指標已到達有限串列尾端，因此沒有環。

PRACTICE

延伸練習

  1. 建立一條尾端指回第二個節點的串列，分別測試 has_cycle 與 find_cycle_entry。
  2. 延伸計算環的長度：在首次相遇後固定一個指標，另一個繞一圈並計步。
