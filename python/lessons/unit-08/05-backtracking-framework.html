UNIT 08 / LESSON 05

Recursion, Divide and Conquer, and Backtracking

Backtracking 回溯框架

做選擇、深入探索，再撤銷選擇

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

建立狀態空間樹與選擇、遞迴、撤銷的通用回溯骨架。

LEARNING GOALS

  • 描述回溯搜尋的狀態與選項
  • 正確撤銷共享狀態
  • 區分產生答案與判斷存在性
01

回溯是受限制的深度優先探索

回溯法（Backtracking）在狀態空間樹中逐步建立候選答案，每層選一個決定並深入。走到完整答案就記錄；發現不可能成功或探索完成時，退回上一層改試其他選項。

  • 狀態：目前已做的選擇
  • 選項：此狀態下可以採取的下一步
  • 完成條件與無效條件決定何時停止深入
KEY IDEA

回溯通常探索組合空間，最壞時間可能是指數級；它的價值在於系統化且可剪枝。

02

選擇、遞迴、撤銷

若多層遞迴共用同一個 path，加入選項後必須在子呼叫返回時撤銷，讓下一個分支看到原本狀態。這個對稱結構常寫成 append、backtrack、pop。

  • Choose：path.append(choice)
  • Explore：backtrack(...)
  • Unchoose：path.pop()
03

設計介面與複雜度

若要列出所有答案，回溯必須走訪所有可行葉節點；若只問是否存在，找到第一個答案就可傳回 True 提早結束。二元選擇深度 n 最多有 O(2ⁿ) 狀態，堆疊與 path 深度為 O(n)，輸出空間另計。

  • 列舉問題的時間至少與答案數量成正比
  • 存在性搜尋可用布林回傳值提前停止
  • 複製 path 的成本也要納入產生所有答案的時間

RECAP

這堂課要帶走的事

  1. 01回溯在狀態空間樹中以深度優先方式試探選項。
  2. 02共享 path 時，選擇與撤銷必須成對。
  3. 03列舉所有答案與只判斷是否存在，停止策略不同。

CHECK YOURSELF

先想一想，再看答案

為什麼 results.append(path) 常會造成錯誤？

它保存同一個可變 list 的參照，後續 append 或 pop 會改動已保存結果；應加入 path.copy()。

回溯中的撤銷步驟有什麼目的？

它恢復進入本分支前的狀態，確保下一個選項不會受到上一個分支殘留選擇影響。

PRACTICE

延伸練習

  1. 產生長度 n、只含 A 或 B 的所有字串。
  2. 修改二元選擇回溯，只保留恰好含 k 個 1 的答案。
