UNIT 08 / LESSON 06

Recursion, Divide and Conquer, and Backtracking

子集合

每個元素都有選與不選兩條分支

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

以二元決策樹產生所有子集合，並處理含重複元素的輸入。

LEARNING GOALS

  • 把子集合建模成選與不選
  • 寫出索引型回溯
  • 使用排序與同層跳過完成去重
01

選或不選形成 2ⁿ 個答案

對 n 個互異元素，每個元素都可選入或略過，因此共有 2ⁿ 個子集合。回溯的 index 表示目前正在決定哪個元素，走到 index == n 時就完成一個答案。

  • 左分支：不選 numbers[index]
  • 右分支：選 numbers[index]
  • 空集合也是合法子集合
02

另一種寫法：每個節點都是答案

也可在進入每個狀態時立刻保存 path，再從 start 起選擇下一個元素。這種寫法自然產生不同長度的組合，且 start 保證索引只向右前進。

  • 每個 path 本身就是一個子集合
  • 下一層從 index + 1 開始，避免重複選同一位置
  • 輸出順序不同不影響子集合內容正確性
03

重複元素與成本

輸入含重複值時，先排序，並在同一層跳過與前一個相同的候選，可避免產生重複子集合。互異元素版本有 2ⁿ 個答案，每次複製最多 n 個元素，因此產生全部結果的時間為 O(n·2ⁿ)，遞迴工作空間 O(n)。

  • 排序讓相同值相鄰，便於偵測
  • 條件 index > start 表示只跳過同一層的重複候選
  • 不能無條件跳過相同值，否則會漏掉 [2, 2] 之類答案

RECAP

這堂課要帶走的事

  1. 01子集合可建模為每個元素選或不選的二元決策。
  2. 02start 索引能避免回頭選取並自然產生各種長度。
  3. 03排序加同層跳過可處理重複輸入而不漏解。

CHECK YOURSELF

先想一想，再看答案

n 個互異元素為什麼有 2ⁿ 個子集合？

每個元素各有選與不選兩種獨立決定，n 個元素的組合數為 2×2×…×2=2ⁿ。

unique_subsets 為何使用 index > start，而不是 index > 0？

只應跳過同一決策層的重複候選；更深層仍可再次選取另一個相同值，形成合法的 [2, 2]。

PRACTICE

延伸練習

  1. 產生 [1, 2, 3] 的所有子集合，並依長度分組。
  2. 只產生元素總和不超過 target 的子集合，加入可安全使用的剪枝。
