Graph Fundamentals

Union-Find 並查集

快速合併群組並查詢是否連通

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

建立 Disjoint Set Union，使用路徑壓縮與按大小合併處理動態連通性。

LEARNING GOALS

  • 理解集合代表元
  • 實作 find 與 union
  • 用 Union-Find 偵測無向冗餘邊
01

Parent Forest 與代表元

Union-Find 又稱 Disjoint Set Union（DSU），把互不重疊的集合表示成多棵父指標樹。find(x) 沿 parent 找到根代表元；兩點代表元相同，就表示位於同一集合。

  • 初始時每個元素各自成集合，parent[x]=x
  • 根節點是自己的 parent
  • DSU 回答連通性，不保存兩點間實際路徑
02

Union by Size 合併

union(a,b) 先找到兩者根；若相同就無須合併，否則把較小樹根接到較大樹根。按大小合併限制樹高，配合路徑壓縮可讓操作攤銷成本極低。

  • 先比較 root_a 與 root_b
  • 交換後保證 root_a 是較大集合
  • 更新 parent 與新根的 component_size
03

適用情境與複雜度

依序讀取無向邊時，若 union 回傳 False，該邊連接了原本已連通的兩點，加入後會形成環。路徑壓縮加按大小合併讓 m 次操作耗時 O(m·α(V))，α 成長極慢，實務上近似常數；空間 O(V)。

  • 適合邊逐步加入的動態連通查詢
  • 可計數成功 union 次數或剩餘集合數
  • 不擅長刪邊，也不能取代 BFS 的最短路徑

RECAP

這堂課要帶走的事

  1. 01find 取得集合代表元，union 合併兩個不同集合。
  2. 02路徑壓縮與按大小合併使攤銷操作近似 O(1)。
  3. 03Union-Find 適合動態連通與無向環偵測，但不提供實際路徑。

CHECK YOURSELF

先想一想，再看答案

union(a,b) 發現兩者根相同時代表什麼？

a 與 b 原本已在同一連通集合，不需要再次合併；若它們是一條新無向邊，可能形成環。

路徑壓縮做了什麼？

find 返回時把沿途節點直接接到根，縮短未來查找代表元的路徑。

PRACTICE

延伸練習

  1. 維護 component_count，讓每次成功 union 後集合數減一。
  2. 給定無向邊依序加入，回報每一步兩個指定頂點是否已連通。
