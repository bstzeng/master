UNIT 10 / LESSON 02

Graph Fundamentals

Adjacency List 與 Adjacency Matrix

依圖的密度與查詢需求選擇表示法

入門25 分鐘PYTHON 3

WHY THIS MATTERS

建立鄰接表與鄰接矩陣，並比較空間、鄰居走訪與邊查詢成本。

LEARNING GOALS

  • 建立無向與有向鄰接表
  • 建立鄰接矩陣
  • 依密度選擇表示法
01

Adjacency List 鄰接表

鄰接表（Adjacency List）為每個頂點保存可直接到達的鄰居，空間是 O(V+E)，適合多數稀疏圖。無向邊必須在兩端各加入一次，有向邊只加入來源到目的地。

  • dict 的鍵是頂點，值可用 list 或 set
  • 走訪頂點 u 的鄰居需 O(deg(u))
  • set 避免重複邊並提供平均 O(1) 邊查詢
02

Adjacency Matrix 鄰接矩陣

鄰接矩陣（Adjacency Matrix）以 V×V 表格記錄任兩頂點是否相連，查詢一條邊是 O(1)。它固定使用 O(V²) 空間，走訪某頂點鄰居也要掃描整列 O(V)。

  • matrix[u][v] 為 1 表示有邊
  • 無向圖矩陣沿主對角線對稱
  • 加權圖可用權重取代 1，並選定無邊的特殊值
03

依密度與操作選擇

當 E 遠小於 V²，鄰接表通常較省空間且能快速列出實際鄰居；圖很密或經常詢問特定兩點是否直接相連時，矩陣較直覺。建表時間至少要讀取所有頂點與輸入邊。

  • 鄰接表空間 O(V+E)
  • 鄰接矩陣空間與初始化 O(V²)
  • 演算法複雜度必須註明採用哪種表示法
操作鄰接表鄰接矩陣
空間O(V+E)O(V²)
列出 u 鄰居O(deg(u))O(V)
查詢 u→vlist O(deg(u))O(1)

RECAP

這堂課要帶走的事

  1. 01鄰接表適合稀疏圖與鄰居走訪。
  2. 02鄰接矩陣以 O(V²) 空間換取 O(1) 邊查詢。
  3. 03無向邊在鄰接表與矩陣中都要建立對稱關係。

CHECK YOURSELF

先想一想，再看答案

V 很大而 E 接近 V 時，通常應選哪種表示法？

通常選鄰接表，空間 O(V+E) 遠小於矩陣的 O(V²)。

為什麼鄰接矩陣列出一個頂點的鄰居要 O(V)？

必須掃描該頂點對應的整列，才能判斷每個可能頂點是否相鄰。

PRACTICE

延伸練習

  1. 把一份有向邊清單轉成鄰接表，確保沒有加入反向邊。
  2. 同一張小圖分別畫成鄰接表與鄰接矩陣，核對每條邊。
