Graph Fundamentals

Connected Components 連通元件

從每個未訪頂點啟動一次完整走訪

基礎25 分鐘PYTHON 3

WHY THIS MATTERS

使用外層迴圈配合 DFS 或 BFS，計算無向圖中的連通群組。

LEARNING GOALS

  • 定義連通元件
  • 計數並標記每個元件
  • 處理孤立頂點
01

一次走訪覆蓋一個元件

無向圖的連通元件（Connected Component）是內部任兩點互相可達的最大頂點集合。從一個未訪頂點開始 DFS 或 BFS，會恰好標記它所在的整個元件。

  • 已訪頂點不再啟動新走訪
  • 每次從未訪頂點啟動，元件數加一
  • 沒有邊的孤立頂點本身也是一個元件
02

標籤比只有計數更實用

若替每個頂點保存 component_id，之後可在 O(1) 判斷兩點是否屬於同一元件。標記方式是在一次 DFS 中，將所有發現頂點寫入相同編號。

  • component_of[vertex] = component_id
  • 同編號代表存在無向路徑
  • 元件清單也可用 list 收集各群組頂點
03

方向差異與成本

鄰接表下，掃描所有頂點與邊的總時間是 O(V+E)，標記與走訪空間 O(V)。有向圖的「強連通」要求雙向可達，不能直接套用此無向版本，需要另外的強連通元件演算法。

  • 輸入必須把孤立頂點也列為 graph 的鍵
  • 多次啟動走訪不會重複處理已訪頂點
  • 本課元件定義限無向圖
KEY IDEA

只有邊清單而沒有完整頂點清單時，孤立頂點會消失，元件數也會算錯。

RECAP

這堂課要帶走的事

  1. 01每次從未訪頂點啟動走訪，就找到一個新連通元件。
  2. 02孤立頂點也必須計為一個元件。
  3. 03無向元件計數時間 O(V+E)，不可直接當成有向強連通解法。

CHECK YOURSELF

先想一想，再看答案

為什麼外層迴圈要遍歷所有頂點？

只從一個起點走訪無法到達其他元件；外層迴圈才能為每個未訪區域啟動搜尋。

一個沒有任何邊的頂點算連通元件嗎？

算，它本身構成只含一個頂點的最大連通集合。

PRACTICE

延伸練習

  1. 回傳無向圖中最大連通元件的頂點數。
  2. 輸出每個元件的頂點清單，並為孤立頂點加入測試。
