Cycle Detection 環偵測

無向圖追蹤 parent，有向圖追蹤目前路徑

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

比較有向與無向圖的環定義，實作兩種 DFS 偵測方式。

LEARNING GOALS

  • 以 parent 偵測無向環
  • 以三色狀態偵測有向環
  • 說明兩種方法不能混用
01

無向圖：排除走回 parent

無向邊會在鄰接表出現兩個方向，所以從 u 走到 v 後，v 看見已訪的 u 並不代表成環。DFS 必須攜帶 parent；遇到已訪鄰居且它不是 parent，才表示存在另一條路形成環。

  • 未訪鄰居：遞迴並把目前頂點當 parent
  • 鄰居等於 parent：忽略原路返回
  • 已訪且不是 parent：找到無向環
02

有向圖：回到目前路徑才是環

有向 DFS 中，指向任何已訪頂點不一定成環；只有指向目前遞迴路徑上的頂點，才形成回邊。可用 0 未訪、1 探索中、2 已完成的三色狀態區分。

  • state=1：頂點仍在目前 Call Stack
  • 遇到 state=1 鄰居：找到有向環
  • 探索所有鄰居後設為 state=2
03

成本與適用界線

兩種 DFS 在鄰接表下都以 O(V+E) 時間與 O(V) 空間完成。parent 規則專用於無向邊的對稱表示，三色規則則反映有向圖的遞迴路徑，套錯模型會誤判。

  • 自環 u→u 會立即形成環
  • 平行無向邊是否形成長度二的環取決於圖定義
  • 若要回傳實際環，可保存 parent 並在發現時重建
圖類型需追蹤資訊成環訊號
無向parent + visited已訪鄰居不是 parent
有向三色 state邊指向探索中頂點

RECAP

這堂課要帶走的事

  1. 01無向圖需排除回到 parent 的反向邊。
  2. 02有向圖只有回到目前遞迴路徑才構成環。
  3. 03兩種 DFS 偵測皆為 O(V+E) 時間、O(V) 空間。

CHECK YOURSELF

先想一想，再看答案

無向 DFS 遇到已訪的 parent 為什麼不能判定成環？

那只是同一條無向邊在反方向的鄰接紀錄，代表沿原路返回。

有向 DFS 遇到 state=2 的鄰居為什麼不代表環？

該鄰居的探索已完成且不在目前遞迴路徑中，這條邊不會回到自己的祖先。

PRACTICE

延伸練習

  1. 修改無向環偵測，回傳一條形成環的邊。
  2. 為有向圖三色 DFS 印出狀態變化，追蹤一張含環小圖。
