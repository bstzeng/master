Python Built-in Data Structures

Tuple：固定且可表意的序列

用不可變序列表達一筆完整資料

入門20 分鐘PYTHON 3

WHY THIS MATTERS

學習 Tuple 的建立、拆包、回傳多值與作為複合鍵的條件。

LEARNING GOALS

  • 辨認 Tuple 與 List 的選型差異
  • 使用拆包提升程式可讀性
  • 判斷 Tuple 是否可以被雜湊
01

不可變序列的用途

Tuple 與 List 一樣有順序、可重複並支援索引，但建立後不能新增、刪除或替換元素。它適合表達欄位數量固定的一筆資料，例如座標、日期或函式回傳的多個結果。

  • 索引讀取通常是 O(1)
  • 走訪與成員搜尋是 O(n)
  • 不可變能降低資料被意外改動的風險
02

打包、拆包與多值回傳

逗號才是建立 Tuple 的關鍵，所以單元素 Tuple 必須寫成 (value,)。拆包會按照位置把資料指派給名稱，也能使用星號收集剩餘元素，讓固定格式的資料更容易閱讀。

  • single = (42,) 才是單元素 Tuple
  • left, right = right, left 可交換變數
  • first, *middle, last 可收集不定長中段
03

Tuple、雜湊與選型

只有當 Tuple 內所有元素都可雜湊時，Tuple 才能成為 Dictionary 的鍵或 Set 的元素。若資料會頻繁增刪就用 List；若長度與語意固定，或需要複合鍵，Tuple 通常更合適。

  • ("A", 3) 可作為字典鍵
  • ([1, 2], 3) 含 List，因此不可雜湊
  • Tuple 的不可變只限制欄位參照，內含的可變物件仍可改動

CHECK YOURSELF

先想一想，再看答案

為什麼 (5) 不是 Tuple，而 (5,) 才是？

括號只負責分組運算式，逗號才會建立 Tuple。

Tuple 一定能作為 Dictionary 的鍵嗎？

不一定；若其中含有 List 等不可雜湊元素，整個 Tuple 也不可雜湊。

PRACTICE

延伸練習

  2. 把棋盤位置表示為 Tuple，建立 Dictionary 保存各位置上的棋子。
