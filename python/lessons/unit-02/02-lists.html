UNIT 02 / LESSON 02

Python Built-in Data Structures

List：有順序的可變序列

掌握索引、更新與動態陣列成本

入門25 分鐘PYTHON 3

WHY THIS MATTERS

學習 List 的建立、走訪、增刪與動態陣列特性，並辨認頭尾操作的成本差異。

LEARNING GOALS

  • 使用索引、切片與 List comprehension
  • 正確選擇 append、insert、pop 與 remove
  • 估算 List 常見操作的複雜度
01

索引、切片與走訪

List 以連續位置保存參照，適合需要維持順序與依索引讀取的資料。讀取或更新單一索引通常是 O(1)，完整走訪與複製切片則依元素數量為 O(n)。

  • 索引可用負數從尾端計算
  • 切片左含右不含，會建立新 List
  • enumerate 可同時取得索引與元素
02

加入、移除與位移

append 與從尾端 pop 的平均成本是 O(1)，因為通常不用搬動既有元素。從開頭或中間 insert、pop 會讓後方元素位移，成本是 O(n)，因此 List 不適合當作頻繁出隊的 Queue。

  • append(value)：尾端加入，平均 O(1)
  • pop()：尾端移除，O(1)
  • insert(0, value)／pop(0)：O(n)
  • remove(value)：先搜尋再移除，O(n)
03

搜尋、排序與推導式

使用 in 或 index 尋找 List 元素通常要從頭掃描，所以是 O(n)；排序 n 個元素通常是 O(n log n)。List comprehension 能把轉換與篩選寫得清楚，但仍會走訪輸入並建立新 List。

  • value in items：O(n)
  • items.sort()：就地排序，通常 O(n log n)
  • sorted(items)：回傳新的已排序 List
  • 查找頻繁且不在意順序時考慮 Set

RECAP

這堂課要帶走的事

  1. 01List 適合有順序、可重複且需要修改的資料
  2. 02索引是 O(1)，線性搜尋與中間增刪通常是 O(n)
  3. 03List 尾端適合 Stack，但開頭不適合頻繁出隊

CHECK YOURSELF

先想一想，再看答案

為什麼 list.pop(0) 是 O(n)？

移除第一個元素後，其餘元素都必須向前位移一格。

sort() 與 sorted() 的主要差異是什麼？

sort() 就地修改原 List 並回傳 None；sorted() 接受任意可迭代物件並回傳新的 List。

PRACTICE

延伸練習

  1. 將一組溫度資料篩選出高於平均值的項目並由高到低排序。
  2. 比較從尾端 pop 與從開頭 pop 的用途，寫出各自適合的情境。
