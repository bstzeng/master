Python Built-in Data Structures

容器、參照與可變性

先理解資料怎麼被保存與改動

入門20 分鐘PYTHON 3

WHY THIS MATTERS

建立容器選型的共同語言，理解可變物件、不可變物件、別名與淺複製。

LEARNING GOALS

  • 區分可變與不可變物件
  • 說明賦值與複製的差異
  • 用需求初步篩選資料結構
01

容器解決的四個問題

資料結構是保存與取用資料的規則，而選擇時先問四件事：順序是否重要、元素能否重複、查找要多快、內容會不會改動。Python 提供多種容器，沒有一種能在所有操作上同時最好。

  • List：有順序、可重複、可修改
  • Tuple：有順序、可重複、不可修改
  • Dictionary：以唯一鍵對應值
  • Set：只保留不重複元素

02

可變與不可變物件

List、Dictionary 與 Set 是可變（mutable）物件，原物件可以就地更新；Tuple、String 與數字是不可變（immutable）物件，所謂修改其實會產生新物件。這個差異會影響函式副作用、能否作為字典鍵，以及除錯方式。

  • 可變物件適合持續累積或更新內容
  • 不可變物件較容易推理與安全分享
  • 字典鍵與集合元素必須可雜湊，通常也應不可變
03

賦值、淺複製與成本

賦值只讓兩個名稱指向同一物件，時間是 O(1)；list.copy() 或切片會建立外層的新容器，時間與額外空間皆為 O(n)。淺複製不會複製內層的可變物件，因此巢狀資料仍可能共享內容。

  • alias = original：共享同一物件，O(1)
  • clone = original.copy()：複製外層，O(n)
  • 需要完整分離巢狀物件時才考慮 deepcopy
KEY IDEA

看到資料被意外改動時，先檢查是否有兩個變數指向同一個可變物件。

CHECK YOURSELF

先想一想，再看答案

為什麼 List 不能直接作為 Dictionary 的鍵？

List 可變且不可雜湊，內容改動會破壞鍵在雜湊表中的定位；可改用只含可雜湊元素的 Tuple。

將含 n 個元素的 List 指派給另一個變數，時間複雜度是多少？

O(1)，因為只複製物件參照，沒有逐一複製元素。

延伸練習
