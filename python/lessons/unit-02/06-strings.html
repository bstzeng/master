Python Built-in Data Structures

String：不可變的文字序列

以序列觀念處理文字與避免低效串接

入門25 分鐘PYTHON 3

WHY THIS MATTERS

理解 String 的不可變性、索引切片、常用轉換與高效組合方式。

LEARNING GOALS

  • 以索引、切片與字串方法處理文字
  • 解釋 String 不可變帶來的成本
  • 使用 join 高效組合多段文字
01

文字也是序列

String 是由 Unicode 字元組成的不可變序列，支援索引、切片、in 與迭代。讀取單一位置通常是 O(1)，但切片長度為 k 時需要建立新字串，時間與空間皆為 O(k)。

  • 索引取得一個新的一字元 String
  • 切片規則與 List 相同，左含右不含
  • 成員或子字串搜尋不應假設為 O(1)
02

清理、拆分與格式化

字串方法不會改動原字串，而是回傳新的 String；strip、split、replace 與 lower 是資料清理的常用工具。這些方法通常需要檢視或複製文字，對長度 n 的字串多半以 O(n) 理解。

  • strip() 移除頭尾空白
  • split(separator) 拆成 List
  • separator.join(parts) 合併字串
  • f-string 適合將值嵌入文字
03

大量串接與資料選型

因 String 不可變，迴圈中反覆使用 result += piece 可能不斷複製既有內容，累積成本可能接近 O(n²)。先把片段存入 List，最後用 join 一次配置結果，通常可在總字元數的 O(n) 時間完成。

  • 固定文字與文字處理：String
  • 大量累積片段：List 加 join
  • 需要修改單一字元：先轉 List，完成後 join
  • String 可雜湊，因此可作為 Dictionary 鍵或 Set 元素
KEY IDEA

小量、一次性的 + 串接很清楚；需要在迴圈大量累積時再改用 List 與 join。

CHECK YOURSELF

先想一想，再看答案

為什麼不能寫 text[0] = 'A'？

String 不可變，不能就地替換字元；必須建立新的 String。

迴圈中大量串接字串時，為何 join 通常較好？

反覆 += 可能一再複製逐漸變長的結果；join 能先知道片段並較接近一次完成配置，總成本通常為 O(n)。
