Python Built-in Data Structures

Dictionary：鍵與值的快速對應

用雜湊表建立可讀又高效的查找

入門25 分鐘PYTHON 3

WHY THIS MATTERS

學習 Dictionary 的鍵值模型、安全存取、走訪、計數與平均複雜度。

LEARNING GOALS

  • 建立、查詢與更新鍵值資料
  • 使用 get、items 與 setdefault
  • 理解雜湊表的平均 O(1) 與鍵限制
01

從鍵找到值

Dictionary（字典）用唯一的鍵對應一個值，適合學生編號對姓名、商品代碼對庫存等查詢。鍵查找、新增與更新平均是 O(1)，但這是雜湊表在一般分布下的平均表現。

  • 鍵必須唯一，重複指派會覆蓋舊值
  • 鍵必須可雜湊，例如 String、數字或合格的 Tuple
  • 現代 Python 保留插入順序，但主要優勢仍是依鍵查找
02

安全存取與走訪

使用 brackets 讀取不存在的鍵會拋出 KeyError，而 get 可以提供預設值。走訪 items() 能同時取得鍵和值，完整走訪 n 組資料需要 O(n)。

  • mapping[key]：鍵必須存在
  • mapping.get(key, default)：缺少時回傳預設值
  • keys()、values()、items() 提供不同走訪視角
03

計數模式與複雜度

Dictionary 常用來累積頻率，因為每次依鍵讀寫平均 O(1)，處理 n 個項目的總時間平均為 O(n)。它需要額外 O(k) 空間保存 k 個不同鍵；若只在意元素是否出現，Set 表達會更直接。

  • 查找、插入、刪除：平均 O(1)
  • 完整複製或走訪：O(n)
  • 頻率、分組與快取是常見使用情境

CHECK YOURSELF

先想一想，再看答案

何時應使用 get 而不是 brackets 讀取字典？

當鍵可能不存在且希望提供合理預設值時使用 get；若缺鍵代表程式錯誤，brackets 的 KeyError 反而有助除錯。

Dictionary 查找一定是 O(1) 嗎？

通常以平均 O(1) 分析；極端雜湊碰撞下最壞可退化，但一般選型以平均成本為主。
