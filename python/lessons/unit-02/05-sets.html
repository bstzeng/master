Python Built-in Data Structures

Set：唯一元素與集合運算

快速判斷存在、去重與比較群組

入門20 分鐘PYTHON 3

WHY THIS MATTERS

學習 Set 的唯一性、成員測試、集合運算與不保證位置順序的特性。

LEARNING GOALS

  • 使用 Set 去除重複資料
  • 以集合運算比較兩群資料
  • 比較 Set 與 List 的查找成本
01

唯一性與快速成員測試

Set（集合）只保存不重複且可雜湊的元素，特別適合回答某值是否已出現。成員測試、加入與刪除平均為 O(1)，相較 List 的 O(n) 線性搜尋更適合大量重複查找。

  • 元素不重複，沒有索引位置
  • in、add、discard 平均 O(1)
  • 不要依賴 Set 的迭代順序
02

交集、聯集與差集

集合運算能直接表達兩群資料之間的關係，比巢狀迴圈更接近問題語意。對大小分別為 n 與 m 的集合，聯集與差集通常與輸入規模線性相關，交集通常可從較小集合開始檢查。

  • a | b：聯集，出現在任一集合
  • a & b：交集，同時出現
  • a - b：差集，只出現在 a
  • a ^ b：對稱差集，只出現在其中之一
03

去重與選型限制

set(items) 能在線性平均時間內去重，但結果不保證保留可依賴的位置順序。若要保留第一次出現順序，可利用 Dictionary 鍵唯一且保留插入順序的特性；若元素還要對應資料，直接使用 Dictionary。

  • 只需唯一性與存在判斷：Set
  • 需要唯一鍵對應資訊：Dictionary
  • 需要位置、重複與順序：List
  • 空集合必須寫 set()，{} 是空 Dictionary

CHECK YOURSELF

先想一想，再看答案

為什麼大量成員測試通常應選 Set 而不是 List？

Set 以雜湊表將平均查找降為 O(1)，List 通常要逐項比較而為 O(n)。

如何建立空 Set？

使用 set()；字面值 {} 建立的是空 Dictionary。
