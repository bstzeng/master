Python Built-in Data Structures

Stack、Queue 與 deque

依進出順序選擇正確的 Python 實作

入門25 分鐘PYTHON 3

WHY THIS MATTERS

理解 LIFO 與 FIFO 規則，並以 List 或 collections.deque 實作有效率的操作。

LEARNING GOALS

  • 用 List 或 deque 實作 Stack
  • 用 deque 實作 Queue
  • 比較兩種容器在兩端操作的複雜度
01

Stack：後進先出

Stack（堆疊）遵守後進先出（LIFO），像疊盤子一樣最後放上的項目最先取走。Python 可直接用 List 尾端的 append 與 pop 實作，兩者平均或攤銷成本皆為 O(1)。

  • push：list.append(value)
  • pop：list.pop()
  • peek：stack[-1]，先確認非空
  • 適合復原、括號配對與深度優先搜尋
02

Queue：先進先出

Queue（佇列）遵守先進先出（FIFO），適合排隊工作與廣度優先搜尋。List 的 pop(0) 是 O(n)，應改用 collections.deque 的 append 與 popleft，兩端操作都是 O(1)。

  • enqueue：deque.append(value)
  • dequeue：deque.popleft()
  • 不要用 List 的 pop(0) 處理大量出隊
  • deque 可限制 maxlen 建立固定長度緩衝區
03

List 與 deque 的選型

deque 是雙端佇列，左右兩端加入與移除皆為 O(1)，但不適合頻繁依中間索引存取。需要隨機索引與尾端操作時用 List；需要左端或兩端頻繁進出時用 deque。

  • List 索引：O(1)，左端增刪：O(n)
  • deque 兩端增刪：O(1)
  • deque 中間索引不具 List 的常數時間優勢
  • 單執行緒的一般 Stack 可優先用 List，語意清楚即可
需求建議結構主要操作
後進先出List／dequeappend、pop：O(1)
先進先出dequeappend、popleft：O(1)
雙端操作dequeappendleft、popleft：O(1)
依索引隨機讀取Listitems[i]：O(1)

RECAP

這堂課要帶走的事

  1. 01Stack 是 LIFO，List 尾端 append 與 pop 即可高效實作
  2. 02Queue 是 FIFO，應使用 deque 的 append 與 popleft
  3. 03deque 擅長兩端操作，List 擅長隨機索引

CHECK YOURSELF

先想一想，再看答案

為什麼不建議以 List 的 pop(0) 實作 Queue？

每次移除第一項都要搬動其餘元素，單次成本為 O(n)。

只需要一般 Stack 時，List 與 deque 應如何選？

兩者尾端操作都有效率；List 較常見且簡單，若還需要左端操作或固定 maxlen 再選 deque。
