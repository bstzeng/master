UNIT 12 / LESSON 04

Greedy Algorithms

Jump Game 跳躍遊戲

不用保存每條路，只追蹤目前能到達的最遠位置

中階28 分鐘PYTHON 3

WHY THIS MATTERS

以最遠可達邊界解決是否能到終點，並用前綴可達不變量證明線性貪心正確。

LEARNING GOALS

  • 建立 farthest 狀態
  • 實作 O(n) 可達性判斷
  • 用不變量說明提前失敗
01

問題只問能否到達

給定非負整數 jumps，每格數值是從該位置最多能向右跳幾步，目標是判斷能否到最後一格。因為只問可達性，不必記住實際選了哪個落點；在目前可達位置中，保留最遠可達邊界已涵蓋所有較短選擇。

  • 輸入值必須非負
  • 狀態是前綴能延伸到的最遠索引
  • 較近的可達位置不會提供邊界外的額外資訊
02

掃描可達前綴

走到 index 時，若 index > farthest，表示目前可達前綴已結束而此格無法站上，立即回傳 False；否則用 index + jump 更新最遠位置。只掃描一次，時間 O(n)、額外空間 O(1)。

  • 先確認目前位置可達
  • farthest 只增不減
  • 到達最後索引後可提前成功
03

最遠邊界是完整摘要

處理完索引 i 後，不變量是 farthest 等於所有已處理且可達位置能延伸出的最大索引。若下一個 index 超過它，任何先前跳法都不可能跨過缺口；若它覆蓋終點，則一定存在一連串可達位置支持這個延伸。

  • 不變量摘要所有已探索選擇
  • 無需回溯每一條跳躍路徑
  • 局部更新不會丟失更遠可能性
  • 若要求最少跳數，需要增加層級邊界狀態

RECAP

這堂課要帶走的事

  1. 01可達性問題只需保存目前最遠可達索引
  2. 02超過 farthest 的第一個索引證明存在無法跨越的缺口
  3. 03一次掃描得到 O(n) 時間與 O(1) 空間

CHECK YOURSELF

先想一想，再看答案

[3,2,1,0,4] 為何無法到終點？

前三格最遠只能到索引 3，而索引 3 的跳躍為 0，farthest 無法覆蓋索引 4。

每次真的跳到能到達最遠的位置，和只維護 farthest 完全相同嗎？

不一定。程式沒有承諾實際落點，只摘要所有可達位置的最大覆蓋，避免過早固定路徑。

PRACTICE

延伸練習

  1. 手動追蹤 [2,3,1,1,4] 每個索引的 farthest。
  2. 擴充演算法計算到終點的最少跳數，使用 current_end 與 next_end 表示層級。
