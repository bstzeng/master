KMP 完整搜尋流程

組合 LPS 與雙指標找出所有匹配

進階40 分鐘PYTHON 3

WHY THIS MATTERS

整合 LPS 與雙指標搜尋，處理完整匹配後回退、重疊結果及空 Pattern 契約。

LEARNING GOALS

  • 實作回傳全部位置的 KMP
  • 處理重疊匹配與完整匹配後回退
  • 說明 O(n + m) 時間界線
01

搜尋狀態與三種分支

KMP 搜尋維護 text_index 與 pattern_index；相同時兩者前進，失配且 pattern_index > 0 時依 LPS 回退，否則只前進 Text。這三個分支保證 Text 指標不倒退，Pattern 指標只沿已知 Border 移動。

  • 相同：兩個指標同時加一
  • 失配且 j > 0：j = lps[j - 1]
  • 失配且 j == 0：i += 1
  • 不要在回退分支同時增加 i
02

完整實作與重疊匹配

當 pattern_index == m 時，匹配起點為 text_index - m；若要繼續尋找重疊結果，不把 j 歸零，而是設為 lps[j - 1]。空 Pattern 的數學與函式庫契約可能不同，下例明確定義它匹配所有 n + 1 個邊界。

  • 完整匹配位置：i - m
  • 匹配後回退可保留 Border
  • 回傳 List 可保存重疊結果
  • 空 Pattern 行為應在介面中記錄
03

複雜度、適用情境與限制

建 LPS 為 O(m)，搜尋為 O(n)，總時間 O(n + m)、額外空間 O(m) 加輸出 O(k)，且沒有雜湊碰撞。KMP 適合要求確定線性最壞界線、Pattern 有重複結構或相同 Pattern 搜尋多個 Text；一次性短字串則未必比內建搜尋更簡單。

  • 確定最壞時間 O(n + m)
  • 相同 Pattern 可重用 LPS
  • 精確比較，不存在碰撞
  • 程式較暴力法複雜，需仔細測試邊界
方法最壞時間預處理風險

KEY IDEA

KMP 的線性保證來自 Text 不回退，以及 Pattern 回退總量受到前進總量限制。

CHECK YOURSELF

先想一想，再看答案

找到完整匹配後，為何不一定把 pattern_index 設為 0？

完整 Pattern 的後綴可能也是前綴，回退到 LPS 能保留這段資訊並找到重疊匹配。

KMP 相對 Rabin–Karp 的一項保證是什麼？

KMP 直接比較字元並有確定 O(n + m) 最壞時間，不存在雜湊碰撞造成的額外驗證。
