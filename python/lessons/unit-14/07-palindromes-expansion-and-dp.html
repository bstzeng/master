UNIT 14 / LESSON 07

Classic String Algorithms

回文：中心擴展與動態規劃

利用對稱性找最長回文子字串

進階45 分鐘PYTHON 3

WHY THIS MATTERS

區分回文子字串與子序列，以中心擴展及二維 DP 求最長回文子字串。

LEARNING GOALS

  • 區分 Substring 與 Subsequence 回文題型
  • 實作奇偶中心擴展
  • 建立回文區間 DP 狀態
01

回文與問題邊界

Palindrome（回文）正讀與反讀相同；Substring（子字串）必須連續，Subsequence（子序列）則可跳過字元，兩者不能套用同一解法。單純判斷整串是否回文可用雙指標 O(n)，找最長回文子字串則要探索可能區間。

  • 'racecar' 是回文
  • 子字串位置連續，子序列不要求連續
  • 空字串與單字元通常都是回文
  • 先確認題目要長度、內容或全部位置
02

Expand Around Center

每個回文都能由中心向左右擴展；奇數長回文中心是一個字元，偶數長回文中心是兩字元間隙，因此需檢查 2n - 1 個中心。每次擴展最壞 O(n)，總時間 O(n²)、額外空間 O(1)。

  • 奇數中心：(i, i)
  • 偶數中心：(i, i + 1)
  • 左右相同就繼續向外
  • 用最佳起點與長度避免反覆切片
03

二維 DP 與方法比較

定義 dp[left][right] 表示 text[left:right + 1] 是否回文；兩端相同，且區間長度不超過 3 或內層 dp[left + 1][right - 1] 為真時成立。填表需由短區間到長區間，時間 O(n²)、空間 O(n²)，優勢是能保留所有區間狀態供後續計數或查詢。

  • 狀態：閉區間是否回文
  • 轉移依賴更短的內層區間
  • 時間 O(n²)、空間 O(n²)
  • 只求最長內容時中心擴展更省空間
方法時間空間較適合
雙指標判斷O(n)O(1)整串是否回文
中心擴展O(n²)O(1)最長回文子字串
區間 DPO(n²)O(n²)需要多個區間狀態

RECAP

這堂課要帶走的事

  1. 01回文子字串必須連續，與回文子序列是不同問題
  2. 02中心擴展檢查奇偶中心，時間 O(n²)、空間 O(1)
  3. 03區間 DP 保存所有回文區間，時間與空間皆為 O(n²)

CHECK YOURSELF

先想一想，再看答案

為什麼中心擴展要同時檢查 (i, i) 與 (i, i + 1)？

前者處理奇數長回文，後者處理中心在字元間隙的偶數長回文。

只求最長回文子字串時，中心擴展相對 DP 的主要空間優勢是什麼？

中心擴展只需常數額外空間，DP 要保存 O(n²) 個區間狀態。

PRACTICE

延伸練習

  1. 修改中心擴展，計算字串中共有多少個回文子字串。
  2. 用隨機短字串比較中心擴展與 DP 回傳的最長長度是否一致。
