Classic String Algorithms

Prefix、Suffix 與 KMP 直覺

利用已匹配內容決定下一次對齊

基礎35 分鐘PYTHON 3

WHY THIS MATTERS

理解 Proper Prefix、Proper Suffix 與 Border，建立 KMP 失配後不回退 Text 指標的直覺。

LEARNING GOALS

  • 定義前綴、後綴與 Proper Border
  • 找出模式字串的共同前後綴
  • 解釋 KMP 如何重用已匹配資訊
01

前綴、後綴與 Border

Prefix（前綴）從字串開頭取一段，Suffix（後綴）從尾端取一段；Proper Prefix／Suffix 不包含整個字串本身。若某段同時是 Proper Prefix 與 Proper Suffix，就稱為 Border，KMP 會保存最長 Border 的長度。

  • 'ababa' 的 Proper Prefix 包含 'a'、'ab'、'aba'
  • Proper Suffix 包含 'a'、'ba'、'aba'
  • 最長 Border 是 'aba'，長度 3
  • Border 可以重疊，不要求是兩段獨立字元
02

失配時仍有可用資訊

若 Pattern 已匹配 j 個字元後失配，已匹配區段的某個後綴可能同時等於 Pattern 前綴，因此不必把 Pattern 完全歸零。把 Pattern 移到最長 Border 對齊的位置，可以保留已知相同部分，Text 指標也不需倒退。

  • 已匹配區段是 pattern[:j]
  • 尋找其最長 Proper Border
  • 新 j 等於該 Border 長度
  • 目前 Text 字元要用較短前綴重新比較
03

KMP 的兩個指標

Knuth–Morris–Pratt（KMP）使用 i 指向 Text、j 指向 Pattern；相同時兩者都前進，失配且 j > 0 時只把 j 回退到較短 Border，i 留在原位。每次回退都依預先計算的 LPS 表，因此搜尋階段能維持 O(n)。

  • 匹配：i += 1、j += 1
  • 失配且 j > 0：j = lps[j - 1]
  • 失配且 j == 0：i += 1
  • j == m 時找到一個完整匹配
情況Text 指標 iPattern 指標 j
字元相同前進前進
失配且 j > 0不動回退到 Border
失配且 j = 0前進維持 0
完整匹配已在下一字元可回退找重疊
KEY IDEA

KMP 的核心不是跳過任意字元，而是只跳過已能由 Border 證明不必重比的對齊。

CHECK YOURSELF

先想一想，再看答案

'abcab' 的最長 Proper Border 是什麼？

'ab'，因為它同時是開頭兩字元與結尾兩字元。

KMP 失配且 j > 0 時，為什麼 i 不前進？

目前 Text 字元尚未與回退後的新 Pattern 位置比較，它仍可能完成較短前綴的匹配。
