UNIT 14 / LESSON 01

Classic String Algorithms

字串匹配與暴力搜尋

先定義問題，再觀察重複比較

基礎30 分鐘PYTHON 3

WHY THIS MATTERS

定義 Text 與 Pattern，以逐位置對齊實作暴力匹配，分析最壞 O(nm) 與邊界條件。

LEARNING GOALS

  • 區分 Text、Pattern 與 Match Index
  • 實作回傳全部匹配位置的暴力演算法
  • 分析最壞時間與特殊輸入
01

Text、Pattern 與對齊

字串匹配要在長度 n 的 Text（本文）中尋找長度 m 的 Pattern（模式），答案可能是第一個位置、全部位置或是否存在。暴力法把 Pattern 依序對齊 Text 的每個可行起點，再從左到右比較字元。

  • 可行起點為 0 到 n - m
  • Python 索引通常回傳零起始位置
  • 題目要先說明是否允許重疊匹配
  • Pattern 比 Text 長時沒有匹配
02

暴力匹配實作

每個起點最多比較 m 個字元，第一處不同就停止該次對齊；全部相同則記錄起點。若逐字元比較而不建立切片，額外工作空間可維持 O(1)，輸出位置另需 O(k)。

  • 外層枚舉對齊起點
  • 內層逐字元驗證
  • 失配時立即 break
  • 成功匹配後仍只向右移一格即可找重疊結果
03

複雜度與何時足夠

最壞情況每個起點都比較接近 m 次，因此時間 O((n - m + 1)m)，通常簡寫 O(nm)；例如大量相同前綴會造成重複工作。Pattern 很短、資料規模小或只執行少量搜尋時，暴力法簡單可靠，也適合作為進階演算法的測試基準。

  • 最壞時間 O(nm)
  • 逐字元版本工作空間 O(1)
  • 平均情況可能因早期失配而更快
  • Python 實務可先用 str.find，但學習時要理解底層問題
情境暴力法評估
小文字、短 Pattern通常足夠且清楚
大量重複前綴可能反覆比較
要求線性最壞界線考慮 KMP
多 Pattern 前綴查詢考慮 Trie

RECAP

這堂課要帶走的事

  1. 01暴力匹配逐一嘗試所有對齊起點並逐字元驗證
  2. 02最壞時間為 O(nm)，但規模小時簡潔且實用
  3. 03空 Pattern、重疊匹配與回傳格式必須先定義

CHECK YOURSELF

先想一想，再看答案

Text 長 n、Pattern 長 m 時，有多少個完整對齊起點？

若 m <= n，共 n - m + 1 個；若 m > n 則為 0 個。

為何 'aaaaa' 搜尋 'aaab' 接近暴力法最壞情況？

多數對齊都先匹配很長的共同前綴，直到 Pattern 後段才失配，造成重複比較。

PRACTICE

延伸練習

  1. 修改 naive_search，使它只回傳第一個匹配位置，找不到回傳 -1。
  2. 為允許重疊與不允許重疊兩種規則，各找出 'aaaa' 中 'aa' 的位置。
