UNIT04

能根據資料是否排序、條件是否單調，以及問題是否形成圖，選擇並正確實作合適的搜尋演算法。

BEFORE YOU START

先備知識

  • 能使用 Python 函式、條件判斷與迴圈
  • 理解 list、set、dict 與 collections.deque 的基本用途
  • 知道 Big O、O(n) 與 O(log n) 的意義

AFTER THIS UNIT

完成後你能夠

  • 實作並分析線性搜尋與二分搜尋
  • 用迴圈不變量避免二分搜尋邊界錯誤
  • 使用 Lower Bound 與 Upper Bound 處理重複值
  • 辨認並解決可以對答案進行二分搜尋的單調問題
  • 使用 DFS 與 BFS 走訪圖，並比較兩者的適用情境
