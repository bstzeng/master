Sorting Algorithms

排序演算法

從排序規格與 Python 內建工具開始，實作經典比較排序與計數排序，理解穩定性、原地操作和時間空間取捨。

查看 8 堂課 ↓
UNIT05

能根據資料規模、分布、記憶體與穩定性需求選擇排序方法，並正確使用 Python 的 key 設計排序規則。

BEFORE YOU START

先備知識

  • 能閱讀 Python list、函式、迴圈與切片
  • 理解 Big O、時間與空間複雜度
  • 知道陣列索引與遞迴的基本概念

AFTER THIS UNIT

完成後你能夠

  • 使用 sorted、list.sort 與 key 表達多欄位排序
  • 實作 Bubble、Selection、Insertion、Merge、Quick、Heap 與 Counting Sort
  • 判斷排序是否穩定、是否原地操作
  • 比較最好、平均與最壞時間及額外空間
  • 依資料特性選擇合適方法而非只背名稱
