Greedy Algorithms

Greedy 貪心演算法

學習以局部選擇逐步建構答案，透過區間、跳躍、背包、編碼與硬幣案例，辨認何時貪心正確、何時會失敗。

UNIT12

能提出貪心規則、實作並分析演算法，還能以交換論證或反例說明局部最佳是否能導向全域最佳。

BEFORE YOU START

先備知識

  • 能使用 Python 排序、list、dict 與 heapq
  • 理解 Big O、區間與基本圖樹概念
  • 能閱讀簡單的正確性論證與反例

AFTER THIS UNIT

完成後你能夠

  • 辨認具有貪心選擇性質與最佳子結構的問題
  • 解決經典區間排程、Jump Game 與分數背包
  • 理解 Huffman Coding 如何以局部合併得到最佳前綴碼
  • 主動尋找硬幣等問題中的反例
  • 用交換論證說明正確性並區分 Greedy 與 DP
