BEFORE YOU START

先備知識

  • 會定義 Python 函式並理解參數與回傳值
  • 熟悉 list、set、迴圈與條件判斷
  • 理解 Big O、樹與深度優先搜尋的基本概念

AFTER THIS UNIT

完成後你能夠

  • 能寫出具有明確 Base Case 的遞迴函式
  • 能畫出遞迴樹與 Call Stack 並分析複雜度
  • 能用分治法拆解、求解及合併子問題
  • 能套用選擇、遞迴、撤銷的回溯框架
  • 能以限制條件與剪枝降低無效搜尋
