Advanced Data Structures

進階資料結構

針對區間查詢、快取、資料庫索引、近似統計、動態連通性與單調序列，學習專門資料結構如何交換時間、空間與功能。

UNIT15

能從操作比例、更新模式、精確度與記憶體限制出發，選擇並實作合適的進階資料結構，而不是只記住名稱。

BEFORE YOU START

先備知識

  • 熟悉 Python list、dict、class、位元操作與 collections
  • 理解 Tree、Heap、Hash Table、Prefix Sum 與 Big O
  • 能閱讀遞迴、迭代與簡單機率概念

AFTER THIS UNIT

完成後你能夠

  • 依更新與查詢型態選擇 Prefix Sum、Fenwick Tree 或 Segment Tree
  • 理解 Lazy Propagation 如何延後區間更新
  • 以 Hash Map 與 Doubly Linked List 實作 LRU Cache
  • 比較 LFU、B-Tree、B+ Tree、Hash Index 與 Tree Index
  • 實作並分析 Bloom Filter 與 Count-Min Sketch
  • 使用 DSU、Sparse Table、Monotonic Stack 與 Queue 解決典型效能問題
