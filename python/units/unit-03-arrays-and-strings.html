BEFORE YOU START

  • 會使用 Python 的 list、str、dict 與 set

AFTER THIS UNIT

完成後你能夠

  • 能安全走訪陣列與字串，並處理索引邊界
  • 能使用雜湊表統計字元或快速查找互補值
  • 能辨認雙指標與滑動視窗的適用情境
  • 能以最長不重複子字串說明動態視窗的維護方式
  • 能使用前綴和回答區間查詢，並用差分陣列處理批次區間更新
