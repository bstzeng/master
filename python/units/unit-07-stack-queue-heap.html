Stack、Queue 與 Heap

從元素進出的順序出發，學習 Stack、Queue、Priority Queue、Heap，以及能在線性時間解題的單調結構。

UNIT07

能辨認後進先出、先進先出、依優先權取出與滑動區間問題，選用合適結構並分析操作複雜度。

BEFORE YOU START

先備知識

  • 熟悉 Python List、Tuple 與 Dictionary
  • 會使用 collections.deque 與基本迴圈
  • 理解 Big O 與攤銷複雜度

AFTER THIS UNIT

完成後你能夠

  • 使用 List 或 deque 實作 Stack 與 Queue
  • 以 Stack 解決括號配對與巢狀結構問題
  • 以 heapq 實作 Priority Queue、Min Heap 與 Max Heap
  • 使用 Heap 解決 Top K 題型
  • 辨認並實作 Monotonic Stack 與 Monotonic Queue
