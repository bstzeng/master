鏈結串列

從節點與單向鏈結開始，練習走訪、搜尋、插入、刪除、反轉、雙向鏈結、快慢指標與環狀偵測。

UNIT06

能用 Python 建立鏈結串列，安全調整節點連結，並根據問題選擇走訪、反轉或快慢指標技巧。

BEFORE YOU START

先備知識

  • 會定義 Python class、函式與使用 None
  • 理解物件參照與變數指向物件的概念
  • 能分析 O(1) 與 O(n) 時間複雜度

AFTER THIS UNIT

完成後你能夠

  • 能畫出 Node、head、next 與 prev 之間的連結
  • 能實作單向與雙向鏈結串列的基本操作
  • 能正確反轉單向鏈結串列而不遺失剩餘節點
  • 能使用快慢指標尋找中點與倒數節點
  • 能以 Floyd 演算法偵測環狀鏈結串列
