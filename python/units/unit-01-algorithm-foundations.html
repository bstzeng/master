Algorithm Foundations

演算法基礎

從生活化的解題流程出發，建立資料結構、演算法與複雜度的基本語言，並學會初步估算 Python 程式的成本。

查看 6 堂課 ↓
UNIT01

能說明一段解法為何正確、如何隨輸入規模成長，並以 Big O 比較常見 Python 操作、迴圈與簡單遞迴。

BEFORE YOU START

先備知識

  • 能閱讀 Python 變數、條件判斷、迴圈與函式
  • 知道 list、dict、set 等基本容器的用途
  • 不需要微積分或資訊工程背景

AFTER THIS UNIT

完成後你能夠

  • 區分資料結構、演算法與程式實作
  • 用測試案例與不變量初步說明解法正確性
  • 辨認 O(1)、O(log n)、O(n)、O(n log n) 與 O(n²)
  • 查判 Python 常見容器操作的平均或最壞複雜度
  • 分析基本迴圈、巢狀迴圈與遞迴的時間及空間成本
