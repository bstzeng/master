PHASE 02 / UNIT 11

Classic Graph Algorithms

經典圖論演算法

依邊權重與問題目標，學習單源及全點對最短路徑，以及連接所有頂點的最小生成樹演算法。

查看 8 堂課 ↓
UNIT11

能根據負權重、圖的稀疏程度與查詢範圍，選擇並實作 Dijkstra、Bellman–Ford、Floyd–Warshall、Prim 或 Kruskal。

BEFORE YOU START

先備知識

  • 熟悉圖的頂點、邊、鄰接表與鄰接矩陣
  • 能使用 DFS、BFS、Heap 與 Union-Find
  • 理解時間複雜度中的 V 與 E

AFTER THIS UNIT

完成後你能夠

  • 將加權圖建模為鄰接表或鄰接矩陣
  • 正確選用單源與全點對最短路徑演算法
  • 辨認負權重與可達負環造成的限制
  • 區分最短路徑樹與最小生成樹
  • 以 Prim 或 Kruskal 建立最小生成樹並驗證連通性
