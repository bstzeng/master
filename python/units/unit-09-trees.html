從樹與二元樹的共同語言開始，學習深度與廣度走訪，再進入 BST、平衡樹、Trie 與 Heap 的結構及用途。

UNIT09

能把階層資料表示成樹，選擇合適走訪方式，並依查找、前綴或極值需求選用 BST、Trie 或 Heap。

BEFORE YOU START

先備知識

  • 理解 Python 類別、函式、list、dict、set 與 deque
  • 能閱讀遞迴與迭代程式
  • 知道 Stack、Queue、Heap 與 Big O 基本概念

AFTER THIS UNIT

完成後你能夠

  • 使用正確術語描述樹與二元樹
  • 實作前序、中序、後序與層序走訪
  • 計算樹的高度、節點深度與直徑
  • 實作 BST 的查找、插入與刪除
  • 說明平衡如何影響樹操作成本
  • 依需求使用 Trie 或陣列式 Heap
