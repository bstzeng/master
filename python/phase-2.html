UNIT 11 8 LESSONS

經典圖論演算法

依邊權重與問題目標，學習單源及全點對最短路徑，以及連接所有頂點的最小生成樹演算法。

  1. 01加權圖與最短路徑
  2. 02Dijkstra：以最小暫定距離擴張
  3. 03Heap 優化 Dijkstra
  4. 04Bellman–Ford 與負環偵測
  5. 05Floyd–Warshall：全點對最短路徑
  6. 06Minimum Spanning Tree 基礎
  7. 07Prim：從一個頂點擴張 MST
  8. 08Kruskal、Union-Find 與總比較

UNIT 12 8 LESSONS

Greedy 貪心演算法

學習以局部選擇逐步建構答案，透過區間、跳躍、背包、編碼與硬幣案例，辨認何時貪心正確、何時會失敗。

  1. 01貪心核心與題型辨認
  2. 02活動選擇與區間排程
  3. 03區間合併
  4. 04Jump Game 跳躍遊戲
  5. 05Fractional Knapsack 分數背包
  6. 06Huffman Coding
  7. 07硬幣陷阱與反例
  8. 08交換論證與 Greedy vs DP

UNIT 13 12 LESSONS

Dynamic Programming 動態規劃

以狀態與轉移保存子問題答案，系統學習序列、網格、字串、背包與區間 DP。

  1. 01DP 核心：重疊子問題與最佳子結構
  2. 02Memoization 與 Tabulation
  3. 03State、Transition、Base Case 與順序
  4. 04Fibonacci 與 Climbing Stairs
  5. 05House Robber 與 Maximum Subarray
  6. 06Coin Change 與 Word Break
  7. 07Grid、Unique Paths 與 Minimum Path Sum
  8. 08LCS 與 Edit Distance
  9. 090/1 Knapsack
  10. 10Complete Knapsack、Subset Sum 與 Partition
  11. 11LIS：O(n²) 與 O(n log n)
  12. 12回文、Interval DP 與統一解題框架

UNIT 14 8 LESSONS

經典字串演算法

從暴力匹配的重複比較出發，學習 KMP、Rolling Hash、Trie，以及中心擴展、動態規劃與 Manacher 回文演算法。

  1. 01字串匹配與暴力搜尋
  2. 02Prefix、Suffix 與 KMP 直覺
  3. 03LPS Table：預先整理回退位置
  4. 04KMP 完整搜尋流程
  5. 05Rabin–Karp 與 Rolling Hash
  6. 06Trie：以共同前綴組織單字
  7. 07回文：中心擴展與動態規劃
  8. 08Manacher 概念與字串演算法選型

UNIT 15 10 LESSONS

進階資料結構

針對區間查詢、快取、資料庫索引、近似統計、動態連通性與單調序列，學習專門資料結構如何交換時間、空間與功能。

  1. 01Range Query 與 Prefix Sum 的限制
  2. 02Fenwick Tree 樹狀陣列
  3. 03Segment Tree 線段樹
  4. 04Lazy Propagation 與 Fenwick 比較
  5. 05LRU Cache 與 LFU Cache
  6. 06B-Tree、B+ Tree 與資料庫索引
  7. 07Bloom Filter 與 False Positive
  8. 08Count-Min Sketch
  9. 09DSU 進階與 Sparse Table
  10. 10Monotonic Stack 與 Queue 進階

綜合解題與演算法設計

  4. 04Two Pointers vs Sliding Window
  5. 05DFS、BFS 與 Union-Find 選型

  7. 07Binary Search on Answer
