# Prompt Review Checklist

## 任務契約

- [ ] 目標是一個可以驗收的成果
- [ ] 背景只包含會改變答案的事實
- [ ] 硬限制與偏好分開
- [ ] 必要證據與完成條件清楚
- [ ] 輸出格式只包含下游真正需要的內容

## 精簡

- [ ] 每條規則只出現一次
- [ ] 工具細節放在工具契約，而非全域重複
- [ ] 範例能修正實測缺口或鎖定產品格式
- [ ] 動態資料沒有混入穩定前綴
- [ ] 開場、泛用背景、重複摘要已刪除
