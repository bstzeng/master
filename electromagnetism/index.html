PART 1

庫侖定律 電荷之間的力

同性相斥、異性相吸。力和兩電荷電量的乘積成正比，和距離平方成反比：距離拉遠一倍，力剩四分之一。兩顆電荷受的力大小相同、方向相反。

公式F = k q₁q₂ / r²
常數k = 8.99 × 10⁹ N·m²/C²

PART 1

電場與電場線 電荷周圍的「力場」

電場是每單位電荷受到的力。電場線從正電荷出發、回到負電荷，線越密代表電場越強，切線方向就是正電荷受力的方向。

定義E = F / q
點電荷E = k q / r²（單位 N/C = V/m）

PART 1

高斯定律 穿出封閉曲面的電通量

把電荷包在任意封閉曲面裡，曲面變大時電場變弱、面積變大，兩者剛好抵消，穿出的總電通量不變。總通量只由包在裡面的電荷決定。

公式∮ E·dA = Q_enc / ε₀
常數ε₀ = 8.85 × 10⁻¹² F/m

PART 1

電位與等位線 電荷的「地形高度」

正電荷周圍電位高、負電荷周圍電位低，像山丘和凹谷。正電荷會從高電位往低電位「滾」，電場指向電位下降最快的方向。電壓就是兩點的電位差。

點電荷電位V = k q / r
電場與電位E = −dV/dx
能量W = q ΔV

PART 1

導體的靜電屏蔽 法拉第籠

外加電場時，金屬裡的自由電子重新分布到表面，產生的電場剛好抵消外加電場，所以導體內部電場為零。電梯、微波爐門網、同軸電纜外層都是應用。

導體內部E = 0
電荷分布只在導體表面

PART 2

電容器 用電場儲存能量

兩片平行板接上電壓，上板累積 +Q、下板 −Q，中間是均勻電場。間距越小、面積越大，電容越大，同樣電壓能存越多電荷。

電容C = ε₀ A / d
電荷與能量Q = CV、U = ½CV²
板間電場E = V / d

PART 2

介電質 讓電容變大

在兩板之間放入介電質，裡面的分子偶極會轉向排列，產生反向電場，使淨電場變弱。同樣電壓下能存更多電荷，電容變成 κ 倍。high-k 閘極介電層就是這個道理。

電容C = κ ε₀ A / d
電場E = E₀ / κ
例SiO₂ 3.9、HfO₂ ~25

PART 2

RC 電路 充電與放電

電容經過電阻充電時，電流一開始最大、越充越慢；經過 τ = RC 充到約 63%，約 5τ 幾乎充滿。放電時電壓以同樣的時間常數下降。

時間常數τ = RC
充電V_C = V₀(1 − e^(−t/RC))
放電V_C = V₀ e^(−t/RC)

PART 3

電流與漂移速度 電子其實走得很慢

沒有電場時自由電子亂跑但沒有淨移動；加上電場後，電子在亂跑中慢慢往電場反方向漂移，漂移速度只有約 mm/s 等級，但電場本身以接近光速傳遞，所以燈一開就亮。

電流I = n q v_d A
定義I = dQ / dt（A = C/s）

PART 3

歐姆定律與電阻率 長度越長、截面越小，電阻越大

電阻由材料（電阻率 ρ）和形狀決定：越長越大、越粗越小。電壓、電流、電阻的關係就是歐姆定律，I–V 曲線的斜率是 1/R。

歐姆定律V = IR
電阻R = ρ L / A

電功率與焦耳熱 電流通過電阻會發熱

電子在導體中不斷撞擊原子，把電能變成熱。發熱功率和電流平方成正比：電流加倍，發熱變四倍。

功率P = IV = I²R = V²/R
能量E = P·t（1 度 = 1 kWh）

PART 3

克希荷夫定律 電流守恆、電壓守恆

KCL：流進一個節點的電流總和等於流出的總和（電荷守恆）。KVL：沿任何封閉迴路繞一圈，所有電壓升降加起來等於零（能量守恆）。分析任何電路都從這兩條開始。

KCLΣ I = 0
KVLΣ V = 0

磁鐵與磁力線 N 出、S 進

磁力線在磁鐵外從 N 極出來、繞回 S 極，在磁鐵內從 S 回到 N，永遠是封閉的。灑上鐵粉，每粒鐵粉都會轉成磁力線的方向。

磁的高斯定律∮ B·dA = 0
單位T（1 T = 10⁴ G）
例地磁 ~50 μT、ECR 875 G

PART 4

勞倫茲力 帶電粒子在磁場中繞圈

磁場對運動電荷的力永遠垂直於速度，所以只改變方向、不改變速率，粒子在磁場中繞圈；若速度有沿磁場的分量就變成螺旋。這是 ECR、磁控濺鍍把電子「綁住」的原理。

力F = q v × B
迴旋半徑r = mv / (qB)
迴旋頻率f = qB / (2πm)

PART 4

電流產生磁場 安培右手定則

直導線通電，周圍出現同心圓的磁場：右手拇指指向電流方向，四指彎曲的方向就是磁場方向。磁場和電流成正比、和距離成反比；電流反向，磁場也反向。

直導線B = μ₀ I / (2πr)
常數μ₀ = 4π × 10⁻⁷ T·m/A

螺線管 線圈裡的均勻磁場

導線繞成線圈，每一圈的磁場疊加，線圈裡面的磁力線平行、等距，形成均勻磁場；外面看起來像一根條形磁鐵。加鐵芯可以讓磁場再放大很多倍。

線圈內B = μ₀ n I
加鐵芯B × μ_r

馬達原理 磁場對電流的力

通電線圈放在磁場中，兩邊導線受力方向相反，形成力矩讓線圈轉動；換向器讓電流每半圈反向，線圈就能一直同方向轉。

導線受力F = I L × B
力矩τ = N I A B sin θ

PART 4

磁性材料 磁區與磁滯曲線

鐵磁材料內有許多磁區，平常方向雜亂所以不帶磁；外加磁場時磁區轉向排齊，拿掉外加磁場後仍留下一部分磁化，形成磁滯曲線。軟磁材料曲線瘦，適合做變壓器鐵芯；硬磁材料曲線胖，適合做磁鐵。

PART 5

電磁感應 法拉第定律

通過線圈的磁通量改變時，線圈會產生感應電動勢；磁通量不變（磁鐵不動）就沒有電。變化越快，電動勢越大；磁鐵進、出的方向相反，電流方向也相反。

法拉第定律ε = −N dΦ/dt
磁通量Φ = B·A

冷次定律與渦電流 感應電流抵抗變化

感應電流的方向總是要抵抗磁通量的變化。磁鐵在銅管裡下落時，管壁感應出渦電流，它的磁場阻止磁鐵運動，所以落得很慢；塑膠管沒有導電就一下掉下去。

PART 5

電感與 RL 電路 電流不能瞬間改變

電感中的電流一改變，就會感應出反向電動勢阻止它變化，所以接上電壓後電流慢慢爬升，切斷時慢慢下降。電感把能量存在磁場裡。

電感電壓V_L = L dI/dt
時間常數τ = L / R
能量U = ½ L I²

變壓器 用圈數比改變電壓

一次側的交流電在鐵芯裡產生變化的磁通量，同一個磁通量穿過二次側，每一圈感應的電壓相同，所以電壓和圈數成正比；理想情況下功率不變，電流則反比。

電壓V₂/V₁ = N₂/N₁
電流I₂/I₁ = N₁/N₂

PART 6

阻抗與相位 R、L、C 的相位差

交流電路裡，電阻的電壓和電流同相；電感的電壓領先電流 90°，頻率越高阻抗越大；電容的電流領先電壓 90°，頻率越高阻抗越小。這三者合起來就是阻抗 Z。

電阻Z = R
電感Z = jωL
電容Z = 1/(jωC)

PART 6

RLC 共振 能量在 L 和 C 之間來回

電容放電時電流流進電感、建立磁場；磁場消失時又把電容反向充回去，能量來回擺盪。驅動頻率等於共振頻率時，電感和電容的阻抗互相抵消，電流最大；電阻越小，共振峰越尖。

共振頻率f₀ = 1/(2π√(LC))
共振時Z_L = Z_C、|Z| 最小

阻抗匹配 讓功率全部送到負載

電磁波 電場和磁場互相推著前進

變化的電場產生磁場、變化的磁場又產生電場，兩者互相垂直、也垂直於前進方向，一路往前傳，不需要介質。馬克士威由方程式算出它的速度正好等於光速，發現光就是電磁波。

PART 7

電磁波譜 同一種波，波長不同

無線電、微波、紅外線、可見光、紫外線、X 光都是電磁波，差別只在波長和頻率。波長越短，頻率越高，每顆光子的能量也越大。RF 13.56 MHz、ECR 的 2.45 GHz、OES 看的可見光、EUV 13.5 nm 都在這張譜上。

集膚效應 高頻電流只走表面

PART 8

馬克士威方程組 四句話說完電磁學
